# データモデリングの学習ドキュメント

データエンジニアの視点でデータモデリングを学ぶためのドキュメント群である。
各章は、概念の解説、具体例（SQL や dbt モデル）、参考文献の三部構成とする。
例は特定製品に依存させず、BigQuery や Snowflake 相当の一般的な SQL で書く。

## 目次

各章の本文、演習問題、読み上げ音声を章ごとにまとめる。
演習問題は四択で、選択肢を選ぶと正誤と解説がその場で表示される（第 11 章は章全体が総合演習のため対象外）。
音声は聴取用の読み上げ原稿から生成した mp3 で、移動中などのハンズフリー学習に使える。
