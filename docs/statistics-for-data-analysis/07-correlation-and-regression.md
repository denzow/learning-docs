# 第7章 相関と回帰分析

第 5 章と第 6 章では、二つの群の平均や比率に差があるかを問うた。
そこで比べたのは、デバイスや地域のような区分ごとの値である。
しかし分析の問いには、区分ではなく量の関係を尋ねるものも多い。
広告費を増やした日は売上が増えるのか、顧客の年齢が上がると注文金額は上がるのか、といった問いである。
本章では、二つ以上の量的変数のあいだの関係を測る道具として、相関と回帰を扱う。

相関は、二つの変数が連動する強さを一つの数で要約する。
回帰は、連動の向きと大きさを式で表し、ある変数の値からもう一方の値を見積もる。
どちらも記述統計として使えるうえ、第 4 章の推定と第 5 章の検定をそのまま載せて、標本から母集団の関係を推測する道具にもなる。
一方で、相関も回帰も、それだけでは因果を示さない。
広告費と売上が連動していても、両方を押し上げる別の要因が隠れているかもしれない。
本章では、その「関係はあるが原因とは限らない」という限界を、数値の上で確かめる。
原因を問う道具は第 9 章で扱う。

## 概念の解説

### 共分散と相関係数

二つの量的変数の関係を測る出発点は、両方の変数がそれぞれの平均からどちらの向きにずれているかを掛け合わせることである。
広告費が平均より多い日に売上も平均より多ければ、その日の積は正になる。
片方だけが平均より多ければ積は負になる。
この積を全期間で平均したものが**共分散**であり、正なら二つの変数は同じ向きに動きやすく、負なら逆向きに動きやすい。

共分散には、値の大きさが単位に依存するという不便がある。
売上を円で測るか千円で測るかで、共分散の値は千倍変わる。
そこで共分散を、二つの変数の標準偏差の積で割って単位を消したものが**相関係数**である[^pearson]。
相関係数は −1 から 1 の範囲に収まり、1 に近いほど一方が増えると他方も直線的に増え、−1 に近いほど一方が増えると他方が直線的に減る。
0 は直線的な連動がないことを表す。

相関係数の大きさを読むときには、二乗した値を見るとよい。
相関係数を二乗した値は、一方の変数のばらつきのうち、他方との直線関係で説明できる割合を表す。
顧客の年齢と注文金額の相関係数が 0.15 だとすると、二乗は 0.02 であり、注文金額のばらつきの 2% しか年齢では説明できない。
「相関がある」という言い方は、それだけでは関係の強さを伝えない。

相関係数は、外れ値に引きずられやすく、直線的でない関係を捉えられない。
この弱点を避けたいときは、値そのものではなく値の順位のあいだで相関係数を計算する。
これが**スピアマンの順位相関係数**である。
順位に置き換えれば、極端に大きな値も「一番大きい」という順位になるだけなので、外れ値の影響が抑えられる。
また、一方が増えれば他方も増えるという単調な関係であれば、直線でなくても順位相関は高くなる。
値の大きさそのものに意味がある場面では通常の相関係数を、順序だけを問題にする場面や外れ値が多い場面では順位相関を使う。

### 相関係数が見せないもの

相関係数は関係を一つの数に圧縮するので、圧縮で失われる情報がある。
分析でよく問題になる失われ方を五つ挙げる。

**外れ値**は、相関係数を一日で作れる。
一年分の日次データで広告費と売上の相関を計算するとき、大型キャンペーンで広告費も売上も桁違いに大きい日が一日あれば、残りの 364 日に連動がなくても相関係数は高く出る。
散布図を描いて一点が離れていないかを確かめるか、順位相関と比べて値が大きく違わないかを見る。

**非線形な関係**は、相関係数には映らない。
たとえば年齢と注文金額の関係が、40 代まで上がってその後下がる山形だとすると、上りと下りが打ち消し合って相関係数は 0 に近くなる。
相関係数が 0 であることは、関係がないことを意味しない。
「直線的な関係がない」ことを意味するだけである。

**範囲の制限**は、相関を弱く見せる。
年間購入額が上位 10% の優良顧客だけを取り出して、サイトの訪問回数と購入額の関係を調べると、相関はほとんど出ない。
優良顧客はどの人も訪問回数が多く、購入額も高いので、変数の動く範囲がそもそも狭いからである。
全顧客で計算すれば、同じ二つの変数のあいだに強い相関が見えることが多い。

**疑似相関**は、二つの変数に共通して効く第三の要因が作る相関である。
広告費と売上は連動して見えるが、その連動の一部は年末商戦が作っている。
年末には販促の予算が増えて広告費が上がり、同時に贈答需要で売上も上がる。
広告に効果がまったくなくても、年末を含む一年分のデータでは広告費と売上に正の相関が出る。
このような共通要因を**交絡**と呼ぶ。
交絡は相関を作るだけでなく、消したり逆向きにしたりもする。

**シンプソンのパラドックス**は、交絡が関係を逆転させる極端な形である。
全体で見ると A のほうが B より良いのに、デバイス別に分けると mobile でも desktop でも B のほうが良い、ということが起きる。
A と B でデバイスの構成比が違い、デバイスが結果に強く効いていると、全体の比較はデバイスの構成比の比較になってしまう。
具体例の節で、この逆転を実際の表で確かめる。

### 単回帰と最小二乗法

相関係数は連動の強さを表すが、「広告費を 1 万円増やすと売上はいくら増えるか」という大きさの問いには答えない。
その問いに答えるのが**回帰分析**である。
回帰分析は、説明したい変数（**目的変数**）を、手がかりになる変数（**説明変数**）の式で表す。
説明変数が一つで、式が直線のものを**単回帰**と呼ぶ。

```text
売上 = 切片 + 傾き × 広告費 + 残差
```

**切片**は広告費が 0 のときの売上の見積もり、**傾き**は広告費が 1 円増えたときに売上が平均していくら変わるかを表す。
**残差**は、直線による見積もりと実際の値との差である。
直線の引き方は、残差を二乗して足し合わせた値が最小になるように傾きと切片を選ぶ。
この決め方を**最小二乗法**と呼ぶ[^ols]。

回帰の当てはまりの良さは**決定係数**で測る。
決定係数は、目的変数のばらつきのうち、回帰式で説明できた割合であり、0 から 1 の値を取る。
単回帰では、決定係数は相関係数の二乗に一致する。
決定係数が 0.44 なら、売上の日ごとのばらつきの 44% が広告費の直線で説明でき、残りの 56% は残差として残る。

傾きは標本から計算した推定値なので、第 4 章の推定の枠組みがそのまま載る。
傾きには標準誤差があり、信頼区間が作れる。
第 5 章の検定も載り、「傾きは 0 である」を帰無仮説にした t 検定が、統計ソフトの出力に並ぶ p 値である。
傾きの信頼区間が 0 をまたがなければ、説明変数と目的変数の直線関係は偶然では説明しにくい、と読む。

### 重回帰と統制変数

説明変数が二つ以上ある回帰を**重回帰**と呼ぶ。

```text
売上 = 切片 + b1 × 広告費 + b2 × 週末 + b3 × 12月 + 残差
```

重回帰の傾きの読み方は、単回帰と一つだけ違う。
b1 は「他の説明変数の値を固定したうえで、広告費が 1 円増えたときに売上が平均していくら変わるか」を表す。
週末かどうかと 12 月かどうかを固定して比べるので、年末商戦が作る見かけの連動は b1 から取り除かれる。
このように、関心のある変数の効果を測るために式に加える変数を**統制変数**と呼ぶ。
前節の疑似相関への対処は、交絡になっている変数を統制変数として式に入れることである。
ただし、統制できるのは列として持っている変数だけであり、記録されていない交絡は取り除けない。
この限界の扱いは第 9 章に持ち越す。

「週末」や「12 月」のような二値の変数は、該当する日を 1、しない日を 0 とした列にして式に入れる。
この 0 と 1 の列を**ダミー変数**と呼ぶ。
ダミー変数の傾きは、「その条件に当てはまる日は、当てはまらない日より平均していくら多いか」を表す。
曜日のように三つ以上の値を取る質的変数は、一つの値を基準にして残りの値ごとにダミー変数を作る。
月曜を基準にすると、火曜から日曜の六つのダミー変数ができ、それぞれの傾きは月曜との差になる。
七つ全部をダミー変数にすると、七つの列を足すと必ず 1 になって切片と区別がつかなくなるため、一つは必ず基準として外す。

説明変数を増やすと、決定係数は必ず上がるか変わらない。
まったく無関係な列を足しても、偶然の当てはまりで決定係数はわずかに上がる。
説明変数の数で罰則を付けたものが**自由度調整済み決定係数**であり、説明変数の数が違うモデルを比べるときはこちらを見る。

重回帰には、単回帰にはない落とし穴がある。
説明変数どうしが強く相関していると、それぞれの傾きを分けて推定できなくなる。
広告費と広告のクリック数は、クリック数が広告費でほぼ決まるので、ほとんど同じ動きをする。
両方を式に入れると、売上の変化をどちらの変数のせいにすべきかをデータから決められず、両方の傾きの標準誤差が大きくなり、符号が不安定になる。
この状態を**多重共線性**と呼ぶ。
共線性の程度は、各説明変数を他の説明変数で回帰したときの決定係数から計算する**分散拡大係数**（VIF）で測り、10 を超えたら疑うという目安がよく使われる。
対処は、意味の重なる変数の片方を外すか、二つを一つの指標にまとめることである。

### 回帰の前提と、予測と説明の違い

最小二乗法の傾きと信頼区間が信頼できるのは、いくつかの前提が成り立つときである。
関係が直線で近似できること、残差が互いに独立であること、残差のばらつきが説明変数の値によらず一定であること、の三つが主要な前提になる。
残差が正規分布に従うという前提もよく挙げられるが、これは傾きの推定そのものには要らず、標本が小さいときの信頼区間と p 値に効くだけである。

前提の点検は、残差を見て行う。
説明変数の値に対して残差を並べ、曲がったパターンが見えれば直線の前提が崩れている。
残差の幅が説明変数の値とともに広がっていれば、ばらつき一定の前提が崩れている。
日次データでは、前日の残差と当日の残差が似ている（自己相関がある）ことが多く、残差の独立の前提が崩れる。
自己相関があると傾きの標準誤差が実際より小さく計算され、信頼区間が狭すぎる形で出る。
時系列に固有のこの問題は第 10 章で扱う。

回帰分析には、目的の違う二つの使い方がある。
一つは**予測**で、明日の広告費と曜日から明日の売上を見積もるように、目的変数の値を当てることが目的である。
もう一つは**説明**で、広告費の傾きそのものを知りたい、という使い方である。
どちらの目的かで、同じモデルの評価が変わる。
予測が目的なら、多重共線性は問題にならない。
広告費とクリック数の傾きがどう分かれようと、二つを合わせた見積もりは安定しているからである。
一方、説明が目的なら、共線性で傾きが不安定になるのはそのまま結論の不安定を意味する。
また、予測が目的ならモデルの当てはまりは未知のデータで測るべきで、手元のデータへの決定係数は当てにならない。
本章の具体例は説明を目的にしており、傾きの大きさと信頼区間を読む。

## 具体例

一年分の日次売上（daily_sales）と日次広告費（daily_ads）を使い、広告費が売上に与える効果を見積もる。
本文の数値は、広告費 1 円あたり 2 円の売上増、週末に 15 万円の上乗せ、12 月に広告費の倍増と 30 万円の上乗せ、という構造を仮定して作った模擬データから計算した。
現実のデータではこの「正解」は見えないが、模擬データなら分析の手続きがどれだけ正解に近づくかを確かめられる。

### 広告費と売上の相関を SQL で測る

相関係数は、多くの DWH が集計関数として持っている。

```sql
SELECT
    CORR(a.ad_cost, s.amount) AS r_all,
    CORR(CASE WHEN EXTRACT(MONTH FROM s.sales_date) <> 12 THEN a.ad_cost END,
         CASE WHEN EXTRACT(MONTH FROM s.sales_date) <> 12 THEN s.amount END) AS r_excl_dec
FROM daily_sales AS s
JOIN daily_ads AS a ON a.sales_date = s.sales_date
WHERE s.sales_date BETWEEN DATE '2025-01-01' AND DATE '2025-12-31';
```

```text
r_all   r_excl_dec
0.661   0.205
```

一年を通した相関係数は 0.66 で、広告費と売上は強く連動しているように見える。
しかし 12 月を除くと 0.21 まで下がる。
12 月は広告費が倍になり、贈答需要で売上も上がる。
12 月の 31 日分が右上に固まって、残りの 334 日にある弱い連動を強い直線に見せていた。
同じデータでスピアマンの順位相関を計算すると 0.38 で、通常の相関係数より小さい。
順位相関が大きく下回るのは、一部の極端な値が通常の相関係数を押し上げている合図である。

### 単回帰で広告費の効果を見積もる

一年分のデータで、売上を広告費だけで回帰する。

```python
import pandas as pd
import statsmodels.formula.api as smf

daily = pd.read_csv("daily.csv")  # sales_date, ad_cost, amount
daily["sales_date"] = pd.to_datetime(daily["sales_date"])
daily["weekend"] = (daily["sales_date"].dt.dayofweek >= 5).astype(int)
daily["december"] = (daily["sales_date"].dt.month == 12).astype(int)

simple = smf.ols("amount ~ ad_cost", data=daily).fit()
print(simple.params.round(2))
print("R2:", round(simple.rsquared, 3))
```

```text
Intercept    987131.30
ad_cost           6.15
R2: 0.437
```

傾きは 6.15 で、広告費が 1 円多い日は売上が平均で 6.15 円多いと読める。
決定係数 0.437 は、相関係数 0.661 の二乗に一致する。
しかし、模擬データに仕込んだ本当の効果は 1 円あたり 2 円である。
単回帰は、年末商戦が作る売上の上乗せまで広告費の傾きに乗せてしまい、効果を三倍に見積もっている。

### 曜日と年末を統制した重回帰

週末と 12 月のダミー変数を統制変数として加える。

```python
multi = smf.ols("amount ~ ad_cost + weekend + december", data=daily).fit()
print(multi.summary().tables[1])
print("R2:", round(multi.rsquared, 3), "adj R2:", round(multi.rsquared_adj, 3))
```

```text
                 coef    std err          t      P>|t|      [0.025      0.975]
Intercept   1.102e+06    2.3e+04     47.845      0.000    1.06e+06    1.15e+06
ad_cost        2.6782      0.457      5.859      0.000       1.779       3.577
weekend     1.575e+05   1.11e+04     14.153      0.000    1.36e+05    1.79e+05
december    2.890e+05   3.01e+04      9.618      0.000    2.30e+05    3.48e+05
R2: 0.687 adj R2: 0.685
```

広告費の傾きは 2.68 まで下がり、95% 信頼区間は 1.78 から 3.58 で、仕込んだ正解の 2 を含む。
週末の傾きは約 15.8 万円、12 月の傾きは約 28.9 万円で、どちらも仕込んだ値（15 万円と 30 万円）に近い。
決定係数は 0.687 に上がったが、これは統制変数が売上の変動を説明したためであり、広告費の説明力が上がったわけではない。
残差の標準偏差は約 9.6 万円で、仕込んだ日々のばらつき（10 万円）とほぼ一致する。

ここで傾きの読み方に注意したい。
2.68 という値は、「同じ曜日区分で同じ月区分の日どうしを比べたとき、広告費が 1 円多い日は売上が平均で 2.68 円多い」という意味である。
週末と 12 月を統制したので、年末商戦が作る見かけの連動は取り除かれた。
しかし、記録していない交絡、たとえばテレビで書籍が紹介された日に広告費も増やしていたといった事情があれば、その分はまだ傾きに乗っている。
重回帰が取り除けるのは、列として持っている交絡だけである。

### 共線性のある説明変数を足す

広告のクリック数（clicks）も日次で記録されているとする。
クリック数は広告費でほぼ決まるので、二つの相関係数は 0.99 になる。
これを説明変数に足すと、傾きはどうなるか。

```python
collinear = smf.ols("amount ~ ad_cost + clicks + weekend + december", data=daily).fit()
print(collinear.summary().tables[1])
```

```text
                 coef    std err          t      P>|t|      [0.025      0.975]
Intercept   1.102e+06   2.31e+04     47.787      0.000    1.06e+06    1.15e+06
ad_cost        1.9041      2.201      0.865      0.388      -2.424       6.232
clicks        30.9986     86.212      0.360      0.719    -138.544     200.541
weekend     1.575e+05   1.11e+04     14.135      0.000    1.36e+05    1.79e+05
december    2.893e+05   3.01e+04      9.612      0.000    2.30e+05    3.48e+05
```

広告費の傾きの標準誤差は 0.46 から 2.20 に膨らみ、信頼区間は −2.4 から 6.2 まで広がって、効果の有無すら判断できなくなった。
クリック数の傾きも同様である。
分散拡大係数を計算すると、広告費とクリック数はどちらも 60 を超え、目安の 10 を大きく上回る。

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor
import statsmodels.api as sm

X = sm.add_constant(daily[["ad_cost", "clicks", "weekend", "december"]])
for i, name in enumerate(X.columns[1:], start=1):
    print(name, round(variance_inflation_factor(X.values, i), 1))
```

```text
ad_cost 64.3
clicks 62.0
weekend 1.0
december 2.8
```

週末と 12 月の傾きは変わっていない点にも注目したい。
共線性は、相関している説明変数どうしの傾きだけを壊す。
広告の効果を知りたいなら、広告費とクリック数のどちらか一方だけを式に残す。
予測が目的なら、この式のままでも売上の見積もりは安定している。

### ランディングページとシンプソンのパラドックス

回帰から離れて、質的な変数のあいだで交絡が関係を逆転させる例を見る。
二種類のランディングページ A と B について、セッション単位のコンバージョン率をデバイス別に集計する。

```sql
SELECT
    landing_page,
    device,
    COUNT(*) AS sessions,
    SUM(CASE WHEN converted THEN 1 ELSE 0 END) AS conversions,
    ROUND(100.0 * SUM(CASE WHEN converted THEN 1 ELSE 0 END) / COUNT(*), 2) AS cvr
FROM sessions
WHERE landing_page IN ('A', 'B')
GROUP BY landing_page, device
ORDER BY landing_page, device;
```

| ページ | デバイス | セッション数 | 購入数 | CVR |
| --- | --- | --- | --- | --- |
| A | desktop | 8,000 | 320 | 4.00% |
| A | mobile | 2,000 | 40 | 2.00% |
| B | desktop | 2,000 | 90 | 4.50% |
| B | mobile | 8,000 | 192 | 2.40% |

デバイス別に見ると、desktop でも mobile でも B のほうが CVR が高い。
ところがデバイスを合算すると、A は 360 ÷ 10,000 で 3.60%、B は 282 ÷ 10,000 で 2.82% となり、A のほうが高い。
逆転の原因は、A のセッションの 8 割が CVR の高い desktop から来ていて、B のセッションの 8 割が CVR の低い mobile から来ていることにある。
合算した比較は、ページの比較ではなくデバイス構成の比較になっていた。

どちらの比較を信じるべきかは、デバイスがどのように決まるかで決まる。
デバイスは利用者が持ち込むものであり、ページによって変わるものではない。
だからページの良し悪しは、デバイスを固定した比較で判断すべきであり、B のほうが良いという結論になる。
これは重回帰でデバイスをダミー変数として統制するのと同じ判断である。
逆に、ページが利用者のデバイスの選択を変えるような状況（たとえばページ B がアプリへの誘導を強く出す）なら、デバイス別に分けると効果の一部を消してしまう。
分けるかどうかは表の形からは決まらず、変数のあいだの因果の向きを考えて決める。
この判断の整理は第 9 章で扱う。
