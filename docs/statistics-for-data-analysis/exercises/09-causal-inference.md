# 第9章 演習問題

対象章：[第9章 因果推論の入門](../09-causal-inference.md)（[読み上げ原稿](../audio-scripts/09-causal-inference.md)）

## 問題

### 問1

クーポンを配布した顧客の翌月の購入額は 5,000 円だった。
因果推論の考え方で、この顧客一人についてのクーポンの効果を測れないとされる理由はどれか。

- A. 一人分のデータでは標本が小さすぎて、信頼区間が広くなりすぎるから
- B. 同じ顧客の同じ月について、配布しなかった場合の購入額（反事実）は観測できないから
- C. 購入額は右に歪んだ分布に従い、一人の値は平均を代表しないから
- D. クーポンの効果は顧客によって異なり、一人の効果は集団の平均と一致しないから

### 問2

過去 1 年の注文回数が多い顧客に優先してクーポンを配布し、翌月の購入額を配布の有無で比べたところ、処置群のほうが 1,642 円多かった。
配布前の月の購入額も処置群のほうが 1,123 円多かった。
この結果の読み方として適切なものはどれか。

- A. 配布後の差 1,642 円がクーポンの効果である。配布前の差は、処置群がもともと熱心な顧客だという事実を示すだけで、効果の推定には影響しない
- B. 処置群は注文回数が多い顧客なので購入額が多いのは当然であり、1,642 円は、クーポンの効果と、注文回数の多さがもたらす効果を合計した因果効果である
- C. 配布前の差はクーポンの効果ではありえないので、処置群と対照群には処置とは無関係の差があり、1,642 円の大半は選択バイアスと考えられる
- D. 配布前から差があるということは、処置群と対照群は比較できない集団であり、観察データからは効果について何も言えない

### 問3

差の差（DID）で効果を推定するとき、置いている前提と、その前提について確かめられることの組み合わせとして正しいものはどれか。

- A. 前提は、処置群と対照群の処置前の水準が等しいことであり、処置前の平均を比べて確かめる
- B. 前提は、処置がなければ両群の結果が同じように変化したことであり、処置前の複数期間で両群の推移が平行だったかを確かめる。処置後についても平行だったことまでは確かめられない
- C. 前提は、交絡因子がすべて観測されていることであり、処置と結果の両方に相関する変数がデータに含まれているかを確かめる
- D. 前提は、処置の割り当てが乱数で決まっていることであり、両群の属性の分布が等しいかを確かめる

### 問4

クーポンの効果を回帰で推定するにあたり、モデルに含める変数を検討している。
含めると効果の推定を歪める変数はどれか。

- A. 配布の基準に使われた、過去 1 年の注文回数
- B. 顧客の登録からの経過月数
- C. 配布前の月の購入額と、顧客の地域
- D. クーポンの受け取り履歴と購入額の両方から決まる、翌月末の会員ランク

### 問5

配布の基準が過去 1 年の注文回数だと分かっており、注文回数が 11 回以上の顧客には全員に配布されていた。
観察データからの推定について正しい記述はどれか。

- A. 注文回数で調整すれば、11 回以上の顧客層についても他の層と同じ精度で効果を推定できる
- B. 注文回数が 11 回以上の顧客層には対照群がいないため、その層の効果は観察データからは推定できず、推定値が意味を持つ範囲を報告に書き添える必要がある
- C. 全員に配布された層は選択バイアスがないので、その層だけを使えば単純比較で効果を推定できる
- D. 傾向スコアを使えば、対照群のいない層についても処置群の重みを調整して効果を推定できる

## 解答と解説

### 問1

**解答**：B

因果効果は、配布した場合と配布しなかった場合の潜在結果の差として定義されるが、一人の顧客について観測できる潜在結果は片方だけである。
実際に起きなかったほうの結果（反事実）は定義上観測できないため、個人の因果効果は原理的に測れず、因果推論は集団の平均を推定の対象にする。
A は推定の精度の問題であり、データを増やしても反事実が観測できるようにはならない。
C と D は事実として正しい面があるが、章が個人の効果を測れない理由として挙げたのは反事実の観測不能性である。

### 問2

**解答**：C

観測された差は、処置の効果と選択バイアス（処置がなくても両群のあいだにあったはずの差）の和に分解できる。
配布前の月の差はクーポンの効果ではありえないので、処置群が処置を受けなくても対照群より多く買っていたはずの差、つまり選択バイアスが存在する証拠である。
A は選択バイアスを無視している。
B は誤りで、注文回数の多さは処置より前に決まっている属性であり、クーポンが引き起こした結果ではない。処置と結果の両方に影響する交絡因子であって、その影響は因果効果ではなく選択バイアスに数えられる。
D は誤りで、配布前から差がある集団でも、差の差や交絡因子の調整によって効果を推定できる。

### 問3

**解答**：B

差の差は、処置群の前後の変化から対照群の前後の変化を引くことで、時間を通じて変わらない群の差と、両群に共通する時間の変化を消す。
残りを効果と読むには、処置がなければ両群が同じように変化したという平行トレンドの仮定が要る。
処置前に複数の期間があれば、その期間で推移が平行だったかを確かめられるが、処置後についての平行は確かめようがなく、仮定として残る。
A は誤りで、差の差は処置前の水準が違っていても使え、その差を消すための方法である。
C は層別化や回帰による調整が置く無視可能性の前提、D はランダム化の前提であり、差の差のものではない。

### 問4

**解答**：D

会員ランクは、処置（クーポンの受け取り）と結果（購入額）の両方から矢印を受けるコライダーである。
コライダーで条件づけると、同じランクの中でクーポンと購入額のあいだに元はなかった相関が生まれ、閉じていた経路が開く。
処置の後に決まる変数も、処置の働く経路の一部なら調整すべきでない。
A は配布の基準そのものであり、調整すべき交絡因子である。
B と C は処置より前に決まる顧客の属性であり、調整しても効果の推定を歪めず、交絡因子であれば調整に役立つ。

### 問5

**解答**：B

観測した交絡因子で調整する方法は、交絡因子の値が同じ顧客どうしを比べるので、ある値の顧客が処置群にしかいなければ比較の相手がいない。
これが共通サポートの条件であり、全員に配布された層についての効果は観察データからは推定できない。
報告では、効果が定義されている集団の範囲として、この点を書き添える。
A は共通サポートを無視している。
C は誤りで、全員に配布された層には対照群がなく、単純比較そのものができない。
D も誤りで、傾向スコアが 1 に近い顧客は逆確率重み付けで極端な重みを持つか、対照群に対応する顧客がいないため、共通サポートの問題を解決しない。
