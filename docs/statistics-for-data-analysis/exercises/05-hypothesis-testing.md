# 第5章 演習問題

対象章：[第5章 仮説検定の考え方](../05-hypothesis-testing.md)（[読み上げ原稿](../audio-scripts/05-hypothesis-testing.md)）

## 問題

### 問1

おすすめ枠の A/B テストで、二群のコンバージョン率の差を検定したところ p 値は 0.03 だった。
この p 値の意味として正しいものはどれか。

- A. 二群の母集団のコンバージョン率が等しい確率が 3% である
- B. おすすめ枠に効果がある確率が 97% である
- C. 二群の率が等しいと仮定したとき、観測された差と同じかそれ以上に極端な差が得られる確率が 3% である
- D. 同じテストを繰り返したとき、97% の確率で同じ向きの差が再現する

### 問2

決済フローを変更する施策の A/B テストで、有意水準を慣例の 0.05 ではなく 0.01 にすることにした。
この決定がもたらす影響として正しいものはどれか。

- A. 第一種の過誤の確率は下がるが、同じ標本サイズでは第二種の過誤の確率が上がる
- B. 第一種の過誤と第二種の過誤の確率が両方とも下がる
- C. 第二種の過誤の確率は下がるが、第一種の過誤の確率が上がる
- D. 過誤の確率は変わらず、必要な標本サイズだけが減る

### 問3

各群 5,000 セッションの A/B テストで、コンバージョン率は対照群 3.0%、処置群 3.3% だったが、p 値は 0.39 で有意ではなかった。
この結果の報告として適切なものはどれか。

- A. 帰無仮説が棄却できなかったので、おすすめ枠には効果がないと結論する
- B. 差の信頼区間が 0 をまたいで広いことを示し、この標本サイズでは効果の有無を判断できなかったと報告する
- C. 観測された差は相対 10% の改善なので、p 値にかかわらず効果ありと報告する
- D. 片側検定に切り替えて p 値を半分にし、有意になるかを確かめてから報告する

### 問4

月に数百万セッションが届くストアで A/B テストを行ったところ、コンバージョン率の 0.01 ポイントの差が p 値 0.001 で有意になった。
この結果の扱いとして適切なものはどれか。

- A. p 値が非常に小さいので、効果は大きいと判断して施策を全面展開する
- B. 標本が大きすぎると検定が信頼できなくなるので、標本を減らして再検定する
- C. 有意水準を 0.001 に下げても有意なので、効果の存在は確実と報告する
- D. 統計的有意と実務的な意味は別なので、差の大きさと信頼区間を、事前に決めた意味のある差の水準と照らして判断する

### 問5

3.0% から 3.3% への改善を想定した A/B テストを設計している。
検出力の計算について正しいものはどれか。

- A. 検出力は有意水準 α を決めれば自動的に決まり、標本サイズには依存しない
- B. 検出力 0.8 とは、効果が本当にあるときにそれを有意として検出できる確率が 80% であることを意味し、想定する効果量が小さいほど必要な標本サイズは増える
- C. 検出力は分析の後にしか計算できないため、必要な標本サイズは経験則で決める
- D. 検出力を 0.8 から 0.9 に上げると、必要な標本サイズは減る

## 解答と解説

### 問1

**解答**：C

p 値は「帰無仮説が正しいと仮定したとき、観測された値と同じかそれ以上に極端な検定統計量が得られる確率」である。
A は条件の向きが逆で、p 値は仮説を仮定したうえでのデータの確率であり、仮説そのものの確率ではない。
B は A の裏返しの誤りで、1 から p 値を引いた値に意味はない。
D の再現確率も p 値の定義には含まれず、p 値からは導けない。

### 問2

**解答**：A

有意水準 α は、帰無仮説が正しいときに第一種の過誤（偽陽性）を犯す確率そのものなので、0.01 にすれば偽陽性は減る。
しかし棄却の閾値が遠のくため、同じ標本サイズでは本当に効果があっても棄却できない場面が増え、第二種の過誤（偽陰性）は増える。
二つの過誤は片方を減らせばもう片方が増える関係にあり、B のように両方を同時に下げるには標本サイズを増やすしかない。
D のように必要な標本サイズが減ることもなく、むしろ同じ検出力を保つには標本を増やす必要がある。

### 問3

**解答**：B

帰無仮説を棄却できなかったことは、帰無仮説が正しいことの証拠にはならない。
各群 5,000 セッションでは検出力が 0.14 程度しかなく、効果があっても高い確率で見逃す設計だったので、A のように「効果がない」とは言えない。
C は検定の結果を無視しており、観測された差が偶然の範囲にあることを説明できない。
D はデータを見てから検定の向きを選ぶ操作であり、第一種の過誤の確率を宣言した α より大きくしてしまう。
信頼区間の幅を示して、判断に足るデータがなかったことを報告するのが適切である。

### 問4

**解答**：D

p 値は効果の大きさと標本サイズの両方で決まるため、標本が大きければどんなに小さな差でも有意になる。
0.01 ポイントの改善が施策のコストに見合うかは統計とは別の判断であり、差の推定値と信頼区間を、事前に決めた意味のある差の水準と照らして判断する。
A は「p 値が小さいほど効果が大きい」という誤読で、C も p 値の小ささを効果の存在の確実性に読み替えている。
B は誤りで、標本が大きいこと自体は検定の信頼性を損なわず、推定の精度をむしろ高める。

### 問5

**解答**：B

検出力は「実際に効果があるときに、それを統計的に有意として検出できる確率」であり、効果量、標本サイズ、α の三つから決まる。
想定する効果量が小さいほど、同じ検出力を得るのに必要な標本サイズは急速に増える（相対 10% の改善では各群 5 万余り、相対 5% では 20 万余り）。
A は誤りで、検出力は標本サイズに強く依存する。
C も誤りで、検出力は想定する効果量を置けば分析の前に計算でき、必要な標本サイズを決めるのに使う。
D は逆で、検出力を上げるには標本サイズを増やす必要がある。
