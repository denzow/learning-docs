# 総合演習問題

対象章：[第12章 総合演習](../12-capstone.md)（[読み上げ原稿](../audio-scripts/12-capstone.md)）

第1章から第11章までの全章を対象に、学んだ知識を四択で復習する問題集である。
出題は章の順に並んでおり、全 33 問ある。
各問の解説に対応する章を記したので、間違えた問題は該当の章に戻って確認できる。

## 解答と解説

### 問1

**解答**：C

記述したい対象が手元の 3 年分に閉じているなら、全数のデータは母集団そのものであり、検定や信頼区間は要らない。
しかし「このストアの顧客一人あたりの注文金額」という言い方は、来月の顧客や別の状況にも通用する値を指しており、手元のデータはその一つの実現である。
A の欠損や B の期間は標本と見なす理由ではなく、D のように全数に手法が使えないわけでもない。
第1章の母集団と標本の節である。

### 問2

**解答**：B

5 段階の満足度は順序はあるが、「やや不満」と「普通」の間隔が「普通」と「やや満足」の間隔と等しい保証はないので順序尺度である。
実務では平均を目安に使うこともあるが、間隔の等しさを仮定しているという限界を知ったうえで、中央値や分布と併記する。
A の間隔尺度や D の比尺度は間隔や比の意味を要求し、C の名義尺度は順序さえ持たない。
第1章の尺度の分類である。

### 問3

**解答**：D

「出せば上がるか」は介入の効果を問う因果の問いであり、相関や予測では答えられない。
おすすめ枠を見たセッションと見なかったセッションを集計しても（A、B）、見た人がもともと買いやすい人だった可能性を除けない。
表示をランダムに分ければ、その可能性を設計で断てる。
第1章の問いの型と、第8章の A/B テストへの対応である。

### 問4

**解答**：B

右に歪んだ分布では、少数の高額注文が平均を押し上げ、平均は多くの注文より高い位置に来る。
中央値は半数の注文がその値以下にあるという意味を持ち、典型的な注文を表す。
平均は合計売上を語るときには適切だが（C）、それは「典型的な一注文」の問いへの答えではない。
D の最頻値は文庫 1 冊の価格のような特定の値に張りつき、分布全体の代表にはならない。
第2章の代表値の使い分けである。

### 問5

**解答**：C

四分位範囲は第 1 四分位数と第 3 四分位数の差であり、上下の極端な値を動かしても変わらない。
