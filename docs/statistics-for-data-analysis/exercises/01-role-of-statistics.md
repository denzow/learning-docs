# 第1章 演習問題

対象章：[第1章 データ分析における統計の役割](../01-role-of-statistics.md)（[読み上げ原稿](../audio-scripts/01-role-of-statistics.md)）

## 問題

### 問1

分析チームが、先月の注文データから「先月の平均注文金額は 3,200 円だった」と報告した。
この報告と、同じデータから「この店の顧客は平均して 3,200 円程度を 1 回の注文で使う傾向がある」と述べることの違いとして正しいものはどれか。

- A. 前者は記述統計の答えで手元のデータについての事実だが、後者は推測統計の答えで、外れる可能性を含む
- B. 前者は標本からの推定値だが、後者は母集団の値なので、後者のほうが正確である
- C. 両者は同じ数値を指しているので、統計の観点では区別する必要がない
- D. 前者は SQL で計算できるが、後者は Python でなければ計算できない

### 問2

先月の注文は全件が orders テーブルに入っている。
このデータを「標本」として扱わなければならないのはどの問いに答えるときか。

- A. 先月の注文数と売上の合計を報告するとき
- B. 先月、注文金額が 1 万円を超えた注文の件数を数えるとき
- C. デスクトップからの注文はモバイルからの注文より金額が高い傾向があるかを判断するとき
- D. 先月の注文のうちデスクトップからの注文が占める割合を求めるとき

### 問3

購入後のアンケートで満足度を集計したところ、平均が五段階中 4.6 だった。
この値から「顧客の大半は満足している」と結論づけるときに、まず疑うべき点はどれか。

- A. 満足度は名義尺度なので、平均そのものが計算できない
- B. 満足した顧客ほどアンケートに答えやすいという選択バイアスにより、回答者が全顧客を代表していない可能性がある
- C. 五段階の満足度は比尺度なので、4.6 は 2.3 の 2 倍満足していることを意味する
- D. アンケートの回答は離散データなので、平均ではなく合計を使わなければならない

### 問4

次のデータのうち、順序尺度にあたるものはどれか。

- A. sessions テーブルの device（'mobile' か 'desktop'）
- B. orders テーブルの amount（税込の注文金額）
- C. daily_sales テーブルの sales_date（日付）
- D. 書籍のレビューの星の数（1 から 5）

### 問5

「おすすめ枠の効果を見てほしい」という依頼を受けた。
依頼者が本当に知りたいことが「おすすめ枠を出すと CVR が上がるのか」だとすると、この問いの型と、答えるために必要なものの組み合わせとして正しいものはどれか。

- A. 関係の問いであり、おすすめ枠の表示回数と CVR の相関係数を求めればよい
- B. 記述の問いであり、おすすめ枠を出した後の期間の CVR を集計すればよい
- C. 比較の問いであり、おすすめ枠を見た顧客と見ていない顧客の CVR の差が偶然でないと示せればよい
- D. 因果の問いであり、おすすめ枠を出さなかった場合との比較が必要で、無作為に割り当てた A/B テストの記録がそれにあたる

## 解答と解説

### 問1

**解答**：A

先月の注文は全件が手元にあるので、その平均は先月についての事実であり、記述統計の答えである。
一方、今後の顧客を含めた「傾向」についての主張は、先月のデータを標本として、その背後にある仕組みを推し量る推測統計の答えであり、外れる可能性を含む。
B は前者と後者の立場が逆で、手元にあるのは先月の事実であって母集団の値ではない。
C は「記述統計と推測統計」の節で述べた通り、同じ数値でも問いによって事実か推測かが変わるので誤りである。
D は道具の違いであって、両者の違いの本質ではない。

### 問2

**解答**：C

全数か標本かは、データの側ではなく問いの側で決まる。
A、B、D はいずれも先月の注文についての事実を求める記述の問いであり、先月の全体が手元にあるのだから全数として集計すればよい。
C は今後の顧客を含めた購買の傾向についての問いであり、先月のデータはその傾向のもとでたまたま観測された一つの標本にすぎない。
同じ傾向のもとでも来月の値は別の値になるので、差が偶然で説明できる大きさかどうかを見積もる必要がある。

### 問3

**解答**：B

満足した顧客ほどアンケートに答えやすいという仕組みがあると、回答者は全顧客を偏って写した標本になり、回答の平均は全顧客の満足度より高く出る。
これが「母集団と標本」の節で扱った選択バイアスである。
A は誤りで、五段階の満足度は順序尺度であり、名義尺度ではない。
順序尺度の平均には注意がいるが、計算そのものができないわけではない。
C は誤りで、五段階の満足度は差にも比にも意味を保証できない順序尺度であり、倍率の表現は意味を持たない。
D の離散データに平均が使えないという主張は成り立たない。

### 問4

**解答**：D

星の数には順序があるが、星 4 と星 2 の差が星 5 と星 3 の差と同じ大きさだとは言えないため、順序尺度にあたる。
A の device は分類の名前で順序を持たない名義尺度、B の金額は差にも比にも意味があり、ゼロが「何もない」ことを表す比尺度である。
C の日付は差（何日後）に意味はあるが倍率に意味がない間隔尺度である。

### 問5

**解答**：D

「おすすめ枠を出すと CVR が上がるのか」は、働きかけをすると結果が変わるかを問う因果の型である。
因果の問いに答えるには、働きかけを行わなかった場合との比較が必要で、顧客を無作為に割り当てた A/B テストの記録がその比較を与える。
A の相関は関係の問いへの答えであり、連動していても働きかけの効果とは限らない。
B の集計は記述の問いへの答えで、出す前との違いが季節など別の要因によるものかを区別できない。
C は比較の問いへの答えで、差が偶然でないと示せても、おすすめ枠を見た顧客と見ていない顧客がもともと違う層であれば、差の原因がおすすめ枠にあるとは言えない。
