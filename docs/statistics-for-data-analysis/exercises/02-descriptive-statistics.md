# 第2章 演習問題

対象章：[第2章 記述統計と分布の要約](../02-descriptive-statistics.md)（[読み上げ原稿](../audio-scripts/02-descriptive-statistics.md)）

## 問題

### 問1

書籍オンラインストアの注文金額は、最頻値が 1,500 円付近、中央値が 2,400 円、平均が 3,200 円だった。
この三つの値の並びから読み取れる分布の形として正しいものはどれか。

- A. 左に長い裾を引く分布で、少数の安い注文が平均を押し下げている
- B. 左右対称な分布で、三つの値の差は集計の誤差である
- C. 山が二つある分布で、安い注文の山と高い注文の山が分かれている
- D. 右に長い裾を引く分布で、少数の高額な注文が平均を押し上げている

### 問2

「典型的な一件の注文はいくらか」を経営層に伝えるために、注文金額の代表値を一つ選ぶことになった。
注文金額の分布が右に歪んでいるとき、最も適切な選択はどれか。

- A. 平均。件数を掛ければ売上の合計に戻るため、経営指標として整合するから
- B. 中央値。半分の注文がそれより安く半分が高いという位置を示し、裾の高額注文に引っ張られないから
- C. 最頻値。度数分布表で最も件数の多い階級の値であり、集計が最も安価だから
- D. 最大値。高額の注文が売上に与える影響を強調できるから

### 問3

ある日の注文 400 件に、法人からの 500,000 円の一括注文が一件加わった。
この日の要約統計量への影響として正しいものはどれか。

- A. 平均と中央値がともに大きく上がり、標準偏差は変わらない
- B. 平均は変わらず、中央値と標準偏差が大きく上がる
- C. 平均と標準偏差が大きく上がり、中央値はほとんど動かない
- D. 平均、中央値、標準偏差のいずれもほとんど動かない

### 問4

注文金額の箱ひげ図を描いたところ、第 3 四分位数から四分位範囲の 1.5 倍を超えた側に、全注文の 6% にあたる点が並んだ。
これらの点の扱いとして適切なものはどれか。

- A. 記録の誤りと見なし、原因を調べる前に集計から除外する
- B. 規則が外れ値と判定したのだから、分析対象から一律に除外して平均を計算し直す
- C. 上位 6% の値を第 3 四分位数の値に置き換えてから平均を計算する
- D. 右に歪んだ分布では規則が正当な高額注文も拾うので、由来を確かめたうえで、必要なら中央値のような極端値に影響されにくい統計量に切り替える

### 問5

「平均注文金額」という指標を注文単位で計算すると 3,200 円、顧客ごとの平均を求めてから平均すると 2,950 円になった。
この差が生じる理由として正しいものはどれか。

- A. 月に何度も注文する顧客は一件あたりの金額も大きい傾向があり、その注文が件数分だけ注文単位の平均に効くから
- B. 顧客単位の集計では未ログインの注文が除外され、件数が減るから
- C. 二段階の集計では丸め誤差が積み重なり、値が小さく出るから
- D. 注文単位の平均は中央値に近く、顧客単位の平均は幾何平均に近い性質を持つから

## 解答と解説

### 問1

**解答**：D

右に歪んだ分布では、最頻値、中央値、平均の順に右へずれる。
裾にある少数の高額な注文が合計を押し上げ、合計に依存する平均だけが裾の側へ引かれるためである。
A は逆向きで、左に裾を引く分布なら平均が最も小さくなる。
B のように三つの値が一致するのは左右対称な分布の場合であり、800 円の差を誤差とは呼べない。
C の山の数は代表値の並びからは読み取れず、度数分布表やヒストグラムで確かめる事柄である。

### 問2

**解答**：B

中央値は「半分の注文はこれより安く、半分は高い」という位置の情報であり、右の裾にある高額注文に影響されないので、典型的な一件を伝える代表値として適している。
A の平均は合計に結びつく利点があるが、右に歪んだ分布では大多数の注文より高い値を指すため、典型を伝える目的には合わない。
C の最頻値は連続的な量では階級に依存し、集計の安さは代表値を選ぶ理由にならない。
D の最大値は分布の中心を表す代表値ではない。

### 問3

**解答**：C

平均は合計を件数で割るため、一件の 500,000 円がそのまま合計に加わり、400 件の平均は 1,000 円以上上がる。
標準偏差は平均からの偏差の二乗に基づくので、極端な一件でさらに大きく増える（章の例では 8 倍になった）。
一方、中央値は順位で決まるため、一件加わっても順位が一つずれるだけでほとんど動かない。
A と B は中央値が動くとしている点で誤りであり、D は平均と標準偏差が動かないとしている点で誤りである。

### 問4

**解答**：D

四分位範囲の 1.5 倍という規則は左右対称な分布を想定した経験的な目安であり、右に歪んだ分布では裾の正当な値を大量に拾う。
専門書のまとめ買いのような通常の注文が外れ値の側に振り分けられるので、規則の判定を機械的に除外の根拠にするわけにはいかない。
A は由来を確かめずに記録の誤りと決めつけており、B は規則の判定をそのまま除外の基準にしている点で誤りである。
C は打ち切り（ウィンザー化）に似た操作だが、置き換える値も割合も根拠がなく、章で述べた「上位 1% を 99 パーセンタイルで置き換える」のような明示的な基準になっていない。

### 問5

**解答**：A

注文単位の平均では、注文の多い顧客の注文がその件数分だけ効く。
月に何度も注文する顧客は一件あたりの金額も大きい傾向があるため、注文単位の平均は顧客単位の平均より高くなる。
B について、顧客単位の平均も同じ orders テーブルの customer_id で集計しており、除外の有無で説明される差ではない。
C の丸め誤差は 250 円もの差を生まない。
D は中央値や幾何平均とは無関係で、どちらも算術平均である。
