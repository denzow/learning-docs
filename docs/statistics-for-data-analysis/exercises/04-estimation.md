# 第4章 演習問題

対象章：[第4章 標本と推定](../04-estimation.md)（[読み上げ原稿](../audio-scripts/04-estimation.md)）

## 問題

### 問1

先週の注文 2,800 件を集計したところ、注文金額の標準偏差は 2,798 円、平均の標準誤差は約 53 円だった。
来月も同じ集計を続けて注文が 4 倍の 11,200 件になったとき、二つの値はどうなると考えられるか。

- A. 標準偏差は約 1,400 円に縮み、標準誤差は約 53 円のまま変わらない
- B. 標準偏差は約 2,800 円のまま変わらず、標準誤差は約 26 円に縮む
- C. 標準偏差も標準誤差も約 4 分の 1 に縮む
- D. 標準偏差も標準誤差も約 2 分の 1 に縮む

### 問2

注文金額の分布は右に大きく歪んでいる。
この注文金額について、標本平均の信頼区間を正規分布や t 分布で作ってよい根拠と、その根拠が効く条件の組み合わせとして適切なものはどれか。

- A. 中心極限定理により、独立な観測の平均の分布は n が大きいほど正規分布に近づく。歪んだ分布では n が数百程度は要る
- B. 大数の法則により、n が大きいほど標本平均は母平均に一致する。n が 30 を超えれば分布の形は問わない
- C. 対数変換により、注文金額そのものが正規分布に従うようになる。変換後であれば n の大小は問わない
- D. 中心極限定理により、n が大きいほど注文金額そのものの分布が正規分布に近づく。歪んだ分布では n が数百程度は要る

### 問3

注文金額の平均について、95% 信頼区間が 3,098 円から 3,305 円と求まった。
この区間の意味として正しい記述はどれか。

- A. 母平均が 3,098 円から 3,305 円の間にある確率は 95% である
- B. 注文の 95% は金額が 3,098 円から 3,305 円の間に入る
- C. 同じ手続きで標本を取り直して区間を作ることを繰り返すと、そのうち 95% の区間が母平均を含む
- D. 次の週の標本平均が 3,098 円から 3,305 円の間に入る確率は 95% である

### 問4

新しく作ったランディングページのセッションが 200 件あり、そのうち 3 件が購入に至った。
コンバージョン率の 95% 信頼区間を報告するにあたり、Wald 区間ではなく Wilson 区間を選ぶ理由として適切なものはどれか。

- A. Wilson 区間は t 分布を使うため、標本が小さいときの補正が入るから
- B. Wald 区間は比率が 0 に近く n が小さいと下限が負になるなど破綻するが、Wilson 区間は 0 と 1 の内側に収まる妥当な区間を返すから
- C. Wald 区間は比率の信頼区間ではなく平均の信頼区間の方法であり、比率には使えないから
- D. Wilson 区間のほうが常に幅が狭く、同じデータからより精密な推定ができるから

### 問5

注文金額の中央値に 95% 信頼区間を付けたい。
ブートストラップでこれを行う手続きと、その手続きが成り立つ前提の組み合わせとして正しいものはどれか。

- A. 標本から同じ大きさの標本を非復元抽出で作り直して中央値を計算することを繰り返す。前提は元の分布が正規分布であること
- B. 母集団から新しい標本を何度も取り直して中央値を計算する。前提は母集団の全体にアクセスできること
- C. 中央値の標準誤差を「標準偏差 ÷ √n」で求め、その 1.96 倍を上下に取る。前提は n が 30 以上あること
- D. 標本から同じ大きさの標本を復元抽出で作り直して中央値を計算することを数千回繰り返し、その 2.5 と 97.5 パーセンタイルを取る。前提は標本が母集団の形をよく写しており観測が独立であること

## 解答と解説

### 問1

**解答**：B

標準偏差は注文 1 件の金額がどれだけ散らばるかという母集団の性質を表す値なので、データを増やしても縮まらず、2,800 円前後にとどまる。
標準誤差は平均という推定値のばらつきで、標準偏差 ÷ √n に従うため、n が 4 倍になると √4 で割った 2 分の 1、約 26 円に縮む。
A は二つの値の役割が逆であり、C と D はどちらも縮むとしている点で誤りである。
「標準誤差と中心極限定理」の節で述べた、標準偏差と標準誤差の区別を問う問題である。

### 問2

**解答**：A

中心極限定理は、元の分布の形によらず、独立な観測の「平均」の分布が n とともに正規分布に近づくことを保証する。
シミュレーションでは、注文金額ほど歪んだ分布だと n が 30 でも平均の分布に歪みが残り、正規分布として扱えるのは数百件からだった。
B の大数の法則は標本平均が母平均に近づくことを述べるだけで、分布の形については何も言わない。
C の対数変換は注文金額の分布を正規に近づけるが、平均の信頼区間の根拠ではない（変換後の平均は元の金額の平均と別の量になる）。
D は正規分布に近づくのが「注文金額そのもの」ではなく「平均」である点を取り違えている。

### 問3

**解答**：C

信頼区間の 95% は、区間を作る手続きの性質を述べている。
母平均は一つに定まった値で、区間に入るか入らないかのどちらかであり、確率を持つのは標本ごとに変わる区間の側である。
A はこの点を取り違えた、もっとも多い誤解である。
B は注文 1 件の散らばり（標準偏差 2,798 円で、はるかに広い）と平均の推定の誤差を混同している。
D は次の標本平均の予測区間であり、母平均の信頼区間とは別の量である。

### 問4

**解答**：B

Wald 区間は標本の比率から標準誤差を計算するため、200 件中 3 件では下限が負になり、0 件では幅がゼロの区間になってしまう。
Wilson 区間は真の比率を未知数として正規近似の式を解く形で作るため、n が小さくても 0 と 1 の内側に収まる。
A は誤りで、Wilson 区間は t 分布ではなく正規近似を使う。
C も誤りで、Wald 区間は比率の信頼区間の方法である。
D も誤りで、この例では Wilson 区間のほうが広く、目的は幅の狭さではなく妥当さである。

### 問5

**解答**：D

ブートストラップは、手元の標本を母集団の代役にして、復元抽出で標本を作り直し、推定量の標本分布を模擬する方法である。
その前提は、標本が母集団の形をよく写していること（n が十分にあること）と、観測が独立であることで、時系列のように観測が相関するデータには向かない。
A の非復元抽出では元の標本と同じものしか作れず、正規分布の前提も不要である。
B は理想の手続きだが、母集団を取り直せないからこそブートストラップを使う。
C の公式は平均の標準誤差であり、中央値には当てはまらない。
