# 第5章 仮説検定の考え方

商品ページに「この本を買った人はこちらも」というおすすめ枠を出す施策を試し、対照群のコンバージョン率が 3.0%、処置群が 3.3% だったとしよう。
分析者が答えなければならない問いは「この 0.3 ポイントの差は、おすすめ枠の効果と見てよいのか、それとも顧客の割り当てのばらつきで偶然ついた差なのか」である。
第 4 章で見たとおり、標本から計算した比率は標本ごとにばらつく。
だから二つの群の比率が違うという事実だけでは、施策に効果があったとは言えない。

この問いに答える枠組みが**仮説検定**である。
仮説検定は、「差がない」という仮定を置いたうえで、観測された差がその仮定のもとでどれほど起きにくいかを確率で測り、仮定を捨てるかどうかを決める手続きである。
本章では、この手続きを構成する概念（帰無仮説、検定統計量、p 値、有意水準、二種類の過誤、検出力、効果量）を順に導入し、比率の差の検定を Python で手計算して確かめる。
具体的な検定手法の使い分けは第 6 章、A/B テストの運用で起きる多重比較やピーキングの問題は第 8 章で扱う。

## 概念の解説

### 帰無仮説と対立仮説

仮説検定は、検証したい主張をそのまま証明しようとはしない。
代わりに、主張の否定に当たる仮説をいったん真と仮定し、その仮定とデータとの食い違いを測る。
この「差がない」「効果がない」という側の仮説を**帰無仮説**と呼び、記号では H0 と書く。
帰無仮説が否定されたときに採用される側の仮説が**対立仮説**で、H1 と書く。

おすすめ枠の例では、次のように置く。

- **帰無仮説 H0**：処置群と対照群の母集団のコンバージョン率は等しい
- **対立仮説 H1**：処置群と対照群の母集団のコンバージョン率は異なる

帰無仮説の側を仮定するのは、その仮定のもとでは差の分布を具体的に計算できるからである。
「率が等しい」と仮定すれば、二群の差は平均 0 で、標準誤差が標本サイズから決まる分布に従う（第 4 章の中心極限定理）。
対して「率が異なる」という仮定は、どれだけ異なるかを決めないかぎり分布を一つに定められない。
計算できる側に立って、その仮定がデータと矛盾するかを調べる、というのが検定の基本的な構えである。

この構えから、検定の結論は非対称になる。
データが帰無仮説と食い違えば「帰無仮説を棄却する」と言えるが、食い違わなかったときに言えるのは「帰無仮説を棄却できない」までである。
棄却できなかったことは、帰無仮説が正しいことの証拠にはならない。
標本が小さくて差を検出する力が足りなかっただけかもしれないからである。
この点は「検出力と効果量」の節で改めて扱う。

### 検定統計量と p 値

帰無仮説とデータの食い違いを数値にしたものが**検定統計量**である。
比率の差の検定では、観測された差を、帰無仮説のもとでの差の標準誤差で割った値を使う。

```text
z = (処置群の比率 - 対照群の比率) ÷ 標準誤差
標準誤差 = √( p × (1 - p) × (1 ÷ n1 + 1 ÷ n2) )
```

ここで p は二群を合わせた比率で、n1 と n2 は各群のセッション数である。
帰無仮説のもとで二群の率は等しいので、標準誤差の計算には群ごとの率ではなく合わせた率を使う。
この z は、帰無仮説が正しければ標準正規分布に近い分布に従う（第 3 章）。
だから「z がこれほど大きい値になる確率」を正規分布から求められる。

その確率が **p 値**である。
p 値は「帰無仮説が正しいと仮定したとき、観測された値と同じかそれ以上に極端な検定統計量が得られる確率」と定義される。
p 値が小さいほど、観測されたデータは帰無仮説のもとでは起きにくいことになり、帰無仮説を疑う根拠が強まる。

p 値は定義のとおりにしか読めない。
実務で頻繁に見かける次の読み方は、どれも定義と一致しない。

- 「p 値は帰無仮説が正しい確率である」。p 値は帰無仮説を真と仮定したうえでのデータの確率であり、仮説の確率ではない。条件の向きが逆である[^bayes]
- 「p 値が 0.03 なら、効果がある確率は 97% である」。同じ誤りの裏返しで、1 から p 値を引いた値に意味はない
- 「p 値が小さいほど効果が大きい」。p 値は効果の大きさと標本サイズの両方で決まる。小さな効果でも標本が大きければ p 値は小さくなる
- 「p 値が 0.05 を超えたので効果はなかった」。棄却できないことは効果がないことの証明ではない

米国統計学会は 2016 年に p 値の解釈についての声明を出し、これらの誤読を戒めている（参考文献）。
p 値は「帰無仮説とデータの食い違いの度合い」を示す一つの指標であり、それ以上でもそれ以下でもない。

### 有意水準と二種類の過誤

p 値がどれだけ小さければ帰無仮説を棄却するかは、分析の前に決めておく。
その閾値を**有意水準**と呼び、記号では α と書く。
慣例として 0.05 がよく使われるが、この値に理論的な根拠はなく、分野の慣習にすぎない[^fisher]。
p 値が有意水準を下回ったとき、結果は**統計的に有意**であると言う。

閾値を決めて二者択一の判断を下す以上、判断は二通りの間違い方をする。

| | 帰無仮説が実際に正しい | 帰無仮説が実際に誤り |
| --- | --- | --- |
| 棄却する | 第一種の過誤（偽陽性） | 正しい判断 |
| 棄却しない | 正しい判断 | 第二種の過誤（偽陰性） |

**第一種の過誤**は、効果がないのに「効果がある」と判断してしまう誤りである。
有意水準 α は、帰無仮説が正しいときに第一種の過誤を犯す確率そのものである。
α を 0.05 にするとは、「本当は効果のない施策を、20 回に 1 回は効果ありと誤判定することを受け入れる」と決めることに等しい。

**第二種の過誤**は、効果があるのに「効果があるとは言えない」と判断してしまう誤りである。
その確率を β と書く。
β は α のように分析者が直接決められる値ではなく、真の効果の大きさ、標本サイズ、α の三つから決まる。

二つの過誤は片方を減らせばもう片方が増える関係にある。
α を 0.01 に厳しくすれば偽陽性は減るが、同じ標本サイズでは棄却の閾値が遠のくため偽陰性が増える。
どちらの過誤の損失が大きいかは場面によって違う。
おすすめ枠のような可逆な UI 変更なら偽陽性の損失は小さく、決済フローの変更のように失敗の損失が大きい施策なら α を厳しくする理由がある。

### 検出力と効果量

第二種の過誤の確率 β の補数、つまり 1 − β を**検出力**と呼ぶ。
検出力は「実際に効果があるときに、それを統計的に有意として検出できる確率」である。
慣例では 0.8 を目安にすることが多く、これは「本当に効果があっても 5 回に 1 回は見逃す」設計を意味する。

検出力を計算するには、「どのくらいの効果があると想定するか」を決めなければならない。
この想定する効果の大きさが**効果量**である。
比率の差なら「3.0% から 3.3% への改善」のように差そのもので表せるし、標本サイズによらない標準化した指標（比率の差に対する Cohen の h、平均の差に対する Cohen の d など）で表すこともできる。

効果量、標本サイズ、α、検出力の四つは互いに結びついていて、三つを決めれば残りの一つが決まる。
この関係は二つの方向で使う。

- 分析の前に、想定する効果量と α と目標の検出力から、必要な標本サイズを決める
- 分析の後に、実際の標本サイズで想定した効果量をどの程度の確率で検出できたはずかを確かめる

後者は「棄却できなかった」結果を解釈するときに効く。
検出力が 0.3 しかない設計で棄却できなかったのなら、効果があっても 7 割の確率で見逃す状況だったのだから、その結果から「効果がない」とは言えない。
逆に検出力が 0.9 あって棄却できなかったのなら、想定した大きさの効果はなかった可能性が高いと読める。

### 統計的有意と実務的有意

統計的に有意であることと、施策として意味のある大きさの差があることは別である。
p 値は効果の大きさと標本サイズの両方で決まるから、標本さえ大きければどんなに小さな差でも有意になる。
月に数百万セッションが届くストアなら、コンバージョン率の 0.01 ポイントの差でも有意になり得る。
しかし 0.01 ポイントの改善が、おすすめ枠の実装と保守のコストに見合うかは統計とは別の判断である。

だから検定の結果は、p 値だけでなく効果の推定値とその信頼区間を添えて報告する。
「p = 0.015 で有意」とだけ書かれた報告より、「コンバージョン率の差は 0.30 ポイント、95% 信頼区間は 0.06 から 0.54 ポイント」と書かれた報告のほうが、施策の価値を判断する材料になる。
意味のある差の大きさ（この施策なら、たとえば「相対 5% 以上の改善がなければ保守コストに見合わない」）は、分析の前に事業側と決めておく。

### 片側検定と両側検定

対立仮説の立て方には二通りある。
「二群の率は異なる」と置くのが**両側検定**で、「処置群の率のほうが高い」のように向きを決めるのが**片側検定**である。
片側検定は棄却域を片側に集めるため、同じデータでも p 値が両側検定の半分になり、棄却しやすくなる。

その分だけ、片側検定は使う条件が厳しい。
向きを決めてよいのは、逆向きの結果が出ても「効果なし」と同じ扱いをすると分析の前に決められる場合に限る。
おすすめ枠がコンバージョン率を下げる可能性を無視できないなら、両側検定を使う。
データを見てから都合のよい向きを選ぶのは、有意水準を事実上 2 倍にする操作であり、第一種の過誤の確率を宣言した α より大きくしてしまう。
迷ったら両側検定を選ぶのが安全である。

### 信頼区間との対応

仮説検定と第 4 章の信頼区間は、同じ情報を別の形で見せている。
差の 95% 信頼区間が 0 を含まないことと、両側検定で有意水準 0.05 のもとで帰無仮説が棄却されることは、比率の差の検定では近似的に同じ意味を持つ[^ci-test]。

それでも信頼区間のほうが多くを語る。
検定は「差が 0 かどうか」という一点についてしか答えないが、信頼区間は差の大きさがどの範囲にありそうかを示す。
区間が 0 をわずかに含む場合と、0 をまたいで大きく広がる場合では、どちらも「有意でない」が意味は違う。
前者は標本を増やせば有意になりそうな状況で、後者はデータがほとんど何も語っていない状況である。
報告には検定の結果と信頼区間の両方を載せる。

## 具体例

おすすめ枠の A/B テストで、各群に 40,000 セッションを割り当て、対照群で 1,200 件、処置群で 1,320 件の購入があったとする。
コンバージョン率は対照群 3.00%、処置群 3.30% で、相対で 10% の改善に見える。
この差を検定する。

### 比率の差の z 検定を手計算する

まず、群ごとのセッション数とコンバージョン数を分析基盤から取り出す。

```sql
SELECT
    a.variant,
    COUNT(*)                                        AS sessions,
    SUM(CASE WHEN s.converted THEN 1 ELSE 0 END)    AS conversions
FROM sessions AS s
JOIN experiment_assignments AS a
    ON a.customer_id = s.customer_id
   AND a.experiment_id = 'recommend_box_v1'
WHERE s.visited_at >= a.assigned_at
GROUP BY a.variant;
```

```text
variant    sessions  conversions
control       40000         1200
treatment     40000         1320
```

この集計を Python に渡し、検定統計量を定義どおりに計算する。

```python
import numpy as np
from scipy import stats

n_c, x_c = 40000, 1200   # 対照群
n_t, x_t = 40000, 1320   # 処置群

p_c = x_c / n_c          # 0.0300
p_t = x_t / n_t          # 0.0330
diff = p_t - p_c         # 0.0030

# 帰無仮説のもとでは二群の率は等しいので、合わせた率で標準誤差を計算する
p_pool = (x_c + x_t) / (n_c + n_t)
se_null = np.sqrt(p_pool * (1 - p_pool) * (1 / n_c + 1 / n_t))
z = diff / se_null
p_value = 2 * (1 - stats.norm.cdf(abs(z)))   # 両側検定

# 差の信頼区間は群ごとの率から標準誤差を計算する
se_diff = np.sqrt(p_c * (1 - p_c) / n_c + p_t * (1 - p_t) / n_t)
ci_low, ci_high = diff - 1.96 * se_diff, diff + 1.96 * se_diff

print(f"z = {z:.2f}, p = {p_value:.3f}")
print(f"差 = {diff:.4f}, 95% CI = ({ci_low:.4f}, {ci_high:.4f})")
```

```text
z = 2.43, p = 0.015
差 = 0.0030, 95% CI = (0.0006, 0.0054)
```

z が 2.43 で、p 値は 0.015 である。
有意水準を 0.05 と決めていたなら、帰無仮説「二群のコンバージョン率は等しい」を棄却する。
差の 95% 信頼区間は 0.06 ポイントから 0.54 ポイントで、0 を含まない。
検定と信頼区間が同じ結論を指している。

statsmodels には同じ検定を一行で行う関数がある。
手計算と結果が一致することを確かめておくと、関数の引数の意味を取り違えていないかの確認になる。

```python
from statsmodels.stats.proportion import proportions_ztest

z, p_value = proportions_ztest([x_t, x_c], [n_t, n_c])
print(f"z = {z:.2f}, p = {p_value:.3f}")   # z = 2.43, p = 0.015
```

報告するときは、p 値と効果の大きさを並べて書く。
「処置群のコンバージョン率は 3.30% で対照群の 3.00% より 0.30 ポイント高く、この差は有意水準 5% で統計的に有意だった（z = 2.43、p = 0.015）。差の 95% 信頼区間は 0.06 から 0.54 ポイントである」という形になる。
相対で 10% の改善は事前に決めた意味のある差（相対 5%）を上回っているが、信頼区間の下限は相対 2% に相当する。
効果はありそうだが、その大きさにはまだ幅がある、というのがこのデータから言えることである。

### 標本が小さいときに起きること

同じ 3.00% と 3.30% の率が、各群 5,000 セッション（対照群 150 件、処置群 165 件）で観測された場合を計算する。

```python
n_c, x_c = 5000, 150
n_t, x_t = 5000, 165
# 以降は上と同じ計算
```

```text
z = 0.86, p = 0.390
差 = 0.0030, 95% CI = (-0.0038, 0.0098)
```

観測された率の差は先ほどとまったく同じ 0.30 ポイントなのに、p 値は 0.39 で、帰無仮説を棄却できない。
標本が小さいと標準誤差が大きくなり、同じ差でも偶然の範囲に収まってしまうからである。
信頼区間は −0.38 ポイントから +0.98 ポイントまで広がり、率が下がっている可能性も相対 30% 以上改善している可能性も残っている。

この結果を「おすすめ枠に効果はなかった」と報告するのは誤りである。
言えるのは「この標本サイズでは、効果の有無を判断できなかった」までであり、信頼区間の幅がそのことを示している。
この状況を避けるには、テストを始める前に必要な標本サイズを見積もっておく。

### 検出力と必要な標本サイズ

3.00% から 3.30% への改善を想定したとき、各群 40,000 セッションの設計にどれだけの検出力があったかを計算する。
statsmodels の検出力の計算は標準化した効果量（Cohen の h）を受け取るので、まず率の組から h を求める。

```python
from statsmodels.stats.proportion import proportion_effectsize
from statsmodels.stats.power import NormalIndPower

h = proportion_effectsize(0.033, 0.030)   # Cohen の h。約 0.017
analysis = NormalIndPower()

for n in [5000, 20000, 40000]:
    power = analysis.power(effect_size=h, nobs1=n, alpha=0.05,
                           alternative="two-sided")
    print(f"各群 {n:>6} セッション: 検出力 {power:.2f}")

n_required = analysis.solve_power(effect_size=h, power=0.8, alpha=0.05,
                                  alternative="two-sided")
print(f"検出力 0.8 に必要な各群のセッション数: {n_required:.0f}")
```

```text
各群   5000 セッション: 検出力 0.14
各群  20000 セッション: 検出力 0.40
各群  40000 セッション: 検出力 0.68
検出力 0.8 に必要な各群のセッション数: 53182
```

各群 5,000 セッションの設計では検出力が 0.14 しかない。
想定した大きさの効果が本当にあっても、86% の確率で「有意でない」という結果になる設計だったのだから、先ほどの p = 0.39 は驚くべき結果ではない。
各群 40,000 でも検出力は 0.68 で、慣例の 0.8 には届かない。
0.8 にするには各群 53,000 セッション余りが要る。
日次のセッション数から、この規模を集めるのに何日かかるかを逆算して実施期間を決める。

必要な標本サイズは、想定する効果量が小さくなると急速に増える。
相対 5% の改善（3.00% から 3.15%）を検出力 0.8 で捉えるには、各群 20 万セッション余りが要る。
「小さな改善も見逃したくない」という要望には、それに見合う標本サイズという対価がつく。
実施期間の決め方と、テストを途中で何度も見ることの問題は第 8 章で扱う。

[^bayes]: 「データを見たうえで仮説が正しい確率」を求めるには、仮説の事前の確率を置いて計算するベイズ統計の枠組みが要る。本教材ではベイズ統計を扱わないが、p 値がその確率ではないという点だけは押さえておく。
[^fisher]: 0.05 という水準は、R. A. Fisher が 1925 年の著書で便宜的に用いたことに由来する。仮説検定の枠組み自体は、Fisher の有意性検定と、Neyman と Pearson が定式化した二種類の過誤に基づく判断の枠組みが、後に一つの手続きとして教えられるようになったものである。
[^ci-test]: 完全に一致しないのは、検定統計量の標準誤差を二群を合わせた率から計算するのに対し、信頼区間の標準誤差は群ごとの率から計算するためである。二群の率が近いときは両者はほとんど同じ値になる。
