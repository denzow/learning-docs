# 第6章 代表的な検定手法

第 5 章では、帰無仮説と p 値、二種類の過誤、検出力という検定の考え方を学び、コンバージョン率の差を z 検定で確かめた。
しかし実務で比べたいものは比率だけではない。
デバイスごとの注文金額の平均、地域ごとのデバイス構成、施策の前後での同じ顧客の購入額など、比べる量の型も群の数も場面によって変わる。
それぞれに合った検定統計量と、その帰無分布を与えるのが個々の検定手法である。

本章では、検定手法を選ぶための三つの問いを立て、その答えごとに使う手法を対応づける。
そのうえで、t 検定、カイ二乗検定、Mann-Whitney の U 検定、分散分析の四つを、何を帰無仮説とし、どんな前提に依存するかという観点でそろえて解説する。
手法の一覧は暗記の対象ではなく、問いとデータの型から機械的に導けるものとして扱う。
章の後半では、前提が崩れたときに結果がどう動くかを、デバイス別の注文金額の比較で確かめる。

## 概念の解説

### 検定を選ぶ三つの問い

検定手法は、分析の問いとデータの型から決まる。
決め手になるのは次の三つである。

- **比べる量の型**：注文金額のような量的な値か、コンバージョンの有無や地域のようなカテゴリか。量的な値でも、分布が大きく歪んでいるか外れ値が多いなら、順位に基づく手法を候補に入れる
- **群の数**：一つの群を基準値と比べるのか、二つの群を比べるのか、三つ以上の群を比べるのか
- **対応の有無**：二つの群が別々の対象から得られた独立な標本か、同じ対象を二回測った対応のある標本か。施策の前後で同じ顧客の購入額を比べる場面が後者である

この三つの答えから、代表的な手法は次の表のように決まる。

| 比べる量 | 群の数 | 対応 | 手法 |
| --- | --- | --- | --- |
| 量的な値の平均 | 1 | なし | 一標本 t 検定 |
| 量的な値の平均 | 2 | なし | Welch の t 検定 |
| 量的な値の平均 | 2 | あり | 対応のある t 検定 |
| 量的な値の平均 | 3 以上 | なし | 一元配置分散分析 |
| 量的な値の分布（順位） | 2 | なし | Mann-Whitney の U 検定 |
| 量的な値の分布（順位） | 2 | あり | Wilcoxon の符号付き順位検定 |
| 量的な値の分布（順位） | 3 以上 | なし | Kruskal-Wallis 検定 |
| 比率 | 2 | なし | 比率の差の z 検定、2×2 のカイ二乗検定 |
| カテゴリの分布 | 1 | なし | カイ二乗適合度検定 |
| カテゴリ同士の関係 | 2 以上 | なし | カイ二乗独立性検定 |

表の各行は、第 5 章の枠組みの中で検定統計量と帰無分布の組を一つ定めたものにすぎない。
どの行でも、帰無仮説のもとで統計量が従う分布を求め、観測された統計量がその分布のどこに落ちるかで p 値を出す、という手順は同じである。
違うのは、何を統計量にするかと、その分布を導くのにどんな前提を置くかである。

### 平均を比べる t 検定

**t 検定**は、量的な値の平均を比べる検定である。
統計量は「平均の差 ÷ 差の標準誤差」で、帰無仮説（平均に差がない）のもとで t 分布に従う。
第 4 章で平均の信頼区間を作ったときと同じ量で、標準誤差を標本の標準偏差から見積もるために、正規分布ではなく t 分布を使う。

二つの独立な群を比べる t 検定には、二つの群の分散が等しいと仮定する Student の方法と、仮定しない **Welch の t 検定**がある。
Welch の方法は、群ごとの分散を別々に見積もって標準誤差を作り、自由度を分散と標本サイズから調整する[^welch]。
分散が等しいときには二つの方法の結果はほぼ一致し、等しくないときには Welch の方法だけが正しい大きさの第一種の過誤を保つ。
だから分散の等しさを事前に検定してから方法を選ぶ必要はなく、独立な二群の比較では Welch の方法を既定にしてよい。

**対応のある t 検定**は、同じ対象を二回測ったデータに使う。
施策の前後で同じ顧客の月間購入額を比べるとき、顧客ごとに「後 − 前」の差を取り、その差の平均がゼロかどうかを一標本の t 検定で調べる。
顧客ごとの購入額の個人差は差を取った時点で消えるため、独立な二群として扱うよりも小さな変化を検出できる。
対応のあるデータを独立な二群の検定にかけるのは、この利点を捨てるだけでなく、二回の測定が独立だという誤った前提を置くことにもなる。

### 比率とカテゴリを比べるカイ二乗検定

**カイ二乗検定**は、カテゴリごとの度数を、帰無仮説のもとで期待される度数と比べる検定である。
統計量は、各セルについて「(観測度数 − 期待度数)² ÷ 期待度数」を計算して合計したもので、帰無仮説のもとでカイ二乗分布に従う。
観測が期待からどのセルでも離れていなければ統計量は小さく、どこかのセルで大きく離れていれば統計量は大きくなる。

用途は二つある。
**独立性の検定**は、地域とデバイスのような二つのカテゴリ変数の間に関係がないかを調べる。
帰無仮説は「二つの変数は独立である」で、期待度数は「行の合計 × 列の合計 ÷ 総数」で求め、自由度は「(行数 − 1) × (列数 − 1)」になる。
**適合度検定**は、一つのカテゴリ変数の分布が、あらかじめ定めた比率に従っているかを調べる。
昨年のデバイス構成が 6 対 4 だったとして、今年の注文がその比率から離れたかを問う場面がこれにあたる。

第 5 章の比率の差の z 検定は、2×2 のカイ二乗検定と同じ検定である。
2 群のコンバージョンの有無を 2×2 の分割表に並べてカイ二乗検定にかけると、統計量は z 統計量の二乗に一致し、p 値も一致する。
だから比率の比較は、群が二つなら z 検定でも 2×2 のカイ二乗検定でもよく、群が三つ以上になったら 2×k のカイ二乗検定に広げればよい。

カイ二乗分布への近似は、期待度数が小さいセルがあると崩れる。
目安として期待度数が 5 未満のセルがあるなら、Fisher の正確検定のように近似に頼らない方法に切り替える。
逆に総数が大きいときは、実務上は無視できるほど小さな偏りでも統計量が大きくなり、有意になる。
関係の強さは p 値ではなく **Cramér の V**（統計量を「総数 × (行数と列数の小さいほう − 1)」で割って平方根を取った値、0 から 1 の範囲）のような効果量で別に見る。

### 順位に基づく Mann-Whitney の U 検定

**Mann-Whitney の U 検定**は、二つの群の値を混ぜて順位を付け、一方の群の順位がもう一方より系統的に高いかを調べる検定である。
統計量 U は、一方の群から一つ、もう一方の群から一つ取り出したとき、前者が後者より大きい組の数で、帰無仮説のもとでの分布は値の分布の形に依存しない。
U を二つの群の標本サイズの積で割ると、「一方の群の値がもう一方の値を上回る確率」の推定値になり、0.5 が差のない状態を表す。

この検定の帰無仮説は「一方の値がもう一方を上回る確率が 0.5 である」であって、「中央値が等しい」ではない。
二つの群の分布の形が同じで位置だけが違う、という条件が成り立つときに限り、U 検定の結果を中央値の差として解釈できる。
形が違う分布（一方だけ裾が長いなど）では、中央値が等しくても検定が有意になりうる。
順位に基づくため、外れ値が一つあっても順位が一つずれるだけで、平均を比べる t 検定のように統計量が大きく引かれることはない。

対応のあるデータには **Wilcoxon の符号付き順位検定**を使う。
対ごとの差を取り、差の絶対値に順位を付けて、正の差と負の差の順位の合計を比べる。
対応のある t 検定の順位版にあたる。

### 三群以上を比べる分散分析

三つ以上の群の平均を比べるには、**一元配置分散分析**を使う。
統計量 F は、群の平均のばらつき（群間分散）を群の中でのばらつき（群内分散）で割った比で、帰無仮説「すべての群の平均が等しい」のもとで F 分布に従う。
群の平均が互いに離れているほど群間分散が大きくなり、F が大きくなる。
順位版は **Kruskal-Wallis 検定**である。

三群を t 検定で二群ずつ三回比べる方法を採らないのは、検定を繰り返すたびに第一種の過誤が積み上がるからである。
有意水準 5% の検定を三回行えば、どこかで誤って棄却する確率は 14% を超える。
分散分析はまず「どこかに差があるか」を一度の検定で判定し、どの群の間に差があるかは、過誤の積み上がりを補正した事後の比較で調べる。
検定の繰り返しに伴う補正は第 8 章の多重比較で扱う。

### 前提と頑健性

t 検定と分散分析は、値が正規分布に従うことを前提にすると説明されることが多い。
しかし実際に必要なのは、個々の値ではなく、平均の標本分布が正規分布に近いことである。
第 4 章の中心極限定理により、標本サイズが大きければ、注文金額のように右に歪んだ分布でも平均の標本分布は正規分布に近づく。
だから数千件の注文を比べる t 検定は、値の分布が歪んでいても第一種の過誤の大きさをほぼ保つ。

正規性を事前の検定（Shapiro-Wilk 検定など）で確かめる手順は、この理由から役に立たないことが多い。
標本が大きいときは、実務に影響しない小さな逸脱でも正規性検定は棄却され、標本が小さいときは、大きな逸脱があっても検出できない。
どちらの場合も、検定の結果は t 検定を使ってよいかの判断材料にならない。
分布の形はヒストグラムや第 2 章の要約統計量で直接見るほうがよい。

標本サイズが大きくても、t 検定が外れ値に弱いことは変わらない。
t 検定は平均を比べる検定であり、平均は一件の極端な値に引かれるからである。
少数の高額注文が一方の群に入るだけで、平均の差も p 値も動く。
外れ値の影響を受けにくい比較が要るなら、順位に基づく U 検定を使うか、注文金額の対数を取ってから t 検定にかける。
対数を取った平均の差は、元の尺度では「幾何平均の比」にあたり（対数正規分布に近い分布では中央値の比とほぼ同じになる）、差の信頼区間を指数に戻せば「デスクトップの注文はモバイルの何倍か」という比の区間になる。

どの手法を使う場合も、報告するのは p 値だけではない。
差の推定値とその信頼区間を並べることで、第 5 章で述べた統計的有意と実務的有意の区別を読み手に判断させられる。
p 値が小さいのは「差がゼロではない」と言えるだけであり、差がどれだけの大きさかは信頼区間が示す。

## 具体例

書籍のオンラインストアで、モバイルとデスクトップのどちらから注文した顧客のほうが高額の注文をするか、という問いを扱う。
第 2 章で見たとおり注文金額は右に歪んでおり、比較の前提を考える題材に向く。
さらに、地域とデバイスに関係があるかをカイ二乗検定で調べる。

### デバイス別の注文金額を比べる

直近 2 週間の注文を、デバイスと金額の組で取り出す。

```sql
SELECT
    device,
    amount
FROM orders
WHERE ordered_at >= CURRENT_DATE - INTERVAL '14' DAY;
```

まず群ごとの要約統計量を確かめる。

```python
import pandas as pd
from scipy import stats

df = pd.read_sql(query, conn)
mobile = df.loc[df["device"] == "mobile", "amount"]
desktop = df.loc[df["device"] == "desktop", "amount"]

print(df.groupby("device")["amount"].agg(["count", "mean", "median", "std"]).round(0))
#          count  mean  median   std
# desktop   2000  3613    2685  3256
# mobile    3600  3111    2350  2730
```

平均も中央値もデスクトップのほうが高い。
標準偏差が群で違い、分布は右に歪んでいる。
標本サイズは 2,000 件と 3,600 件で、平均の標本分布は正規分布に近いと見なせるため、Welch の t 検定を使う。

```python
result = stats.ttest_ind(desktop, mobile, equal_var=False)
print(result.statistic, result.pvalue, result.df)
# 5.85  5.4e-09  3563.3
print(result.confidence_interval(confidence_level=0.95))
# ConfidenceInterval(low=333.8, high=670.5)
```

帰無仮説「平均に差がない」のもとで、観測された差 502 円より大きな差が出る確率は 10 億分の 5 程度であり、差は有意である。
差の 95% 信頼区間は 334 円から 670 円で、デスクトップの注文は平均して数百円高いと言える。
分散が等しいと仮定する Student の方法を使うと t 統計量は 6.15 になり、群のサイズと分散が違うぶん検定がわずかに甘くなる。

### 同じ比較を順位で行う

注文金額の歪みが気になるなら、Mann-Whitney の U 検定でも同じ問いに答えられる。

```python
u = stats.mannwhitneyu(desktop, mobile, alternative="two-sided")
print(u.statistic, u.pvalue)
# 3987122.5  2.4e-11
print(u.statistic / (len(desktop) * len(mobile)))
# 0.554
```

デスクトップの注文一件とモバイルの注文一件を無作為に取り出したとき、デスクトップのほうが高額である確率の推定値は 0.554 である。
0.5 からの隔たりは小さいが、標本が大きいので有意になる。
二つの群の分布の形はほぼ同じ（どちらも同じように右に歪んでいる）ため、この結果は「デスクトップの注文金額は分布全体として少し高い側に寄っている」と解釈できる。

比の形で差を報告したければ、対数を取ってから t 検定にかける。

```python
import numpy as np

log_result = stats.ttest_ind(np.log(desktop), np.log(mobile), equal_var=False)
print(np.exp(log_result.confidence_interval(confidence_level=0.95)))
# [1.109, 1.206]
```

デスクトップの注文金額は、幾何平均で見てモバイルの 1.11 倍から 1.21 倍の範囲にあると推定できる。
平均の差の 334 円から 670 円という区間は算術平均の差、比の 1.11 倍から 1.21 倍という区間は幾何平均の比であり、同じ量の言い換えではないが、どちらも二群の違いを表す。
報告先が金額で考えるか比率で考えるかに合わせて選べばよい。

### 標本が小さい日の比較で外れ値が効く

同じ問いを、キャンペーン初日の午前中だけ、デバイスごとに 60 件ずつの注文で答えようとしたとしよう。
要約統計量は、モバイルの平均 2,930 円と中央値 2,245 円、デスクトップの平均 3,766 円と中央値 2,955 円である。

```python
print(stats.ttest_ind(desktop_am, mobile_am, equal_var=False).pvalue)
# 0.100
print(stats.mannwhitneyu(desktop_am, mobile_am, alternative="two-sided").pvalue)
# 0.027
```

Welch の t 検定では有意にならず、U 検定では有意になる。
差の方向は同じでも、標本が 60 件だと右に歪んだ分布での平均の標準誤差が大きく、t 検定は差を検出できない。
順位で比べる U 検定は歪みの影響を受けにくいため、小さな標本でも同じ差を検出しやすい。

ここに、全集（48,000 円と 52,000 円）を買った 2 件の注文がデスクトップ側に加わると、結果が動く。

```python
desktop_am2 = pd.concat([desktop_am, pd.Series([48000, 52000])])
print(desktop_am2.mean(), desktop_am2.median())
# 5257  3030
print(stats.ttest_ind(desktop_am2, mobile_am, equal_var=False).pvalue)
# 0.048
print(stats.mannwhitneyu(desktop_am2, mobile_am, alternative="two-sided").pvalue)
# 0.014
```

平均は 3,766 円から 5,257 円に跳ね上がり、t 検定の p 値は 0.100 から 0.048 に変わって 5% で有意になる。
中央値は 2,955 円から 3,030 円までしか動かず、U 検定の p 値の変化も小さい。
2 件の注文で有意かどうかが入れ替わる t 検定の結果を「デスクトップの注文は高額である」の根拠にするわけにはいかない。
標本が小さく外れ値の影響が大きい場面では、順位に基づく検定か対数変換後の検定を使い、どの検定でも差の推定値と信頼区間を添えて報告する。

### 地域とデバイスの独立性を調べる

次に、注文のデバイス構成が地域によって違うかを調べる。
直近 2 週間の注文を、顧客の地域とデバイスでクロス集計する。

```sql
SELECT
    c.region,
    o.device,
    COUNT(*) AS order_count
FROM orders AS o
JOIN customers AS c ON c.customer_id = o.customer_id
WHERE o.ordered_at >= CURRENT_DATE - INTERVAL '14' DAY
GROUP BY c.region, o.device;
```

集計結果を分割表に並べる。

| 地域 | mobile | desktop | 合計 | mobile の割合 |
| --- | --- | --- | --- | --- |
| kanto | 1,520 | 880 | 2,400 | 63.3% |
| kansai | 880 | 560 | 1,440 | 61.1% |
| other | 1,200 | 560 | 1,760 | 68.2% |
| 合計 | 3,600 | 2,000 | 5,600 | 64.3% |

モバイルの割合は地域によって 61% から 68% の間で違う。
この違いが偶然の範囲かを、独立性のカイ二乗検定で調べる。

```python
table = pd.DataFrame(
    {"mobile": [1520, 880, 1200], "desktop": [880, 560, 560]},
    index=["kanto", "kansai", "other"],
)
chi2, p, dof, expected = stats.chi2_contingency(table)
print(chi2, p, dof)
# 18.9  7.8e-05  2
print(pd.DataFrame(expected, index=table.index, columns=table.columns).round(1))
#         mobile  desktop
# kanto   1542.9    857.1
# kansai   925.7    514.3
# other   1131.4    628.6
```

期待度数は、地域とデバイスが独立なら各セルに入るはずの件数で、どのセルも 5 を大きく超えている。
自由度 2 のカイ二乗分布で統計量 18.9 に対応する p 値は 0.0001 未満であり、地域とデバイスは独立ではない。
期待度数との差を見ると、関東と関西ではデスクトップが期待より多く、その他の地域ではモバイルが期待より多い。

関係の強さは別に見る。

```python
n = table.values.sum()
cramers_v = np.sqrt(chi2 / (n * (min(table.shape) - 1)))
print(cramers_v)
# 0.058
```

Cramér の V は 0.06 で、関係はごく弱い。
5,600 件という総数があるため、モバイルの割合が地域間で数ポイント違うだけで検定は有意になる。
「地域とデバイスに関係がある」という結論は正しいが、その関係はデバイス別の施策を地域で分けるほどの大きさではない。
p 値だけを報告すれば「地域によってデバイスの使われ方が大きく違う」と読まれかねないので、割合の表と効果量を必ず添える。

同じ関数で 2×2 の表を検定すれば、比率の差の検定になる。
ただし 2×2 の表には既定で Yates の連続性補正がかかるので、第 5 章の z 検定と一致させるには correction=False を指定する。
コンバージョンの有無を対照群と処置群で数えた表（第 5 章の例と同じ、それぞれ 40,000 セッション中の 1,200 件と 1,320 件）を渡すと、統計量 5.90 と p 値 0.015 が返る。
統計量の平方根 2.43 が第 5 章の z 統計量にあたり、p 値も一致する。

適合度の検定も同じ集計から行える。
昨年のデバイス構成が 6 対 4 だったとして、今年の 3,600 件対 2,000 件（64.3% 対 35.7%）がそこから離れたかを調べる。

```python
observed = [3600, 2000]
expected = [0.6 * 5600, 0.4 * 5600]
print(stats.chisquare(observed, expected))
# statistic=42.9, pvalue=5.9e-11
```

モバイルの割合は 4 ポイント上がっており、5,600 件の標本ではこの変化は偶然では説明できない。
ここでも、有意かどうかとは別に、4 ポイントという変化の大きさを報告する。
