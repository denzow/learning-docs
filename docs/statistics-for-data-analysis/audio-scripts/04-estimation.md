対象章：[第4章 標本と推定](../04-estimation.md)（[演習問題](../exercises/04-estimation.md)）

第4章、標本と推定。この章では、標本から母集団の値を推定するとき、その推定がどれだけ不確かなのかを測る道具を学びます。推定値のばらつきを表す標本分布と標準誤差、歪んだ分布でも平均を正規分布で扱えるようにする中心極限定理、不確かさを幅で示す信頼区間、そして公式に頼らずに不確かさを求めるブートストラップです。第5章で学ぶ仮説検定は、この章の道具の上に載っています。

まず、なぜ推定という考え方が要るのかを確認します。第2章で、先週の注文金額を集計すると平均は3,202円でした。しかしこの数字が答えているのは、先週の注文はいくらだったか、という問いです。分析者が本当に知りたいのは、この店の注文金額はどれくらいか、という問いであることが多いでしょう。来週の注文はまだ観測していません。だから先週の2,800件は、第1章で述べたとおり、店の注文金額という母集団から取り出した一つの標本にすぎないのです。別の週を取れば、平均は3,150円にも3,260円にもなるでしょう。そのどれもが間違いではありません。

ここで用語を三つ押さえます。母集団を特徴づける値、たとえば母集団の注文金額の平均や、母集団のコンバージョン率を、母数と呼びます。母数は一つに定まっていますが、母集団を全部は観測できないので、直接には分かりません。その母数を標本から見積もるために計算する統計量が推定量で、計算して得た一つの値が推定値です。標本の平均で母平均を見積もるのが典型で、一つの値で答えるこの形を点推定と呼びます。先週の平均3,202円は、母平均の点推定値です。

点推定の弱点は、その値が標本とともに揺れることを表せないところにあります。同じ手続きで別の標本を取れば、推定値は別の値になります。標本を取り直すたびに推定値がどう散らばるかを表す分布を、標本分布と呼びます。標本分布が狭ければ推定値は信頼できますし、広ければ一つの推定値から母数について言えることは少なくなります。ただし、標本分布そのものを観測することはできません。手元にあるのは一つの標本で、標本を何百回も取り直す予算はないからです。だから標本分布は、理論から導くか、手元の標本から模擬するかのどちらかで知ることになります。前者が標準誤差と中心極限定理、後者がブートストラップです。

標本分布の広さを一つの数で表したものが、標準誤差です。標本分布の標準偏差、つまり推定値のばらつきの大きさが標準誤差です。標本平均の標準誤差は、母集団の標準偏差をnの平方根で割ったものになります。母集団の標準偏差は分からないので、実際には標本の標準偏差で置き換えます。先週の注文金額なら、標準偏差2,798円を2,800の平方根で割った、約53円が標準誤差です。

ここで、標準偏差と標準誤差を区別しておきます。標準偏差は注文1件の金額がどれだけ散らばるかを表します。これは母集団の性質なので、データを増やしても縮まりません。一方、標準誤差は平均という推定値がどれだけ散らばるかを表し、データを増やすとnの平方根に反比例して縮みます。注文金額のばらつきは2,800円、平均の推定の誤差は53円。この二つは、同じ標本から出てくる別の量です。

次に、標本分布の形の話です。注文金額の分布は右に歪んでいて、正規分布とは似ていません。それでも平均の標本分布については、中心極限定理が成り立ちます。元の分布がどんな形であっても、独立な観測の平均の分布は、nが大きくなるにつれて正規分布に近づく、という定理です。

この定理の効き方は、シミュレーションで確かめられます。注文金額と同じ形の対数正規分布からn件を取って平均を出す操作を1万回繰り返し、平均の分布を調べました。平均の標準偏差は、標準偏差をnの平方根で割った公式に、どのnでも一致します。一方で、分布の歪みはnが増えるにつれて減っていきますが、nが30でもまだ歪みが残り、300でようやく正規分布に近い形になります。教科書にある、nが30あれば十分という目安は、元の分布が左右対称に近い場合の話です。注文金額ほど歪んだ分布では、正規分布として扱えるのは数百件から先だと考えておくのが安全です。

では、信頼区間に進みます。点推定に不確かさの幅を添えたものが区間推定で、その幅を信頼区間と呼びます。平均の標本分布が正規分布に近いなら、第3章で学んだ68、95、99.7のルールから、推定値の上下に標準誤差の1.96倍を取った区間が、95パーセント信頼区間になります。ただし、標準誤差の計算に標本の標準偏差を使う分だけ、この区間は少し広げる必要があります。その補正を担うのがt分布で、1.96の代わりに、自由度nマイナス1のt分布の97.5パーセンタイルを使います。nが30なら2.045、nが10なら2.262で、nが数百を超えれば1.96とほとんど変わりません。平均の信頼区間には常にt分布を使う、と決めておけば、使い分けの手間がなくなります。

比率の信頼区間には、少し別の事情があります。コンバージョンのように結果が0か1の値なら、標準誤差は比率pだけから、pかける1マイナスpをnで割った平方根と決まります。この標準誤差に標本の比率を入れて1.96倍した区間が、ワルド区間です。簡単ですが、比率が0や1に近いか、nが小さいと破綻します。コンバージョンが200セッション中3件なら下限が負になり、0件なら幅がゼロの区間になってしまいます。

この破綻を避けるのが、ウィルソン区間です。ワルド区間が標本の比率で標準誤差を決めるのに対して、ウィルソン区間は、真の比率がpだとしたら観測した比率は妥当な範囲にあるか、という式をpについて解いて区間を作ります。その結果、nが小さくても0と1の内側に収まります。nが大きく比率が中程度ならワルド区間と一致するので、実務ではウィルソン区間を既定にしてよいでしょう。

信頼区間の意味は、言葉の上で誤解されやすいので、ここで確認しておきます。95パーセント信頼区間は、母平均がこの区間に入る確率が95パーセント、という意味ではありません。母平均は一つに定まった値で、入るか入らないかのどちらかです。確率を持つのは、区間の側です。正しくは、同じ手続きで標本を取り直して区間を作ることを繰り返せば、そのうち95パーセントの区間が母平均を含む、という手続きの性質を述べています。手元の区間がその95パーセントに入っているかは分かりませんが、当たりやすい手続きで作った区間である、というのが95パーセント信頼の中身です。

この95パーセントという値も、前提が崩れれば下がります。nが30の注文金額でt分布の区間を作る操作を2万回模擬すると、母平均を含んだのは91パーセントにとどまりました。右に歪んだ分布では、小さい標本の平均が母平均を下回りやすく、区間もそれに引きずられるためです。nが300では94.5パーセントまで回復します。信頼区間の幅と同じくらい、その前提が成り立つnかどうかを気にかける必要があります。

次に、ブートストラップです。平均と比率には標準誤差の公式がありました。しかし中央値や、二つの平均の比のような推定量には、簡単な公式がありません。公式の代わりに、計算機で標本分布を作るのがブートストラップです。手続きは単純です。手元の標本から、同じ大きさの標本を復元抽出、つまり同じ観測を何度でも選んでよい抽出で作り、推定量を計算します。これを数千回繰り返すと、推定値の散らばりが得られます。その散らばりの2.5パーセンタイルと97.5パーセンタイルを取れば95パーセント信頼区間になり、標準偏差を取れば標準誤差になります。

このやり方が成り立つ理由は、標本を母集団の代役にしているところにあります。本来は母集団から標本を取り直したいのですが、それができないので、標本が母集団の形をよく写していることを前提に、標本からの再抽出で代用するわけです。だから前提が崩れる場面では、ブートストラップも崩れます。10件しかない標本は母集団の形を写しきれていませんし、時系列のように観測同士が相関するデータでは、独立な再抽出は元のデータにない構造を作ってしまいます。

最後に、推定の精度とサンプルサイズの関係です。標準誤差はnの平方根に反比例するので、誤差を半分にするには標本を4倍に、10分の1にするには100倍にしなければなりません。逆に、必要な精度が決まれば、必要なnを先に見積もれます。注文金額の平均をプラスマイナス50円で知りたければ約1万2千件、100円でよければ約3千件で足ります。コンバージョン率をプラスマイナス0.1ポイントで知るには約11万セッション、0.3ポイントなら約1万2千セッションが要ります。比率の精度は、母比率が3パーセントのように小さいと、相対的に高くつきます。

ここで、DWHの全数データにも標準誤差を考えるのか、という疑問に答えておきます。先週の売上を先週の実績として報告するだけなら、それは記述統計であり、誤差はありません。標準誤差が要るのは、その数字を来週や別の顧客層にも当てはまる店の性質として読むときです。将来への一般化を含む問いにおいては、観測済みの全数もまた一つの標本なのです。

では、具体例に進みます。まず、注文金額の平均の信頼区間です。先週1週間の注文について、SQLで件数、平均、標本標準偏差を集計すると、2,800件、平均3,201.6円、標準偏差2,798.0円でした。標準誤差は52.88円、自由度2,799のt分布の97.5パーセンタイルは1.9608なので、95パーセント信頼区間は3,098円から3,305円になります。店の注文金額の平均について、先週のデータは100円ほどの幅までは絞り込めますが、それ以上は言えません。先週と今週の平均が3,202円と3,260円で違ったとしても、この幅の中の揺れであれば、店の性質が変わったとは言えないのです。この、違いが揺れの範囲か、という問いを手続きにしたものが、第5章の仮説検定です。

標本が小さいと、t分布の補正と分布の歪みの両方が効いてきます。発売したばかりの限定セットの注文が30件あり、平均3,293円、標準偏差2,890円だったとします。標準誤差は528円、自由度29のt分布の値は2.045で、区間は2,214円から4,372円まで広がります。店全体の平均3,202円も、それより1,000円高い値も否定できません。1.96を使った区間より上下に45円ずつ広いのが、t分布の補正分です。そしてシミュレーションで見たとおり、nが30のこの区間は、実際には91パーセントほどの確率でしか母平均を含みません。限定セットの単価について何か言うには、注文が数百件たまるのを待つほうがよいでしょう。

次に、コンバージョン率の信頼区間です。同じ週のセッションは2万件で、そのうち612件が購入に至り、コンバージョン率は3.06パーセントでした。ワルド区間もウィルソン区間も、2.8パーセントから3.3パーセントで、実質的に同じです。差が出るのは標本が小さいときです。新しく作ったランディングページのセッションが200件で、そのうち3件が購入に至ったとします。ワルド区間は、マイナス0.19パーセントから3.19パーセントと、下限が負になります。0件のときは幅がゼロになって、コンバージョン率は確実にゼロだと主張してしまいます。ウィルソン区間は、0.5パーセントから4.3パーセントという、200件の観測から言える範囲を正しく返します。新しいページの1.5パーセントが店全体の3パーセントより悪いかどうかは、この区間からはまだ判断できません。ランディングページ別のように行を細かく切るほど各行のnは小さくなるので、集計表に比率を並べるときは、ウィルソン区間を添えておくと、小さい行の値を読みすぎずに済みます。

三つ目は、ブートストラップによる中央値の信頼区間です。注文金額は右に歪んでいるので、代表値としては平均より中央値のほうが向いている場面があります。先週の2,800件の中央値は2,402円でした。この標本から復元抽出で2,800件を作り直して中央値を計算する操作を1万回繰り返し、その2.5パーセンタイルと97.5パーセンタイルを取ると、95パーセント信頼区間は2,333円から2,511円になります。中央値の標準誤差は約47円です。再抽出は乱数に依存するので、区間の端は数円単位で変わりますが、その程度の違いは報告するときの丸めの範囲に収まります。同じ再抽出で平均を計算し直すと、区間は3,101円から3,306円になり、t分布で求めた区間とほぼ一致します。公式のある推定量ではブートストラップは要りませんが、公式の前提が怪しいときに結果を確かめる用途にも使えます。

最後に、目標の精度からサンプルサイズを決める例です。注文金額の平均をプラスマイナス50円で知りたければ約1万2千件で、1日400件の注文なら約1か月分が要ります。一方でコンバージョン率をプラスマイナス0.3ポイントで知るには約1万2千セッションで、1日3,000セッションとして4日分で足ります。どちらの見積もりも、標準偏差2,800円や比率3パーセントという過去の値を前提にしているので、見積もりの後に実際の値で確かめ直します。この計算は、第8章でA/Bテストの期間を決めるときの土台になります。

この章で学んだことをまとめます。標本から計算した推定値は標本とともに揺れ、その揺れの大きさが標準誤差です。中心極限定理のおかげで、平均の揺れは正規分布で扱えますが、歪んだ分布では十分なnが要ります。信頼区間は、その揺れを幅で示す道具で、平均にはt分布、比率にはウィルソン区間、公式のない推定量にはブートストラップを使います。そして信頼区間の95パーセントは、母数が入る確率ではなく、区間を作る手続きの当たりやすさを表しています。次の章では、この標準誤差と信頼区間を使って、二つの値の違いが揺れの範囲かどうかを判断する仮説検定を学びます。
