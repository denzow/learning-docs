対象章：[第2章 記述統計と分布の要約](../02-descriptive-statistics.md)（[演習問題](../exercises/02-descriptive-statistics.md)）

第2章、記述統計と分布の要約。この章では、手元にあるデータをどう要約するかを学びます。第1章で、統計を記述統計と推測統計に分けました。この章はそのうちの記述統計の話です。題材は、書籍オンラインストアの注文金額です。この分布は、右に長く裾を引く形をしていて、要約の道具の使い分けを考えるのにちょうどよい例になります。

まず、要約とは何かを考えるところから始めます。先月の注文金額の平均は3,200円だった、という報告は、12,000件の注文を一つの数に圧縮しています。圧縮である以上、何かを捨てています。捨てたものが問いにとって重要でなければ、それはよい要約です。逆に、重要なものを捨てていれば、正確に計算された数であっても、読み手を誤らせます。要約の善し悪しは、要約する前の全体の姿、つまり分布の形によって決まります。ですからこの章は、分布を見るところから始めます。

分布とは、一つの変数が取る値と、それぞれの値がどれだけの頻度で現れるかの対応のことです。注文金額なら、300円の注文が何件、1,500円の注文が何件という、すべての対応が分布です。要約の対象は、個々の注文ではなく、この分布です。分布を最初に見る道具が度数分布表です。値の範囲を等間隔の区間、これを階級と呼びますが、その階級に区切って、各階級に入る件数と割合を並べます。これを棒の高さで描いたものがヒストグラムです。形を見るときの観点は三つあります。山が一つか複数か、山が中央にあるか一方に寄っているか、そして裾がどちらへどれだけ長く伸びているかです。

山が左に寄っていて、右に長い裾を引く形を、右に歪んだ分布と呼びます。金額や所要時間やアクセス数のように、下限がゼロで上限のない量の多くは、この形になります。注文金額もそうで、文庫本一冊の1,500円前後に山があり、まとめ買いや高額の専門書が右の裾を作ります。これから説明する要約の道具の使い分けは、ほぼすべて、この歪みがあるかないかから導かれます。

では代表値の話に入ります。分布の中心を一つの数で表したものを代表値と呼び、代表的な三つが平均、中央値、最頻値です。平均は、値の合計を件数で割った数です。合計と件数から計算できるので、SQLの集計として最も安価で、売上のように合計そのものに関心がある問いでは自然な代表値になります。平均に件数を掛ければ合計に戻るという性質は、他の二つにはありません。中央値は、値を小さい順に並べたときに中央に来る値です。半分の注文はこれより安く、半分は高い、という位置の情報であり、個々の値の大きさには影響されません。一件だけ極端な注文があっても、順位が一つずれるだけで、中央値はほとんど動きません。最頻値は、最も頻度の高い値です。金額のような連続的な量では、度数分布表で最も件数の多い階級として読みます。

この三つの使い分けは、分布の形で決まります。左右対称な分布では三つがほぼ一致するので、どれを使っても同じ話になります。ところが右に歪んだ分布では、最頻値、中央値、平均の順に右へずれていきます。裾にある少数の大きな値が合計を押し上げるので、合計に依存する平均だけが、裾の側へ引っ張られるからです。注文金額では、最頻値が1,500円付近、中央値が2,400円、平均が3,200円と、三つの値がはっきり分かれます。このとき、平均的な注文、という言い方は誤解を招きます。実際、平均の3,200円を下回る注文は全体の65パーセントにのぼります。平均は、大多数の注文よりも高い金額を指しているのです。典型的な一件の姿を伝えたいなら中央値を、合計に結びつけたいなら平均を選び、歪んだ分布では両方を並べて報告します。

次は散らばりです。代表値だけでは、値がその周りにどれだけ集中しているかがわかりません。中心からの離れ方を一つの数で表したのが散らばりの指標です。分散は、各値と平均との差、これを偏差と呼びますが、その偏差を二乗して平均した数です。偏差をそのまま平均すると、正と負が打ち消し合ってゼロになるので、二乗して符号を消します。その代償として、分散の単位は元の単位の二乗になり、そのままでは読めません。そこで分散の正の平方根を取って単位を元に戻したものが標準偏差です。注文金額の標準偏差は2,800円で、典型的な注文は平均から2,800円くらい離れている、と読めます。

ここで一つ注意があります。標準偏差について、平均プラスマイナス標準偏差の範囲に約68パーセントの値が入る、という説明をよく見かけます。この読み方は、分布が正規分布に近いときに限って成り立ちます。右に歪んだ注文金額では、平均から標準偏差を引くと400円で、分布の左端近くまで届いてしまいます。一方で、平均に標準偏差を足した6,000円より右には、まだ10パーセント以上の注文が残っています。歪んだ分布では、標準偏差は散らばりの大きさの目安にはなっても、範囲の目安にはならないのです。

単位の違う量の散らばりを比べたいときは、標準偏差を平均で割った変動係数を使います。日次の注文数は平均400件で標準偏差60件、注文金額は平均3,200円で標準偏差2,800円です。円と件では比べられませんが、変動係数なら0.15と0.9として比べられます。注文数は日によって15パーセント程度しか揺れないのに対し、一件の注文金額は平均と同じくらいの幅で揺れる、という比較ができます。

続いて、パーセンタイルと箱ひげ図です。値を小さい順に並べたとき、下からpパーセントの位置にある値をpパーセンタイルと呼びます。中央値は50パーセンタイルです。25パーセンタイルを第1四分位数、75パーセンタイルを第3四分位数と呼び、その差を四分位範囲と呼びます。四分位範囲は、中央の50パーセントの注文が収まる幅で、標準偏差と違って、裾の極端な値に影響されません。最小値、第1四分位数、中央値、第3四分位数、最大値の五つを五数要約と呼び、これを図にしたものが箱ひげ図です。箱が四分位範囲、箱の中の線が中央値を表します。ひげは、箱の両端から四分位範囲の1.5倍以内にある最も遠い値まで伸ばし、その外側の値は点として個別に描きます。この四分位範囲の1.5倍という基準を、外れ値の目安とする規則が広く使われています。

ところが、注文金額にこの規則を当てはめると、第3四分位数の3,930円に、四分位範囲2,500円の1.5倍を足した7,680円が上側の境界になり、全注文の6パーセントがその外に出ます。一か月で750件です。これらは入力誤りでも異常でもなく、専門書のまとめ買いという通常の注文です。この規則は左右対称な分布を想定して作られているので、右に歪んだ分布では、裾の正当な値を大量に外れ値の側に振り分けてしまいます。箱ひげ図の点を、機械的に外れ値と呼ぶわけにはいきません。

そこで外れ値の扱いです。他の値から極端に離れた値を外れ値と呼びますが、外れ値かどうかは値だけでは決まらず、その値がどこから来たかの判断を伴います。由来は三つに分けられます。一つ目は記録の誤りです。単位の取り違えやテストデータの混入などで、データそのものが事実を表していないので、原因を特定して除外するか修正します。二つ目は別の母集団の混入です。法人の一括購入や社内の検証注文のように、分析したい対象とは別の集団から来た値です。除外するかどうかは問いによります。個人客の購買行動を知りたいなら除外し、売上全体を知りたいなら含めます。三つ目は正当な極端値です。分析対象の集団に属し、単にまれに起きる大きな値なので、除外する理由はありません。この場合は、要約の側を、中央値やパーセンタイルのような極端値に影響されにくい統計量に切り替えます。どの由来であっても、値を除外したり修正したりしたときは、何件をどの基準で扱ったかを結果とともに記録します。基準が記録されていない要約は、再現できないからです。

次に対数変換です。右に歪んだ量は、対数を取ると左右対称に近い形になることが多いです。対数は掛け算を足し算に変える変換で、1,000円から2,000円への変化と、5,000円から10,000円への変化を、どちらも2倍として同じ幅に写します。金額のように比率で変化する量は、対数の尺度で見たほうが分布の形が素直になります。注文金額の対数を取ると、山は中央に来て、平均プラスマイナス標準偏差の範囲に約68パーセントが収まる形になります。ただし、対数の尺度で計算した平均を元の尺度に戻すと、平均ではなく幾何平均になります。注文金額では、対数の平均を元に戻すと2,380円で、中央値の2,400円とほぼ一致し、算術平均の3,200円とは離れます。これを平均金額と報告すると、合計と整合しない数を平均と呼ぶことになるので注意してください。対数変換は、第3章の対数正規分布や、第6章の検定、第7章の回帰でも繰り返し使います。

概念の最後は、集計の粒度です。同じ平均注文金額でも、何を一件として数えるかで値が変わります。三人の顧客を考えてみましょう。一人は5,000円の注文を10回、残りの二人は2,000円の注文を1回ずつ行いました。注文単位の平均は、合計54,000円を12件で割って4,500円です。顧客単位の平均は、5,000円と2,000円と2,000円の平均で3,000円です。どちらが正しいかは問いで決まります。一回の注文で平均いくら売れるかなら注文単位、顧客一人あたりの購買の典型なら顧客単位です。分析基盤のテーブルは注文のような細かい粒度で持たれていることが多く、何も考えずに集計すると注文単位の平均になります。報告する数がどの粒度の平均かは、数値と一緒に書いてください。

ここからは具体例です。先月の注文12,000件を対象に、まず度数分布表をSQLで作ります。注文金額を1,000円で割って切り捨て、1,000円刻みの階級に区切り、階級ごとの件数と、ウィンドウ関数で全体に対する割合を求めます。結果を見ると、1,000円台が28パーセントで最も多く、2,000円台が21パーセント、3,000円台が13パーセントと、右へ行くほど減っていきます。2,000円未満の注文が全体の4割を占める一方、10,000円以上の注文も3パーセントあります。右に歪んだ分布だとわかった時点で、平均だけで要約しない方針が決まります。

次に、代表値と散らばりを一度の問い合わせで求めます。平均はAVG、標準偏差はSTDDEV_SAMP、パーセンタイルはPERCENTILE_CONTという順序集計関数で書けます。結果は、平均3,200円、標準偏差2,800円、第1四分位数1,430円、中央値2,400円、第3四分位数3,930円、90パーセンタイル6,300円、99パーセンタイル14,300円、最大値は56,000円近くでした。中央の50パーセントの注文は1,430円から3,930円の幅に収まりますが、上位1パーセントは14,300円を超えます。同じ要約はpandasでも得られます。注文金額をDataFrameに載せてdescribeを呼ぶと、件数、平均、標準偏差、四分位数が並びます。さらに、対数を取ってから歪度を計算すると、元の尺度では3.6だった歪度が0.04まで下がり、対数の尺度では左右対称に近いことが確かめられます。

三つ目の例は、一件の大口注文が平均に与える影響です。ある日の注文400件の平均が3,470円、中央値が2,530円だったとします。この日に、法人から500,000円の一括注文が一件加わりました。すると平均は4,710円に上がり、標準偏差は3,050円から約25,000円へと8倍になります。一方、中央値は2,530円のまま動きません。個人客の購買行動を追う日次の指標として平均を使っていれば、この日は施策と無関係に跳ね上がり、翌日には元に戻ります。この注文は記録の誤りではないので、直すべきはデータではなく要約の側です。個人客の行動を見る指標には中央値か、法人注文を除外した平均を使い、法人注文は件数と金額を別に報告します。

最後の例は、注文単位と顧客単位の平均です。顧客ごとに注文件数と平均金額を集計してから、その平均を取ると、顧客単位の平均は2,950円で、注文単位の平均3,200円より250円低くなりました。月に何度も注文する顧客は一件あたりの金額も大きい傾向があり、その注文が件数分だけ注文単位の平均に効くからです。ダッシュボードの平均注文金額がどちらを指すかは、定義を確かめないとわかりません。指標の名前に粒度を含めるか、定義を指標の説明に書くようにしてください。

この章の内容をふり返ります。要約の前に分布の形を見ること。右に歪んだ分布では平均と中央値が分かれるので、問いに応じて選び、両方を報告すること。標準偏差は歪んだ分布では範囲の目安にならないこと。外れ値は値ではなく由来で判断すること。対数変換で歪みを抑えられるが、戻した値は幾何平均になること。そして、平均には粒度があること。次の第3章では、この注文金額のような分布を、確率分布という理論の型に当てはめて扱います。
