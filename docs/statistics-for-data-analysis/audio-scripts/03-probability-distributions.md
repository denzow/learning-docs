対象章：[第3章 確率分布](../03-probability-distributions.md)（[演習問題](../exercises/03-probability-distributions.md)）

第3章、確率分布。この章では、観測した値がどんな仕組みで生まれ、どの程度ばらつくものなのかを表すモデル、つまり確率分布を学びます。第2章では、注文金額や日次注文数のデータを、代表値と散らばりで要約しました。しかし分析の問いの多くは、要約した値そのものではなく、その値をばらつきの中でどう評価するかを求めています。新しいランディングページの初日に、1,000セッションで購入が22件だったとき、これは普段の3パーセントから悪化したと言えるのでしょうか。ある日の注文が450件だったとき、これは記録に残す出来事なのでしょうか。こうした問いに答えるための道具が確率分布です。

この章では、確率変数と確率分布の考え方を導入したうえで、分析の実務で繰り返し現れる四つの分布を扱います。回数を数える二項分布とポアソン分布、連続量の基準になる正規分布、そして金額のように右に歪んだ量に合う対数正規分布です。分布ごとに、それが表すデータの生成の仕組みと、その仕組みが成り立つ条件を対にして押さえていきます。第4章の推定と第5章の検定は、ここで学ぶ分布を土台にしています。

まず、確率変数と確率分布という言葉から始めます。次に訪れるセッションが購入に至るかどうか。明日の注文数がいくつになるか。これらは値がまだ確定しておらず、確定するまでは可能な値のどれかを取る量です。このように、偶然に左右されて値が決まる量を確率変数と呼びます。分析基盤に蓄積された注文金額や日次注文数は、確率変数が実際に取った値、つまり実現値です。そして確率分布は、確率変数がどの値をどの確率で取るかの割り当てです。第2章の度数分布は、観測した実現値を数えて割合にしたものでした。確率分布はその理論上の対応物で、データを生み出す仕組みの側が定めている割合です。

確率変数は、取り得る値の種類で二つに分かれます。購入件数や注文数のように飛び飛びの値を取る変数を離散型と呼び、ちょうど30件になる確率、というように値ごとの確率で分布を表します。金額や時間のように連続した値を取る変数を連続型と呼びます。連続型では、ちょうど2,400円になる確率はゼロで、代わりに2,000円から3,000円の間に入る確率、というように区間で確率を考えます。また、分布は形の族と、族の中の一つを指定する数値で決まります。この数値をパラメータと呼びます。第1章の言葉で言えば、パラメータは母集団の側にある数であり、データから計算する統計量はその推定値です。この区別は第4章の推定で中心になります。

次に、期待値と分散です。期待値は、確率変数の取り得る値を、その確率で重み付けして平均した値です。標本平均が観測値を等しい重みで平均するのに対し、期待値は確率という重みで平均します。分布の分散は、値と期待値の差の二乗を確率で重み付けした平均で、その平方根が標準偏差です。期待値と分散は、分布によってはパラメータから直接計算できます。成功確率がpの試行をn回行ったときの成功回数の期待値は、nかけるp、分散は、nかけるp、かける、1引くpです。1,000セッションでコンバージョン率が3パーセントなら、購入件数の期待値は30件で、標準偏差は約5.4件です。1,000セッションで22件、という値は、22という数字だけを見ても判断がつきません。期待値30と標準偏差5.4を並べて、22が期待値から標準偏差の1.5倍ほど下にあると分かって、初めて珍しさの程度を語れるようになります。

ここから、四つの分布を順に見ていきます。一つ目は二項分布です。購入に至るか至らないか、のように結果が二つしかない試行をベルヌーイ試行と呼び、一方の結果を成功と呼んでその確率をpと書きます。同じpを持つ独立なベルヌーイ試行をn回行ったときの成功回数が従う分布が、二項分布です。二項分布が成り立つ条件は、各試行の成功確率が同じであることと、試行同士が独立であることの二つです。セッション単位のコンバージョンにこのモデルを当てはめるとき、条件はおおむね成り立ちますが、崩れる場面もあります。同じ顧客が短時間に複数のセッションを持てば、それらの結果は独立ではありません。キャンペーンの開始で日の途中からpが変わるなら、同じpという条件が崩れます。条件が崩れると、二項分布が示すばらつきより実際のばらつきは大きくなるのが普通で、モデルの示す珍しさは過大評価になります。モデルを使うときは、その条件を題材に照らして確かめる習慣が要ります。

二つ目はポアソン分布です。一日の注文数のように、一定の期間に起きる出来事の件数を数える場面を考えます。各瞬間に出来事が起きる確率は小さいのですが、瞬間の数は膨大です。つまり、試行回数が大きく、pが小さい二項分布と見なせます。この極限で得られる分布がポアソン分布です。パラメータは一つだけで、期間あたりの平均発生件数、ラムダです。ポアソン分布では期待値と分散がどちらもラムダに等しく、標準偏差はラムダの平方根になります。日次注文数の平均が400件なら、標準偏差は20件で、ラムダが一定という条件のもとでは、日次注文数の95パーセントは360件から440件の範囲に収まります。ただし、この条件は日次注文数に対しては成り立たないことが多いのです。曜日で来訪数が変わり、キャンペーンでラムダ自体が動くからです。このとき観測される分散はラムダより大きくなります。これを過分散と呼びます。過分散があるデータにポアソン分布をそのまま当てはめると、普通の変動を異常と誤認します。一方、ポアソン分布が本領を発揮するのは、平均発生件数が小さい事象です。一日平均2件の決済エラーのような事象では、正規分布で近似すると負の件数に確率を割り当ててしまいますが、ポアソン分布なら0件、1件、2件のそれぞれの確率を正しく扱えます。

三つ目は正規分布です。正規分布は、平均を中心に左右対称の釣鐘型をした連続型の分布で、平均と標準偏差の二つのパラメータで決まります。統計の道具の多くがこの分布を前提にしているのには、二つの理由があります。一つは、多くの小さな要因の和として決まる量は、要因それぞれの分布によらず正規分布に近づくという性質です。これを中心極限定理と呼び、第4章で扱います。もう一つは、二項分布やポアソン分布も、nやラムダが大きくなると正規分布で近似できるという性質です。正規分布で覚えておくべき数値は、平均プラスマイナス1標準偏差の範囲に約68パーセント、プラスマイナス2標準偏差に約95パーセント、プラスマイナス3標準偏差に約99.7パーセントが入る、という関係です。値から平均を引いて標準偏差で割った量をzスコアと呼び、zスコアが2を超える観測は5パーセント程度しか起きない珍しい値、という読み方をします。

四つ目は対数正規分布です。注文金額の分布は右に長い裾を持ち、正規分布の左右対称とはかけ離れています。中央値2,400円に対して平均は3,200円で、最頻値はさらに低い1,500円付近にあります。このような量に合うのが対数正規分布です。対数正規分布とは、その値の対数を取ったものが正規分布に従う分布のことです。正規分布が多くの要因の和で生まれる量に合うのに対し、対数正規分布は多くの要因の積で生まれる量に合います。注文金額は、買う冊数、選ぶ本の単価帯、割引の有無といった要因がおおむね掛け算で効いて決まるため、この形になります。売上、所得、応答時間など、正の値しか取らず右に裾を引く量の多くが、対数正規で近似できます。対数正規分布では、必ず平均が最も大きく、最頻値が最も小さくなります。逆に言えば、中央値と平均の二つが分かれば、分布全体が決まります。

概念の最後は、大数の法則と分布の当てはめです。標本平均は、標本を大きくするほど期待値に近づきます。この性質を大数の法則と呼びます。コンバージョン率3パーセントの母集団から100セッションを取れば、観測されるコンバージョン率は4パーセントにも1パーセントにもなりますが、10万セッションを取ればほぼ3パーセントに落ち着きます。ただし大数の法則は、近づくことを保証するだけで、どれだけの速さで近づくかは別の話です。大数の法則はまた、度数分布と確率分布の関係も説明します。標本が大きければ観測した割合は確率に近づくので、大きな標本の度数分布は確率分布の形を映します。だから、どの分布が題材に合うかは、観測した分位点と理論上の分位点を並べて確かめられます。この比較を散布図にしたものがQQプロットで、点が直線に乗るかどうかで当てはまりを判断します。ただし、分布はデータの生成の仕組みを写したモデルであり、細部まで一致することはありません。一致しない箇所は多くの場合、分布の裾にあります。分布を当てはめるときは、中央付近が合っているかだけでなく、これから判断に使う裾の側が合っているかを見てください。

ここからは具体例です。書籍のオンラインストアの分析基盤を題材に、三つの分布を順に使います。計算はPythonのSciPyで行います。

最初は二項分布です。新しいランディングページを公開した初日、1,000セッションで購入が22件でした。コンバージョン率にすると2.2パーセントで、普段の3パーセントより低く見えます。SciPyで試行回数1,000、成功確率0.03の二項分布を作り、22件以下になる確率を求めると、約8パーセントになります。つまり、コンバージョン率が普段どおり3パーセントだったとしても、22件以下になる日は、12日か13日に1日は起きる程度の出来事です。この1日だけで悪化したと結論づけるわけにはいきません。中央95パーセントの範囲を求めると20件から41件と広く、1,000セッション程度では3パーセントと2.2パーセントの差は区別できないと分かります。この判断を検定という形式に整えるのが第5章です。

次はポアソン分布です。日次注文数の平均は400件です。ポアソン分布を当てはめると、450件以上になる確率は約0.75パーセント、中央95パーセントの範囲は361件から440件と計算できます。しかし本当にラムダが一定かどうかは、観測した平均と分散を比べれば分かります。日次売上のテーブルから注文数の平均と標本分散をSQLで集計すると、このストアでは平均400件に対して分散が1,600前後、標準偏差にして40件ほど観測されます。ポアソン分布が予測する分散400の4倍で、明らかな過分散です。原因は曜日による来訪数の違いで、週末のラムダと平日のラムダが別物になっています。曜日ごとに集計し直せば、それぞれの曜日の中では平均と分散がほぼ一致し、ポアソン分布が使えます。450件を評価するときも、全期間の平均ではなく、その曜日の平均をラムダに置いて計算しなければなりません。

件数の少ない事象では、ポアソン分布がそのまま役に立ちます。決済エラーは一日平均2件で、曜日による差もありません。何件からをアラートの対象にするかを決めるために、平均2のポアソン分布で計算すると、5件以上になる確率は約5.3パーセント、8件以上になる確率は約0.1パーセントです。5件以上を閾値にすると、異常がなくても20日に1回ほどアラートが鳴ります。8件以上なら3年に1回程度に抑えられます。どちらを選ぶかは見逃しの損失と誤報の手間の比較であり、確率分布はその比較に必要な数字を与えてくれます。

三つ目は対数正規分布です。高額注文を確認の対象にする運用を始めるにあたり、10,000円を超える注文が全体のどれだけを占めるかを見積もります。第2章で求めた注文金額の中央値2,400円と平均3,200円から、対数正規分布のパラメータを逆算します。平均と中央値の比から、対数を取った後の標準偏差が約0.76と決まり、対数を取った後の平均は中央値の対数で約7.78です。この二つで対数正規分布を作ると、再現した分布の標準偏差は2,822円で、第2章で観測した2,800円とほぼ一致します。中央値と平均だけから出発した分布が散らばりまで再現できているのは、注文金額が対数正規分布に近い証拠の一つです。この分布で10,000円を超える注文の割合を求めると、全体の3パーセントです。一日400件なら12件ほどが確認の対象になります。閾値を20,000円にすれば0.26パーセント、一日1件程度に減ります。

同じ判断を正規分布で行うと結果は大きく違います。平均3,200円、標準偏差2,800円の正規分布は、10,000円超を0.76パーセントと見積もり、実際の4分の1に過小評価します。しかも金額が負になる確率に12.7パーセントを割り当てており、モデルとして破綻しています。分布の形を取り違えると、平均と標準偏差が正しくても裾の判断は誤るのです。

当てはまりの確認は、観測した分位点と理論上の分位点を並べて行います。SQLで注文金額の10パーセント点から99パーセント点までを集計し、対数正規分布の理論値と並べると、10パーセント点から90パーセント点までは、観測値と理論値の差が数十円から百数十円で、よく合っています。一方、99パーセント点は観測16,800円に対して理論14,014円で、裾は対数正規分布の想定より重くなっています。まとめ買いや法人の注文という、通常の購入とは別の仕組みで生まれる高額注文が混ざっているためです。10,000円の閾値なら3パーセントという見積もりは使えますが、20,000円の閾値では想定より確認の件数が増えると見込んでおくべきです。

最後に、大数の法則をシミュレーションで確かめます。コンバージョン率3パーセントの母集団から、セッション数を変えて標本を取り、観測されるコンバージョン率を乱数で見ます。100セッションでは4パーセントと、真の値から1ポイントもずれています。1,000セッションでは2.9パーセント、1万セッションでは2.73パーセント、100万セッションでは2.98パーセントと、セッション数を増やすにつれて観測値は3パーセントに近づいていきます。これが大数の法則です。ただし1万セッションでも2.73パーセントであり、収束は速くありません。どれだけの標本があれば、どれだけの精度で母集団の値を言い当てられるか。この問いが、次の第4章の主題になります。
