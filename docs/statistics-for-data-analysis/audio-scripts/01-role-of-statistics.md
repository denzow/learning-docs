対象章：[第1章 データ分析における統計の役割](../01-role-of-statistics.md)（[演習問題](../exercises/01-role-of-statistics.md)）

第1章、データ分析における統計の役割。この章では、データ分析の仕事の中で統計がどんな役割を果たすのかをつかみます。手がかりとして、三つの区別を学びます。一つ目は、データを要約する記述統計と、データの背後にあるものを推し量る推測統計の区別です。二つ目は、知りたい対象の全体である母集団と、観測できた一部である標本の区別です。三つ目は、データの種類と尺度の区別です。最後に、分析の問いを五つの型に分けて、この教材の各章がどの型の問いに答えるのかという見取り図を示します。

まず、統計とは何のための道具か、というところから始めます。分析基盤には、注文、セッション、顧客といった業務のデータが日々たまっています。先月の売上はいくらか、という問いには、集計の SQL を書けば答えが出ます。しかし、おすすめ枠は売上を伸ばしたのか、来月の売上はどのくらいか、デスクトップの顧客はモバイルの顧客より高く買うのか、といった問いには、集計の結果を眺めるだけでは答えられません。これらの問いは、手元のデータそのものではなく、手元にないものについて述べることを求めているからです。まだ来ていない顧客、施策を打たなかった場合の世界、来月の売上。こうした手元にないものについて、手元のデータから根拠を持って述べるための道具が統計です。

では、一つ目の区別、記述統計と推測統計の話に入ります。統計の道具は、目的によって二つに分かれます。一つは、手元のデータの特徴を要約して示す記述統計です。先月の注文数、平均注文金額、注文金額の分布の形、デバイス別の内訳。これらはどれも、手元のデータに含まれる事実を圧縮して見やすくしたものです。データが同じなら、誰が計算しても同じ値になります。第2章で扱う代表値と散らばり、第10章で扱う時系列の分解は、この記述統計に属します。

もう一つは、手元のデータから、そのデータを生み出した仕組みや、まだ観測していない対象について推し量る推測統計です。たとえば、デスクトップの顧客はモバイルの顧客より高く買う傾向がある、という主張を考えてみてください。これは先月のデータの要約ではなく、来月の顧客にも当てはまる傾向についての主張です。先月たまたまそうだったのか、それとも今後も繰り返し観測される傾向なのか。それを手元のデータから判断するのが推測統計の役割です。第4章の推定、第5章と第6章の検定、第7章の回帰は、この推測統計に属します。

両者の違いは、計算の難しさではありません。答えに不確実性が伴うかどうかです。記述統計の答えは手元のデータについての事実であり、集計が正しければ間違いようがありません。推測統計の答えは、手元にないものについての判断であり、外れる可能性を常に含みます。だから推測統計の道具は、答えの数値だけでなく、その答えがどのくらい外れうるかの見積もりを必ず伴います。後の章で学ぶ信頼区間や p 値が、その見積もりです。

次に、二つ目の区別、母集団と標本の話です。推測統計は、知りたい対象の全体と、観測できた一部とを区別するところから始まります。知りたい対象の全体を母集団、そのうち実際に観測できた一部を標本と呼びます。たとえば全国の有権者の支持率を知りたいとき、母集団は有権者全員で、電話調査に答えた数千人が標本です。標本から母集団について述べるとき、標本が母集団のどの部分を写しているのかが、主張の妥当性を決めます。

ところが分析基盤のデータでは、この区別が見えにくくなります。先月の注文は全件が注文テーブルに入っているのだから、標本ではなく全数に見えるからです。問いが、先月の売上はいくらか、であれば、その通りです。先月の注文の全体が母集団で、手元にその全体があるのだから、集計した値がそのまま答えになり、推測の余地はありません。

しかし問いが、デスクトップの顧客はモバイルの顧客より高く買うのか、であればどうでしょうか。知りたいのは先月の顧客ではなく、今後も店を訪れる顧客を含めた購買の傾向です。先月のデータは、その傾向のもとで、たまたまその月に観測された一つの標本にすぎません。同じ傾向のもとでも、来月の顧客は別の人であり、注文の金額は別の値になります。同じ仕組みからもう一度データが出たら、値はどのくらい違いうるか。この発想が、推測統計の出発点です。標本によって値がぶれることを標本変動と呼び、そのぶれの大きさを見積もる方法は第4章で扱います。

ここで押さえてほしいのは、全数か標本かはデータの側ではなく、問いの側で決まる、ということです。問いが手元の期間の事実を求めているなら、全数として集計すればよい。問いが仕組みや将来について述べることを求めているなら、同じデータを標本として扱わなければならない。同じテーブルに対する同じ集計でも、答えが事実なのか推測なのかは、問いによって変わります。

標本として扱うとき、もう一つ確かめることがあります。標本が母集団を偏りなく写しているか、です。母集団の一部だけが観測されやすい仕組みがあると、標本の要約は母集団の値からずれます。このずれを選択バイアスと呼びます。分析基盤のデータには、この偏りが入り込む経路がいくつもあります。顧客テーブルの年齢は、登録した顧客のものしかありません。購入後のアンケートには、満足した顧客が答えやすい。解約した顧客の行動ログは、解約の時点で途切れる。どの経路も、手元のデータを母集団の姿だと素朴に読むと判断を誤らせます。偏りを避ける最も確実な方法は、母集団から無作為に標本を取ること、あるいは施策の対象を無作為に割り当てることです。この考え方は、第8章の A/B テストと第9章の因果推論の土台になります。

三つ目の区別、データの種類と尺度の話に移ります。データの値がどんな種類の量かによって、使える要約と手法が決まります。まず大きく、数値として意味を持つ量的データと、分類の名前を表す質的データに分かれます。注文金額、注文数、年齢は量的データ、デバイス、地域、ランディングページは質的データです。購入に至ったかどうかの真偽値は、分類が二つの質的データとして扱います。

この区別は、さらに四つの尺度に細分されます。一つ目は名義尺度で、値が分類の名前であり、順序も差も意味を持ちません。デバイスのモバイルとデスクトップ、地域の関東と関西がこれにあたります。数えることと、最も多い分類を求めることはできますが、平均は定義できません。二つ目は順序尺度で、値に順序はあるが、値の差に意味がないものです。レビューの星の数や満足度の五段階がこれにあたります。星4と星2の差が、星5と星3の差と同じ大きさだとは言えません。三つ目は間隔尺度で、値の差に意味はあるが、ゼロが何もないことを表さないものです。日付や摂氏の温度がこれにあたります。3日後、とは言えますが、2倍の日付、は意味を持ちません。四つ目は比尺度で、値の差にも比にも意味があり、ゼロが何もないことを表すものです。金額、件数、年齢、滞在時間がこれにあたります。平均注文金額の2倍、のような倍率の表現が意味を持ちます。

尺度を気にする理由は、尺度が使える演算を決め、演算が使える要約と検定を決めるからです。名義尺度の平均に意味がないのは明らかですが、順序尺度の平均は実務でよく使われます。レビューの平均星数がその例です。使うこと自体が誤りとは言えませんが、星の間隔が等しいという仮定を暗に置いていることは意識しておく必要があります。量的データには、もう一つ、離散と連続の区別があります。注文数のように整数の値しか取らないものが離散、金額や時間のようにいくらでも細かい値を取りうるものが連続です。この区別は、第3章でデータに当てはめる確率分布を選ぶときに効いてきます。

最後に、分析の問いの型の話です。分析の依頼は、業務の言葉で届きます。おすすめ枠の効果を見てほしい、売上が落ちている理由を知りたい、来期の計画のために予測がほしい。こうした依頼を、統計の道具で答えられる問いに翻訳するのが、分析者の最初の仕事になります。翻訳の手がかりとして、問いを五つの型に分けます。一つ目は記述で、いま、どうなっているか、を問うものです。二つ目は比較で、二つ以上の群は違うか、を問うものです。三つ目は関係で、二つの量は連動するか、を問うものです。四つ目は予測で、将来はどうなるか、を問うものです。五つ目は因果で、ある働きかけをすると結果は変わるか、を問うものです。

この教材の各章は、この型に対応しています。記述の問いには、第2章の代表値と散らばり、第3章の確率分布、第10章の時系列の分解で答えます。比較の問いには、第4章の推定と、第5章、第6章の検定で答えます。関係の問いには第7章の相関と回帰、予測の問いには第7章の回帰と第10章の時系列モデル、因果の問いには第8章の A/B テストと第9章の因果推論で答えます。

五つの型のうち、混同されやすいのは関係と因果です。広告費と売上が連動していても、広告を増やせば売上が増えるとは限りません。年末商戦の時期に広告費も売上も増えるなら、両者を連動させているのは季節であって、広告ではないかもしれない。関係の問いには手元のデータの相関で答えられますが、因果の問いに答えるには、働きかけを行わなかった場合との比較が必要になります。その比較をどう作るかが第8章と第9章の主題で、この教材の後半はこの一点に多くの分量を割いています。

ここからは具体例です。書籍のオンラインストアの分析チームを題材にします。分析基盤には五つのテーブルがあります。注文テーブルは1注文1行で、注文金額とデバイスを持ちます。セッションテーブルは1セッション1行で、購入に至ったかどうかの真偽値を持ちます。顧客テーブルは登録済みの顧客の地域と年齢を持ちます。日次売上テーブルは日ごとの注文数と売上を持ちます。そして実験割り当てテーブルは、A/B テストでどの顧客が対照群と処置群のどちらに入ったかを持ちます。この教材の具体例は、これらのテーブルで書いていきます。

まず、記述の問いです。先月の注文はどんな様子だったか。注文テーブルを先月の期間で絞って、件数、合計、平均、中央値を集計します。結果は、注文数が1万2400件、売上が3968万円、平均注文金額が3200円、中央値が2400円でした。1日あたりにすると注文が400件、売上が128万円です。ここで注目してほしいのは、平均が中央値より800円高いことです。この差は、注文金額の分布が右に長く裾を引いていること、つまり少数の高額な注文が平均を押し上げていることを示します。どの要約値を使い、分布の形をどう読むかは第2章で扱います。この問いは記述の型で、先月の全体が手元にあるので、これらの値はそのまま事実です。不確実性の見積もりはいりません。

次に、同じ注文テーブルをデバイス別に集計します。モバイルからの注文は7750件で平均3050円、デスクトップからの注文は4650件で平均3450円でした。先月、デスクトップからの注文の平均金額はモバイルより400円高かった、と報告するなら、これは記述の問いへの答えで、事実です。しかし、この結果を見た依頼者が本当に知りたいのは、デスクトップの顧客は高く買う傾向があるのか、であることが多い。この問いは比較の型で、今後の顧客を含めた傾向についての主張を求めています。この時点で、同じ集計結果が標本の要約に変わります。

標本として読むとき、400円の差が傾向を表すのか、先月に限った偶然なのかを見積もる必要があります。注文金額は1件ごとに大きくばらつき、標準偏差はおよそ2800円もあります。たまたま高額な注文がデスクトップに多く入った月には、傾向がなくても差が出ます。偶然でどのくらいの差が出うるかは、ばらつきの大きさと注文数から見積もれます。第4章の標準誤差の考え方を先取りすると、この例では1群あたり数千件の注文があるため、偶然で出る差はせいぜい数十円の規模です。400円の差は偶然では説明しにくい。逆に、もし注文数が1群あたり30件しかなければ、偶然の差が500円を超えることも珍しくなく、同じ400円の差から傾向を読み取ることはできません。差の大きさだけでは判断できず、ばらつきと件数を合わせて読む。これが推測統計の基本の作法です。

差が偶然でないとしても、まだ因果の問いは残っています。デスクトップで買うと高く買うようになるのか、と問われれば、答えは別です。デスクトップから注文する顧客には、職場で専門書をまとめ買いする層が多いかもしれません。その場合、金額を押し上げているのは顧客層であって、デバイスではありません。比較の問いに答える道具は、差が偶然かどうかを判定しますが、差の原因がどこにあるかは判定しません。原因を問うには、第9章の道具がいります。

最後に、依頼を問いの型に翻訳する例をいくつか挙げます。先月の売上と注文数を報告してほしい、は記述の問いです。地域によって CVR に差があるのか、は比較の問いです。広告費と売上は連動しているのか、は関係の問いです。来月の日次売上を見積もってほしい、は予測の問いです。そして、おすすめ枠は CVR を上げたのか、昨年配ったクーポンは売上を増やしたのか、はどちらも因果の問いです。ただし、この二つには違いがあります。おすすめ枠は A/B テストとして無作為に割り当てた記録がありますが、クーポンは過去に特定の顧客層へ配った記録しかありません。前者は因果の問いに直接答えられますが、後者は観察データから因果を推し量る手続きが必要で、答えの確からしさも下がります。依頼を型に翻訳し、手元のデータでどの型まで答えられるかを依頼者と合意するところまでが、分析の設計に含まれます。

この章のまとめです。統計は、手元のデータから手元にないものについて述べるための道具です。記述統計は手元のデータを要約し、推測統計はその背後にある仕組みを推し量ります。全数か標本かはデータではなく問いの側で決まり、標本として扱うときは標本変動と選択バイアスに気を配ります。データの尺度は使える要約と手法を決めます。そして分析の依頼は、記述、比較、関係、予測、因果の五つの型に翻訳してから道具を選びます。次の章では、記述統計の道具である代表値と散らばりの指標を、注文金額の分布を題材に学びます。
