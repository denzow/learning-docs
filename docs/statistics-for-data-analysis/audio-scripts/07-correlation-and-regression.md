対象章：[第7章 相関と回帰分析](../07-correlation-and-regression.md)（[演習問題](../exercises/07-correlation-and-regression.md)）

第7章、相関と回帰分析。この章では、二つ以上の量的な変数のあいだの関係を測る道具として、相関と回帰を学びます。第5章と第6章では、デバイスや地域のような区分ごとに、平均や比率に差があるかを問いました。しかし分析の問いには、区分ではなく量の関係を尋ねるものも多くあります。広告費を増やした日は売上が増えるのか。顧客の年齢が上がると注文金額は上がるのか。こうした問いに答えるのが、この章の道具です。

相関は、二つの変数が連動する強さを一つの数で要約します。回帰は、連動の向きと大きさを式で表して、ある変数の値からもう一方の値を見積もります。どちらも記述統計として使えますし、第4章の推定と第5章の検定をそのまま載せて、標本から母集団の関係を推測する道具にもなります。ただし、相関も回帰も、それだけでは因果を示しません。広告費と売上が連動していても、両方を押し上げる別の要因が隠れているかもしれないからです。この章では、その「関係はあるが原因とは限らない」という限界を、数値の上で確かめていきます。原因を問う道具は第9章で扱います。

まず、相関係数から始めます。二つの量的な変数の関係を測る出発点は、両方の変数がそれぞれの平均からどちらの向きにずれているかを掛け合わせることです。広告費が平均より多い日に売上も平均より多ければ、その日の積は正になります。片方だけが平均より多ければ、積は負になります。この積を全期間で平均したものが共分散で、正なら二つの変数は同じ向きに動きやすく、負なら逆向きに動きやすいということになります。ただ、共分散は単位に依存するという不便があります。売上を円で測るか千円で測るかで、値が千倍変わってしまうのです。そこで共分散を、二つの変数の標準偏差の積で割って単位を消したものが相関係数です。相関係数はマイナス1から1の範囲に収まり、1に近いほど一方が増えると他方も直線的に増え、マイナス1に近いほど一方が増えると他方が直線的に減ります。0は、直線的な連動がないことを表します。

相関係数の大きさを読むときは、二乗した値を見るとよいでしょう。相関係数の二乗は、一方の変数のばらつきのうち、他方との直線関係で説明できる割合を表します。たとえば、顧客の年齢と注文金額の相関係数が0.15だとすると、二乗は0.02ですから、注文金額のばらつきの2パーセントしか年齢では説明できません。「相関がある」という言い方は、それだけでは関係の強さを伝えないのです。

相関係数には、外れ値に引きずられやすい、直線的でない関係を捉えられない、という弱点があります。この弱点を避けたいときは、値そのものではなく、値の順位のあいだで相関係数を計算します。これがスピアマンの順位相関係数です。順位に置き換えれば、極端に大きな値も「一番大きい」という順位になるだけなので、外れ値の影響が抑えられます。また、一方が増えれば他方も増えるという単調な関係であれば、直線でなくても順位相関は高くなります。

次に、相関係数が見せないものを五つ挙げます。相関係数は関係を一つの数に圧縮するので、圧縮で失われる情報があるのです。一つ目は外れ値です。一年分の日次データで広告費と売上の相関を計算するとき、大型キャンペーンで広告費も売上も桁違いに大きい日が一日あれば、残りの364日に連動がなくても相関係数は高く出ます。二つ目は非線形な関係です。年齢と注文金額の関係が、40代まで上がってその後下がる山形だとすると、上りと下りが打ち消し合って相関係数は0に近くなります。相関係数が0であることは、関係がないことではなく、直線的な関係がないことを意味するだけです。三つ目は範囲の制限です。購入額が上位1割の優良顧客だけを取り出して、訪問回数と購入額の関係を調べると、相関はほとんど出ません。どの人も訪問回数が多く購入額も高いので、変数の動く範囲が狭いからです。

四つ目は疑似相関です。二つの変数に共通して効く第三の要因が作る相関のことです。広告費と売上は連動して見えますが、その連動の一部は年末商戦が作っています。年末には販促の予算が増えて広告費が上がり、同時に贈答需要で売上も上がります。広告に効果がまったくなくても、年末を含む一年分のデータでは、広告費と売上に正の相関が出てしまうのです。このような共通要因を交絡と呼びます。五つ目はシンプソンのパラドックスで、交絡が関係を逆転させる極端な形です。全体で見るとAのほうがBより良いのに、デバイス別に分けると、モバイルでもデスクトップでもBのほうが良い、ということが起きます。これは後で具体的な数字で確かめます。

ここから回帰分析に入ります。相関係数は連動の強さを表しますが、広告費を1万円増やすと売上はいくら増えるか、という大きさの問いには答えません。その問いに答えるのが回帰分析です。回帰分析は、説明したい変数、つまり目的変数を、手がかりになる変数、つまり説明変数の式で表します。説明変数が一つで、式が直線のものを単回帰と呼びます。式は、売上イコール、切片プラス、傾きかける広告費、プラス残差、という形です。切片は広告費が0のときの売上の見積もり、傾きは広告費が1円増えたときに売上が平均していくら変わるかを表します。残差は、直線による見積もりと実際の値との差です。直線の引き方は、残差を二乗して足し合わせた値が最小になるように傾きと切片を選びます。この決め方を最小二乗法と呼びます。

回帰の当てはまりの良さは、決定係数で測ります。決定係数は、目的変数のばらつきのうち、回帰式で説明できた割合で、0から1の値を取ります。単回帰では、決定係数は相関係数の二乗に一致します。そして、傾きは標本から計算した推定値ですから、第4章の推定の枠組みがそのまま載ります。傾きには標準誤差があり、信頼区間が作れます。第5章の検定も載って、傾きは0であるという帰無仮説の検定が、統計ソフトの出力に並ぶp値です。

説明変数が二つ以上ある回帰を重回帰と呼びます。重回帰の傾きの読み方は、単回帰と一つだけ違います。広告費の傾きは、他の説明変数の値を固定したうえで、広告費が1円増えたときに売上が平均していくら変わるかを表します。週末かどうかと12月かどうかを固定して比べるので、年末商戦が作る見かけの連動は、広告費の傾きから取り除かれます。このように、関心のある変数の効果を測るために式に加える変数を統制変数と呼びます。疑似相関への対処は、交絡になっている変数を統制変数として式に入れることなのです。ただし、統制できるのは列として持っている変数だけです。記録されていない交絡は取り除けません。

週末や12月のような二値の変数は、該当する日を1、しない日を0とした列にして式に入れます。これをダミー変数と呼びます。曜日のように三つ以上の値を取る変数は、一つの値を基準にして、残りの値ごとにダミー変数を作ります。月曜を基準にすると、火曜から日曜の六つのダミー変数ができて、それぞれの傾きは月曜との差になります。七つ全部を入れると、七つの列を足すと必ず1になって切片と区別がつかなくなるので、一つは必ず基準として外します。

重回帰には、単回帰にはない落とし穴があります。説明変数どうしが強く相関していると、それぞれの傾きを分けて推定できなくなるのです。広告費と広告のクリック数は、クリック数が広告費でほぼ決まるので、ほとんど同じ動きをします。両方を式に入れると、売上の変化をどちらのせいにすべきかをデータから決められず、両方の傾きの標準誤差が大きくなります。これを多重共線性と呼びます。程度は分散拡大係数、VIFで測り、10を超えたら疑うという目安がよく使われます。対処は、意味の重なる変数の片方を外すか、二つを一つの指標にまとめることです。

回帰分析には、目的の違う二つの使い方があります。一つは予測で、明日の広告費と曜日から明日の売上を見積もるように、目的変数の値を当てることが目的です。もう一つは説明で、広告費の傾きそのものを知りたい、という使い方です。どちらの目的かで、同じモデルの評価が変わります。予測が目的なら、多重共線性は問題になりません。傾きがどう分かれようと、二つを合わせた見積もりは安定しているからです。しかし説明が目的なら、傾きの不安定はそのまま結論の不安定を意味します。この章の具体例は、説明を目的にしています。

では具体例です。一年分の日次売上と日次広告費を使って、広告費が売上に与える効果を見積もります。数値は、広告費1円あたり2円の売上増、週末に15万円の上乗せ、12月に広告費の倍増と30万円の上乗せ、という構造を仮定して作った模擬データから計算しました。模擬データなら、分析の手続きがどれだけ正解に近づくかを確かめられます。

まず、SQLの集計関数で相関係数を測ります。一年を通した相関係数は0.66で、広告費と売上は強く連動しているように見えます。しかし12月を除くと0.21まで下がります。12月の31日分が右上に固まって、残りの334日にある弱い連動を、強い直線に見せていたのです。同じデータでスピアマンの順位相関を計算すると0.38で、通常の相関係数より小さくなります。順位相関が大きく下回るのは、一部の極端な値が通常の相関係数を押し上げている合図です。

次に、売上を広告費だけで単回帰します。傾きは6.15で、広告費が1円多い日は売上が平均で6.15円多いと読めます。決定係数は0.437で、相関係数0.66の二乗に一致します。しかし、模擬データに仕込んだ本当の効果は、1円あたり2円です。単回帰は、年末商戦が作る売上の上乗せまで広告費の傾きに乗せてしまい、効果を三倍に見積もっているのです。

そこで、週末と12月のダミー変数を統制変数として加えた重回帰を行います。広告費の傾きは2.68まで下がり、95パーセント信頼区間は1.78から3.58で、仕込んだ正解の2を含みます。週末の傾きは約15万8千円、12月の傾きは約28万9千円で、どちらも仕込んだ値に近い値です。決定係数は0.687に上がりましたが、これは統制変数が売上の変動を説明したためで、広告費の説明力が上がったわけではありません。ここで傾きの読み方に注意してください。2.68という値は、同じ曜日区分で同じ月区分の日どうしを比べたとき、広告費が1円多い日は売上が平均で2.68円多い、という意味です。ただし、記録していない交絡、たとえばテレビで書籍が紹介された日に広告費も増やしていたといった事情があれば、その分はまだ傾きに乗っています。

続いて、広告のクリック数を説明変数に足してみます。クリック数は広告費とほぼ同じ動きをするので、相関係数は0.99です。足した結果、広告費の傾きの標準誤差は0.46から2.20に膨らみ、信頼区間はマイナス2.4から6.2まで広がって、効果の有無すら判断できなくなりました。分散拡大係数は、広告費とクリック数のどちらも60を超えています。一方で、週末と12月の傾きは変わっていません。共線性は、相関している説明変数どうしの傾きだけを壊すのです。広告の効果を知りたいなら、広告費とクリック数のどちらか一方だけを式に残します。

最後に、シンプソンのパラドックスを数字で確かめます。二種類のランディングページ、AとBについて、コンバージョン率をデバイス別に集計します。ページAは、デスクトップが8千セッションでコンバージョン率4パーセント、モバイルが2千セッションで2パーセントです。ページBは、デスクトップが2千セッションで4.5パーセント、モバイルが8千セッションで2.4パーセントです。デバイス別に見ると、デスクトップでもモバイルでも、Bのほうが高いことがわかります。ところがデバイスを合算すると、Aは3.6パーセント、Bは2.82パーセントで、Aのほうが高くなります。逆転の原因は、Aのセッションの8割がコンバージョン率の高いデスクトップから来ていて、Bのセッションの8割がコンバージョン率の低いモバイルから来ていることにあります。合算した比較は、ページの比較ではなく、デバイス構成の比較になっていたのです。

どちらの比較を信じるべきかは、デバイスがどのように決まるかで決まります。デバイスは利用者が持ち込むものであり、ページによって変わるものではありません。だからページの良し悪しは、デバイスを固定した比較で判断すべきで、Bのほうが良いという結論になります。これは、重回帰でデバイスをダミー変数として統制するのと同じ判断です。逆に、ページが利用者のデバイスの選択を変えるような状況なら、デバイス別に分けると効果の一部を消してしまいます。分けるかどうかは表の形からは決まらず、変数のあいだの因果の向きを考えて決めます。この判断の整理は、第9章で扱います。
