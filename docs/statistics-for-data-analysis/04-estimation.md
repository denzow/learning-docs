# 第4章 標本と推定

第 2 章で、先週の注文金額を集計すると平均は 3,202 円だった。
しかしこの数字が答えているのは「先週の注文はいくらだったか」であり、分析者が本当に知りたいのは「この店の注文金額はどれくらいか」という問いであることが多い。
来週の注文をまだ観測していない以上、先週の 2,800 件は、第 1 章で述べたとおり、店の注文金額という母集団から取り出した一つの標本にすぎない。
別の週を取れば平均は 3,150 円にも 3,260 円にもなるだろうし、そのどれもが間違いではない。

本章では、標本から母集団の値を推定するとき、その推定がどれだけ不確かなのかを測る道具を扱う。
推定値のばらつきを表す標本分布と標準誤差、歪んだ分布でも平均の推定を正規分布で扱えるようにする中心極限定理、不確かさを幅で示す信頼区間、そして公式に頼らずに不確かさを求めるブートストラップである。
第 3 章で学んだ正規分布と二項分布は、この章では推定値のばらつきを記述する道具として使う。
第 5 章の仮説検定は、この章の標準誤差と信頼区間の上に載る。

## 概念の解説

### 母数、推定量、標本分布

母集団について知りたい値には名前がある。
母集団の注文金額の平均や、母集団のコンバージョン率のように、母集団を特徴づける値を**母数**と呼ぶ。
母数は一つに定まっているが、母集団を全部は観測できないので、直接には分からない。

その母数を標本から見積もるために計算する統計量が**推定量**であり、計算して得た一つの値が**推定値**である。
標本の平均で母平均を、標本のコンバージョン率で母比率を見積もるのが典型で、一つの値で答えるこの形を**点推定**と呼ぶ。
先週の平均 3,202 円は母平均の点推定値である。

点推定の弱点は、その値が標本とともに揺れることを表せないところにある。
同じ手続きで別の標本を取れば、推定値は別の値になる。
標本を取り直すたびに推定値がどう散らばるかを表す分布を**標本分布**と呼ぶ[^sampling-dist]。
標本分布が狭ければ推定値は信頼でき、広ければ一つの推定値から母数について言えることは少ない。

ただし、標本分布そのものを観測することはできない。
手元にあるのは一つの標本であり、標本を何百回も取り直す予算はない。
だから標本分布は、理論から導くか、手元の標本から模擬するかのどちらかで知ることになる。
前者が標準誤差と中心極限定理、後者がブートストラップである。

### 標準誤差と中心極限定理

標本分布の広さを一つの数で表したものが**標準誤差**である。
標本分布の標準偏差、つまり推定値のばらつきの大きさが標準誤差であり、標本平均については次の関係が成り立つ。

```text
標本平均の標準誤差 = 母集団の標準偏差 ÷ √n     （n は標本の大きさ）
```

母集団の標準偏差は分からないので、実際には標本の標準偏差で置き換えて計算する。
先週の注文金額なら、標準偏差 2,798 円を √2800 で割った約 53 円が標準誤差である。

標準偏差と標準誤差は混同しやすいので区別しておく。
標準偏差は注文 1 件の金額がどれだけ散らばるかを表し、データを増やしても縮まらない（母集団の性質だからである）。
標準誤差は平均という推定値がどれだけ散らばるかを表し、データを増やすと √n に反比例して縮む。
「注文金額のばらつきは 2,800 円」と「平均の推定の誤差は 53 円」は、同じ標本から出てくる別の量である。

ここで、標本分布の形が問題になる。
注文金額の分布は右に歪んでおり（第 2 章）、正規分布とは似ていない。
それでも平均の標本分布については、**中心極限定理**が成り立つ。
元の分布がどんな形であっても、独立な観測の平均の分布は、n が大きくなるにつれて正規分布に近づく、という定理である[^clt]。

定理の効き方は、シミュレーションで確かめられる。
注文金額と同じ形の対数正規分布（中央値 2,400 円、平均 3,200 円、標準偏差 2,830 円）から n 件を取って平均を出す操作を 10,000 回繰り返し、平均の分布を調べた結果が次の表である。

| n | 平均の標準偏差（実測） | 標準偏差 ÷ √n | 平均の分布の歪度 |
| --- | --- | --- | --- |
| 1 | 2,845 | 2,831 | 3.25 |
| 5 | 1,275 | 1,266 | 1.45 |
| 30 | 512 | 517 | 0.60 |
| 300 | 163 | 163 | 0.17 |

実測の標準偏差は、標準偏差 ÷ √n の公式にどの n でも一致している。
一方、分布の歪度は n が増えるにつれて 0（正規分布の値）へ近づいていくが、n が 30 でもまだ歪みが残る。
注文金額ほど歪んだ分布では、正規分布として扱えるのは数百件から先だと考えておくのが安全である。
教科書にある「n が 30 あれば十分」という目安は、元の分布が左右対称に近い場合の話である。

### 信頼区間

点推定に不確かさの幅を添えたものが**区間推定**であり、その幅を**信頼区間**と呼ぶ。
平均の標本分布が正規分布に近いなら、第 3 章の 68-95-99.7 のルールから、推定値の上下に標準誤差の 1.96 倍を取った区間が 95% 信頼区間になる。

```text
95% 信頼区間 = 推定値 ± 1.96 × 標準誤差
```

ただし、標準誤差の計算に標本の標準偏差を使う分だけ、この区間は正規分布の想定より少し広げる必要がある。
その補正を担うのが **t 分布**で、1.96 の代わりに自由度 n − 1 の t 分布の 97.5 パーセンタイルを使う。
n が 30 なら 2.045、n が 10 なら 2.262 で、n が数百を超えれば 1.96 とほとんど変わらない。
平均の信頼区間には常に t 分布を使う、と決めておけば、n の大小で使い分ける手間がなくなる。

比率の信頼区間には、平均とは別の事情がある。
コンバージョンのように結果が 0 か 1 の値なら、標準偏差は比率 p だけから p × (1 − p) の平方根と決まるので（第 3 章のベルヌーイ分布）、標準誤差は √(p × (1 − p) ÷ n) と書ける。
この標準誤差に標本の比率を入れて 1.96 倍した区間が **Wald 区間**である。
簡単だが、比率が 0 や 1 に近いか n が小さいと破綻する。
コンバージョンが 200 セッション中 3 件なら下限が負になり、0 件なら幅がゼロの区間になる。

破綻を避けるのが **Wilson 区間**である[^wilson]。
Wald 区間が標本の比率で標準誤差を決めるのに対し、Wilson 区間は「真の比率が p だとしたら観測した比率は正規近似で妥当な範囲にあるか」を p について解いて区間を作る。
その結果、区間の中心は標本の比率より 0.5 側へわずかに寄り、n が小さくても 0 と 1 の内側に収まる。
n が大きく比率が中程度なら Wald 区間と一致するので、実務では Wilson 区間を既定にしてよい。

信頼区間の意味は、言葉の上で誤解されやすい。
95% 信頼区間は「母平均がこの区間に入る確率が 95%」を意味しない。
母平均は一つに定まった値であり、入るか入らないかのどちらかで、確率を持つのは区間の側である。
正しくは、同じ手続きで標本を取り直して区間を作ることを繰り返せば、そのうち 95% の区間が母平均を含む、という手続きの性質を述べている。
手元の区間がその 95% に入っているかは分からないが、当たりやすい手続きで作った区間である、というのが「95% 信頼」の中身である。

この 95% という被覆率も、前提が崩れれば下がる。
n が 30 の注文金額で t 分布の区間を作る操作を 20,000 回模擬すると、母平均を含んだのは 91% にとどまった。
右に歪んだ分布では小さい標本の平均が母平均を下回りやすく、区間もそれに引きずられるためである。
n が 300 では 94.5% まで回復する。
信頼区間の幅と同じくらい、その前提が成り立つ n かどうかを気にかける必要がある。

### ブートストラップ

平均と比率には標準誤差の公式があった。
しかし中央値や、二つの平均の比、顧客あたり売上の上位 10% の割合のような推定量には、簡単な公式がない。
公式の代わりに計算機で標本分布を作るのが**ブートストラップ**である。

手続きは単純である。
手元の標本から、同じ大きさの標本を復元抽出（同じ観測を何度でも選んでよい抽出）で作り、推定量を計算する。
これを数千回繰り返すと、推定値の散らばりが得られる。
その散らばりの 2.5 パーセンタイルと 97.5 パーセンタイルを取れば 95% 信頼区間になり、標準偏差を取れば標準誤差になる[^bca]。

このやり方が成り立つ理由は、標本を母集団の代役にしているところにある。
本来は母集団から標本を取り直したい。
それができないので、標本が母集団の形をよく写している（n が十分にあり、観測が独立している）ことを前提に、標本からの再抽出で代用する。
だから前提が崩れる場面ではブートストラップも崩れる。
n が 10 件しかない標本は母集団の形を写しきれていないし、時系列のように観測同士が相関するデータでは、独立な再抽出は元のデータにない構造を作ってしまう（第 10 章）。

### 推定の精度とサンプルサイズ

標準誤差が √n に反比例することは、精度を上げるコストを決める。
誤差を半分にするには標本を 4 倍に、10 分の 1 にするには 100 倍にしなければならない。
逆に、必要な精度が決まれば、必要な n を先に見積もれる。

```text
n = (1.96 × 標準偏差 ÷ 許容する誤差)²          （平均の場合）
n = 1.96² × p × (1 − p) ÷ 許容する誤差²         （比率の場合）
```

注文金額の平均を ±50 円で知りたければ約 12,000 件、±100 円でよければ約 3,000 件で足りる。
コンバージョン率を ±0.1 ポイントで知るには約 11 万セッション、±0.3 ポイントなら約 12,000 セッションが要る。
比率の精度は、母比率が 3% のように小さいと相対的に高くつく。

最後に、DWH の全数データにも標準誤差を考えるのかという疑問に答えておく。
先週の売上を先週の実績として報告するだけなら、それは記述統計であり、誤差はない。
標準誤差が要るのは、その数字を来週や別の顧客層にも当てはまる店の性質として読むときである。
第 1 章で述べたとおり、将来への一般化を含む問いにおいては、観測済みの全数もまた一つの標本である。

## 具体例

分析基盤の注文テーブルとセッションテーブルを使い、平均、比率、中央値の三つの推定量に信頼区間を付ける。
集計は SQL で行い、区間の計算は Python（numpy と SciPy）で行う。

### 注文金額の平均の信頼区間

先週 1 週間の注文について、件数、平均、標本標準偏差を集計する。

```sql
SELECT
    COUNT(*)            AS n,
    AVG(amount)         AS mean_amount,
    STDDEV_SAMP(amount) AS sd_amount
FROM orders
WHERE ordered_at >= DATE '2026-08-24'
  AND ordered_at <  DATE '2026-08-31';
-- n = 2800, mean_amount = 3201.6, sd_amount = 2798.0
```

この三つの値から、t 分布による 95% 信頼区間を求める。

```python
import numpy as np
from scipy import stats

n, mean, sd = 2800, 3201.6, 2798.0
se = sd / np.sqrt(n)                  # 52.88
t = stats.t.ppf(0.975, df=n - 1)      # 1.9608
print(mean - t * se, mean + t * se)   # 3097.9 3305.3
```

平均 3,202 円の 95% 信頼区間は 3,098 円から 3,305 円である。
店の注文金額の平均について、先週のデータは 100 円ほどの幅までは絞り込めるが、それ以上は言えない。
先週と今週の平均が 3,202 円と 3,260 円で違ったとしても、この幅の中の揺れであれば、店の性質が変わったとは言えない。
この「違いが揺れの範囲か」という問いを手続きにしたものが、第 5 章の仮説検定である。

明細の生データが手元にあるなら、SciPy が同じ計算を一行で行う。

```python
# amount は注文金額の配列
stats.t.interval(0.95, df=len(amount) - 1, loc=amount.mean(), scale=stats.sem(amount))
```

標本が小さいと、t 分布の補正と分布の歪みの両方が効いてくる。
発売したばかりの限定セットの注文が 30 件あり、平均 3,293 円、標準偏差 2,890 円だったとする。

```python
n, mean, sd = 30, 3293.0, 2890.3
se = sd / np.sqrt(n)                  # 527.7
t = stats.t.ppf(0.975, df=n - 1)      # 2.0452
print(mean - t * se, mean + t * se)   # 2213.7 4372.3
```

区間は 2,214 円から 4,372 円まで広がり、店全体の平均 3,202 円も、それより 1,000 円高い値も否定できない。
1.96 を使った区間（2,259 円から 4,327 円）より上下に 45 円ずつ広いのが t 分布の補正分である。
そしてシミュレーションで見たとおり、n が 30 のこの区間は実際には 95% ではなく 91% ほどの確率でしか母平均を含まない。
限定セットの単価について何か言うには、注文が数百件たまるのを待つほうがよい。

### コンバージョン率の信頼区間

セッション単位のコンバージョン率について、同じ週で集計する。

```sql
SELECT
    COUNT(*)                                     AS sessions,
    COUNT(*) FILTER (WHERE converted)            AS conversions,
    AVG(CASE WHEN converted THEN 1.0 ELSE 0 END) AS cvr
FROM sessions
WHERE visited_at >= DATE '2026-08-24'
  AND visited_at <  DATE '2026-08-31';
-- sessions = 20000, conversions = 612, cvr = 0.0306
```

Wald 区間と Wilson 区間を計算する関数を書き、比べる。

```python
import numpy as np

def wald(k, n, z=1.96):
    p = k / n
    half = z * np.sqrt(p * (1 - p) / n)
    return p - half, p + half

def wilson(k, n, z=1.96):
    p = k / n
    denom = 1 + z**2 / n
    center = (p + z**2 / (2 * n)) / denom
    half = z * np.sqrt(p * (1 - p) / n + z**2 / (4 * n**2)) / denom
    return center - half, center + half

print(wald(612, 20000))    # (0.02821, 0.03299)
print(wilson(612, 20000))  # (0.02830, 0.03308)
```

2 万セッションで 3.06% なら、どちらの区間も 2.8% から 3.3% で、実質的に同じである。
差が出るのは標本が小さいときである。
新しく作ったランディングページのセッションが 200 件で、そのうち 3 件が購入に至ったとする。

```python
print(wald(3, 200))      # (-0.00185, 0.03185)
print(wilson(3, 200))    # (0.00511, 0.04317)
print(wald(0, 200))      # (0.0, 0.0)
print(wilson(0, 200))    # (0.0, 0.01885)
```

Wald 区間は下限が負になり、0 件のときは幅がゼロになって「コンバージョン率は確実に 0%」と主張してしまう。
Wilson 区間は 0.5% から 4.3% という、200 件の観測から言える範囲を正しく返す。
新しいページの 1.5% が店全体の 3.0% より悪いかどうかは、この区間からはまだ判断できない。
ランディングページ別やキャンペーン別のように、行を細かく切るほど各行の n は小さくなるので、集計表に比率を並べるときは Wilson 区間を添えておくと、小さい行の値を読みすぎずに済む。

### ブートストラップによる中央値の信頼区間

注文金額は右に歪んでいるので、代表値としては平均より中央値のほうが向いている場面がある（第 2 章）。
その中央値に信頼区間を付ける公式は簡単ではないため、ブートストラップを使う。

```python
import numpy as np

# amount は先週の注文金額の配列（2,800 件、中央値 2401.7）
rng = np.random.default_rng(1)
boot = np.array([
    np.median(rng.choice(amount, size=len(amount), replace=True))
    for _ in range(10_000)
])
print(np.median(amount))                  # 2401.7
print(np.percentile(boot, [2.5, 97.5]))   # [2333.3 2510.9]
print(boot.std())                         # 47.3（中央値の標準誤差）
```

中央値 2,402 円の 95% 信頼区間は 2,333 円から 2,511 円である。
SciPy の `stats.bootstrap` も同じ計算を行うが、再抽出が乱数に依存するため、区間の端は数円単位で変わる。
その程度の違いは、区間を報告するときの丸めの範囲に収まる。

ブートストラップが公式と食い違わないことは、平均で確かめられる。
同じ再抽出で平均を計算し直すと、95% 信頼区間は 3,101 円から 3,306 円になり、t 分布で求めた 3,098 円から 3,305 円とほぼ一致する。
公式のある推定量ではブートストラップは要らないが、公式の前提が怪しいときに公式の結果を確かめる用途にも使える。

### 目標の精度からサンプルサイズを決める

分析を始める前に、望む精度に必要なデータ量を見積もる。
注文金額の平均を ±50 円で知りたい場合と、コンバージョン率を ±0.3 ポイントで知りたい場合を計算する。

```python
n_mean = (1.96 * 2800 / 50) ** 2               # 12,047 件
n_cvr = 1.96**2 * 0.03 * 0.97 / 0.003**2       # 12,421 セッション
```

1 日 400 件の注文なら、平均を ±50 円で知るには約 1 か月分が要る。
一方でコンバージョン率を ±0.3 ポイントで知るには、1 日 3,000 セッションとして 4 日分で足りる。
どちらの見積もりも、標準偏差 2,800 円や比率 3% という過去の値を前提にしているので、見積もりの後に実際の値で確かめ直す。
この計算は、第 8 章で A/B テストの期間を決めるときの土台になる。

- Peter Bruce, Andrew Bruce, Peter Gedeck, *Practical Statistics for Data Scientists*, 2nd Edition, O'Reilly, 2020.（データ分析の実務向けに、ブートストラップと信頼区間を扱う。邦訳『データサイエンスのための統計学入門 第2版』オライリー・ジャパン、2020 年）

[^sampling-dist]: 標本分布は「標本の分布」ではなく「統計量の分布」である。標本の分布はヒストグラムに描ける手元のデータの散らばりを指し、標本分布は標本を取り直したときの平均などの散らばりを指す。似た言葉なので、本章では後者だけを標本分布と呼ぶ。

[^clt]: 定理が成り立つには、観測が互いに独立で、母集団の分散が有限であることが要る。分散が無限になる裾の重い分布（一部の金融データや、ごくまれに極端に大きい注文が混じる分布）では、平均の分布が正規分布に近づかないことがある。注文金額の対数正規分布は分散が有限なので、定理の対象である。

[^wilson]: Edwin B. Wilson が 1927 年に提案した区間で、スコア区間とも呼ばれる。Brown らの 2001 年の論文は、n が大きくても比率が端に近いと Wald 区間の被覆率が 95% を大きく下回ることを示し、Wilson 区間か、それを近似した Agresti-Coull 区間を勧めている。

[^bca]: パーセンタイルで区間を切るこの方法をパーセンタイル法と呼ぶ。推定量の標本分布が偏っている場合には、偏りと歪みを補正する BCa 法（bias-corrected and accelerated）が使われる。SciPy の `stats.bootstrap` は既定で BCa 法を使う。
