# スタジオ撮影とライティング入門

Canon EOS R10 と Godox のモノブロックストロボを使って、レンタルスタジオで人物と商品を撮るための入門教材である。
カメラの露出とスタジオ向けの設定から始め、ストロボとワイヤレストリガーの扱い、光の質と方向、一灯と多灯のライティング、白ホリと背景紙のスタジオでの撮り方、物撮り、撮影当日の進め方までを順に解説する。
撮影の経験はあるがストロボを使ったことがない読者を想定し、自然光での撮影との違いをそのつど示す。
各章は、概念の解説、具体例（配置図と設定値）、参考文献の三部構成とする。

## 題材と機材

題材には、教材を通して一つの撮影を使う。
モデル役の友人のプロフィール写真（上半身と全身）と、ハンドメイド雑貨のオンラインショップに載せる陶器のマグカップの商品写真を、レンタルスタジオを半日借りて撮る、という撮影である。
章が進むにつれて、一灯から多灯へ、上半身から全身へ、白ホリから背景紙へと場面を広げ、章同士が相互参照できるようにする。
総合演習の章だけは、別の題材（小さなカフェのスタッフ写真とメニュー写真）で通しの撮影計画を立てる。

教材で想定する機材とスタジオは次のとおりである。
別の機種でも、操作の考え方は変わらない。

| 区分 | 想定する機材 | 教材で前提にする仕様 |
| --- | --- | --- |
| カメラ | Canon EOS R10 | APS-C（焦点距離はフルサイズ換算 1.6 倍）、2,420 万画素、ストロボ同調速度 1/250 秒、電子シャッターではストロボを使えない |
| レンズ | RF-S 18-150mm F3.5-6.3 IS STM（キットレンズ）、RF 50mm F1.8 STM | 50mm はフルサイズ換算 80mm で、上半身のポートレートに使う |
| ストロボ | Godox SK400II（モノブロック） | 400Ws、出力は 1/1 から 1/16 まで 0.1 段刻み、モデリングランプ付き、Bowens マウント、Godox X システムの受信機を内蔵。スタジオに 3 灯ある |
| トリガー | Godox XPro II-C | カメラのホットシューに付ける送信機。チャンネルとグループでストロボを選び、出力をカメラ側から変える |
| 用具 | 60×90cm ソフトボックス、白アンブレラ、標準リフレクター、グリッド、白と黒のレフ板、ライトスタンド、サンドバッグ | いずれもスタジオの備品を借りる想定 |
| スタジオ | 白ホリ（幅 5m、奥行 6m、天井 3.5m）と背景紙のブース（幅 2.72m の白、グレー、黒） | 窓は暗幕で塞げる |

## 章をまたいで使う基準の設定

露出やライトの位置は、章ごとに一から決めるのではなく、次の基準から出発して変えていく。

- カメラは M モード、ISO 100、シャッター速度 1/200 秒、絞り f/8、ホワイトバランス 5500K、RAW 記録を基準にする。
- キーライトは 60×90cm のソフトボックスを被写体の斜め前 45 度、高さは被写体の顔より少し上、被写体から 1.5m に置く。
- この位置で出力 1/4 にすると、被写体の顔が f/8 で適正になる。
- ライトを被写体から 2 倍の距離に離すと 2 段暗くなり、出力を 1 段上げると 1 段明るくなる。
