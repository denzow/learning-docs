# 第2章 露出の基本とストロボ撮影の露出（読み上げ原稿）

対象章：[第2章 露出の基本とストロボ撮影の露出](../02-exposure.md)（[演習問題](../exercises/02-exposure.md)）

第2章、露出の基本とストロボ撮影の露出。この章では、写真の明るさを決める露出の考え方を、自然光の撮影と共通の部分から確認したうえで、ストロボ撮影では何が違うのかを学びます。ストロボ撮影で露出を決める四つの要素と、露出計を持たなくても試し撮りとヒストグラムで露出を合わせる手順が、この章の中身です。

まず、この章がなぜ必要なのかを確認します。第1章で、スタジオ撮影は光を自分で作る撮影だと述べました。光を自分で作るということは、写真の明るさを決める変数が、カメラの外にも増えるということです。自然光で撮ってきた方は、絞り、シャッター速度、ISOの三つで明るさを合わせることに慣れていると思います。スタジオでは、そこにストロボの発光量と、ストロボから被写体までの距離が加わります。しかも、この五つの変数は同じ重みで効くわけではありません。自然光で最も頻繁に触るシャッター速度は、ストロボの光に対してはほとんど効きません。この違いを知らないままスタジオに入ると、シャッター速度を上げても下げても明るさが変わらないことに戸惑うことになります。

最初に、露出と段という土台を確認します。写真の明るさを決めるのは、センサーに届く光の量です。この量を露出と呼び、絞り、シャッター速度、ISO感度の三つで調整します。絞りはレンズを通る光の太さを、シャッター速度は光を受ける時間を、ISOはセンサーが光をどれだけ増幅するかを決めます。三つの要素は単位も数字の並びも違いますが、共通の物差しがあります。光の量が2倍になる変化、または半分になる変化を、段、英語でストップと呼びます。

段で見ると、三つの要素はきれいに並びます。絞りは、f/2.8、f/4、f/5.6、f/8、f/11、f/16という並びで、隣同士が1段の差です。値が大きいほど光は少なくなります。シャッター速度は、50分の1秒、100分の1秒、200分の1秒、400分の1秒という並びで、時間が半分になるごとに1段暗くなります。ISOは100、200、400と、2倍になるごとに1段明るくなります。絞り値だけが1.4倍ずつという少し変わった並びですが、これは絞りの面積が2倍になる変化に対応しているためです。カメラの設定はふつう3分の1段刻みで動くので、f/8とf/11の間にはf/9とf/10があります。

段という物差しがあると、三つの要素を交換できます。f/8、200分の1秒、ISO100で適正だった露出は、絞りをf/4に2段開けて、シャッター速度を800分の1秒に2段速くしても、同じ明るさになります。自然光の撮影では、この交換で、被写界深度とブレのどちらを優先するかを選んでいるわけです。スタジオでも段で考える習慣はそのまま使いますが、交換できる相手が変わります。これがこの章の主題です。

次に、絞りと被写界深度の関係を確認します。絞りは光の量と同時に、ピントの合う奥行きも決めます。ピントを合わせた位置の前後で、実用上ピントが合っていると見える範囲を被写界深度と呼びます。絞りを開けるほど浅く、絞るほど深くなります。被写体に近づくほど、また焦点距離が長いほど浅くなります。題材の上半身のポートレートでは、RF50mmを使い、被写体から2mほど離れて撮ります。この条件でf/8なら、被写界深度はおよそ30cmあり、鼻の先から耳までがピントに収まります。f/2.8まで開けると10cmほどしかなく、手前の目に合わせると、奥の目や耳がすでにぼけ始めます。

スタジオ撮影がf/8を基準にするのは、この深さのためです。自然光の撮影で開放に近い絞りを選ぶのは、暗い場所で光を稼ぐためであることが多いと思います。スタジオでは光をいくらでも足せるので、光量のために絞りを開ける必要がなく、被写界深度だけで絞りを選べます。背景をぼかしたいときに開けるのはよいのですが、それは開けなければ暗いからではなく、表現として選ぶことになります。

続いて、シャッター速度と同調速度の話です。自然光の撮影では、シャッター速度は被写体のブレと手ブレを抑えるために選びます。ストロボ撮影では、シャッター速度にもう一つの上限があります。EOS R10のメカシャッターは、先幕が開いてから後幕が閉じるまでの間に、センサー全体が露光する瞬間を持つのは250分の1秒までです。これより速いシャッター速度では、先幕が開ききる前に後幕が追いかけ始め、センサーの上をスリット状の隙間が走る形で露光します。ストロボはその瞬間にしか光らないので、隙間の位置だけが写り、残りは黒い帯になります。ストロボが画面全体に写る最も速いシャッター速度を同調速度と呼び、R10では250分の1秒です。教材では、無線トリガーの伝達に伴うわずかな遅れを見込んで、200分の1秒を基準にします。200分の1秒より遅くする分には、同調の問題はありません。

ここからが、ストロボ撮影の露出の核心です。ストロボの光がどのくらいの時間で出ているかを見てみます。Godox SK400IIの閃光時間は、出力によって800分の1秒から2000分の1秒程度です。シャッターが200分の1秒開いている間に、ストロボは1000分の1秒ほどで光をすべて出しきってしまいます。だからシャッター速度を100分の1秒に遅くしても、シャッターが開いている時間の中でストロボの光が増えることはなく、センサーに届くストロボの光は同じ量です。

したがって、ストロボの光による露出は、四つの要素で決まります。一つ目は絞りで、1段絞れば1段暗くなります。二つ目はISOで、1段下げれば1段暗くなります。三つ目は発光量、つまりストロボの出力で、4分の1から8分の1に落とせば1段暗くなります。四つ目は距離、ストロボから被写体までの距離で、離すほど暗くなり、2倍に離すと2段暗くなります。シャッター速度がこの中にありません。これがストロボ撮影の露出で、自然光の撮影と最も違う点です。

では、シャッター速度は何に効くのでしょうか。部屋の照明や窓からの光のように、シャッターが開いている間ずっと当たり続けている光に対してだけ効きます。このような光を、ストロボの瞬間的な光と区別して定常光と呼びます。つまり、ストロボ撮影の一枚の写真には、二つの露出が重なっています。ストロボ光の露出は絞り、ISO、発光量、距離で決まり、定常光の露出は絞り、ISO、シャッター速度で決まります。スタジオでは、定常光の露出が真っ黒になる設定を選ぶことで、ストロボ光の露出だけを考えればよい状態を作ります。ISO100、200分の1秒、f/8でストロボを切って一枚撮り、真っ黒であることを確かめる手順がそれです。モデリングランプや天井の照明は、この設定では写りません。窓からの光が入る場合や、わざと定常光を混ぜる撮影は第9章で扱います。

ストロボの閃光時間が短いことには、もう一つの帰結があります。被写体のブレも手ブレも、1000分の1秒の閃光の間に起きる動きしか写らないので、事実上止まります。R10にボディ内手ブレ補正がないことは、スタジオでは問題になりません。

次に、露出が適正かどうかを何で判断するかという話です。自然光ではカメラの露出計を見ますが、ストロボ撮影では、ファインダー内の露出計の指針は役に立ちません。露出計はシャッターを切る前の定常光しか測れず、まだ光っていないストロボの光は含まないからです。Mモードで指針が大きくマイナスに振れていても、それは定常光が真っ黒だと言っているだけで、ストロボ光の露出とは関係がありません。ストロボ光を測る専用の露出計、フラッシュメーターがあれば、被写体の位置で発光させて絞り値を直接読めます。しかし必須ではありません。デジタルカメラでは撮った結果をその場で見られるので、試し撮りを露出計の代わりにできます。

試し撮りで見るのは、背面モニターの見た目の明るさではなく、ヒストグラムです。ヒストグラムは画面の明るさの分布を、左を黒、右を白として並べたグラフで、モニターの明るさ設定や部屋の明るさに影響されません。右端に山が張り付いていれば白飛びしており、左端に張り付いていれば黒つぶれしています。肌の明るさは、ヒストグラムの中央から右寄りに来るのが目安で、右端には届きません。白飛びの場所を画面上で示すのがハイライト警告で、飛んだ部分が点滅して表示されます。白いシャツやマグカップの光る縁のように、ハイライト側が心配な被写体では、ヒストグラムより先にこの点滅を見るほうが早いです。ただし、ストロボの反射で光る点、たとえば目のキャッチライトや陶器のつやは、飛んでいて正しいので、面として飛んでいるかどうかで判断します。RAWで記録すれば、現像で1段ほどは明るさを戻せますが、白飛びした部分の情報は戻りません。迷ったら、飛ばさない側に3分の1段暗く撮っておくのが安全です。

ここからは、題材の撮影で具体的に見ていきます。ライトの配置は第1章の基準で、キーライトのソフトボックスを被写体の斜め前45度、被写体から1.5mに置きます。カメラはRF50mmで被写体から2mです。この章では露出の数値だけを追います。

最初に、基準の露出を作ります。カメラをMモード、ISO100、200分の1秒、f/8にします。ストロボを切ったまま一枚撮り、真っ黒であることを確かめます。これで定常光の露出は無視できる状態になりました。次に、キーライトを出力4分の1にして一枚撮ります。ヒストグラムを見ると、肌の山が中央から右寄りにあり、右端には何もありません。ハイライト警告も出ていません。これが基準の露出で、教材ではこの状態を、キー4分の1でf/8と呼んで各章で使います。もし肌の山が中央より左に寄っていれば、1段明るくします。選択肢は、絞りをf/5.6に開ける、出力を2分の1に上げる、ISOを200にする、ライトを1.1mに近づける、の四つで、どれも1段です。被写界深度を変えたくなければ、出力を上げるのが最も素直です。ライトを近づけると、光の質も変わります。シャッター速度を100分の1秒にしても、明るさは変わりません。

次の場面です。友人から、背景をもっとぼかした一枚も欲しいと言われたとします。絞りをf/8からf/4に開ければ、被写界深度は浅くなり、白ホリの壁の継ぎ目もぼけます。しかし絞りを2段開けると、ストロボ光の露出も2段明るくなって、肌が飛びます。自然光ならシャッター速度を2段速くして相殺するところですが、ストロボ光にはシャッター速度が効きません。代わりに、発光量で相殺します。出力を4分の1から2段落として16分の1にすれば、f/4で同じ肌の明るさになります。f/5.6なら1段なので8分の1、f/4なら2段なので16分の1、f/2.8なら3段なので32分の1という対応です。

ここで一つ問題があります。SK400IIの出力は16分の1が下限なので、f/2.8では出力だけでは足りません。そのときは、ライトを1段分離して1.5mから2.1mにするか、レンズにNDフィルターを付けます。NDフィルターは、光量を一様に減らすフィルターです。ライトを離すと光は硬くなり、被写体に当たる範囲も変わるので、絞りを大きく開けたい撮影では、NDフィルターのほうが配置を保てます。より小さい出力まで下がる機種を選ぶ理由の一つが、ここにあります。

三つ目の場面は、全身への切り替えです。被写体は同じ場所に立ち、カメラだけが下がって18-150mmの24mm域で撮るなら、ライトと被写体の距離は変わらず、露出も変わりません。カメラと被写体の距離は、ストロボ光の露出に関係がないのです。一方、全身を照らすためにソフトボックスを被写体から2.1mに引いたなら、ライトから被写体までの距離が1.4倍になって、1段暗くなります。出力を4分の1から2分の1に上げるか、絞りをf/5.6に開けて補います。被写界深度を保ちたいので、出力を上げます。ライトを動かしたら露出が変わる、という関係は、第4章の逆二乗則でもう一度扱います。

最後の場面は、服の色です。友人が白いシャツに着替えました。肌の露出は同じでよいはずですが、試し撮りをすると、シャツの胸元にハイライト警告が点滅しました。白い布は肌より2段ほど明るく写るので、肌を基準の明るさに置くと、シャツが右端に届くことがあります。このときの判断は、シャツの点滅が面で出ているかで決めます。胸元の一部が点滅する程度なら、出力を0.3段落とせば消えます。トリガーのXPro II-Cは0.1段刻みで出力を変えられるので、絞りを動かさずに済みます。面として広く点滅するなら1段落とし、肌は現像で少し持ち上げます。黒いセーターなら逆で、ヒストグラムの山が左に寄るのは服が黒いからで、露出不足ではありません。肌の山の位置だけを見て、基準のままにします。ヒストグラムは画面全体の分布なので、服の色によって山の位置は動きます。見るべきなのは、肌の部分がどこにあるかと、右端と左端に張り付いていないかです。

この章の内容を振り返ります。露出は絞り、シャッター速度、ISOで決まり、段という共通の物差しで交換できます。ストロボ撮影では、閃光時間がシャッターの開いている時間よりずっと短いので、ストロボ光の露出は絞り、ISO、発光量、距離の四つで決まり、シャッター速度は定常光にしか効きません。露出計の指針は当てにせず、試し撮りのヒストグラムとハイライト警告で判断します。次の第3章では、この考え方をEOS R10の設定に落とし込みます。
