# 第6章 一灯で撮るポートレート（読み上げ原稿）

対象章：[第6章 一灯で撮るポートレート](../06-one-light-portrait.md)（[演習問題](../exercises/06-one-light-portrait.md)）

第6章、一灯で撮るポートレート。この章では、ストロボを一灯だけ使って、人の顔を撮ります。第5章で、光の硬さは被写体から見た光源の大きさで決まり、影の落ち方は光源の方向で決まることを学びました。この章では、その二つの道具を一つのライトに絞って使います。

一灯だけで始めるのは、機材が足りないからではありません。ライトが一つなら、角度を10度変えたとき、高さを20センチ上げたとき、写真のどこがどう変わったかを一対一で確かめられるからです。第7章で二灯目、三灯目を足すときも、その効き方を一灯ずつ確かめる手順は変わりません。題材は、モデル役の友人の上半身です。背景紙のブースにグレーの背景紙を引き、キーライトの60×90センチのソフトボックスと、白いレフ板だけで撮ります。カメラの設定は第3章の基準、つまりMモード、ISO100、200分の1秒、f/8、ホワイトバランス5500ケルビン、RAW記録から動かさず、ストロボの出力と位置だけで写真を組み立てます。

まず、一灯の位置で決まる顔の陰影の型を整理します。顔には鼻という出っ張りがあるので、ライトの方向は鼻の影の形にそのまま現れます。ポートレートのライティングには、鼻の影の形で名前の付いた型が四つあります。型を覚える目的は、名前を言えるようになることではありません。モデリングランプで顔を見ながら、いまどの型に近く、どちらへ動かせば別の型になるかを判断できるようになることです。

一つ目はループライティングです。ライトをカメラから見て30度から45度の横、顔より少し高い位置に置いたときの型です。鼻の影は頬に向かって小さな輪、つまりループを描き、頬の影とはつながりません。顔の両側に光が回り、鼻筋と頬骨に立体感が出るので、プロフィール写真のように顔立ちを素直に見せたいときの出発点になります。

二つ目はレンブラントライティングです。ループの位置からライトをさらに横、45度から60度へ振り、高さも上げたときの型です。鼻の影が伸びて頬の影とつながり、影側の頬に逆三角形の光が取り残されます。この三角形は、画家レンブラントの肖像画によく見られることから、レンブラントの三角形と呼ばれます。顔の半分近くが影になるので陰影は強く、落ち着いた印象や重厚な印象に向きます。同じ被写体でも、ループより顔が細く見えます。

三つ目はバタフライライティングです。ライトをカメラのすぐ上、顔の正面の高い位置に置いたときの型です。鼻の真下に蝶の形をした影が落ち、頬骨の下にも影が入ります。顔が左右対称に照らされ、頬骨が強調されるので、美容写真や化粧品の広告で古くから使われてきました。一方で、目の下やあごの下にも影が落ちるので、下から白いレフ板を当てて影を起こすことが多い型です。第7章で扱うクラムシェルは、これをストロボで作るものです。

四つ目はスプリットライティングです。ライトを被写体の真横、90度、顔と同じ高さに置いたときの型です。顔の中心線で明るい側と影の側に分かれ、影側にはほとんど光が届きません。四つの中で最も陰影が強く、人物の性格や緊張を表現する写真に向きますが、プロフィール写真に使うことは少ないでしょう。

この四つの型は、不連続な選択肢ではありません。ライトを正面から横へ動かせば、バタフライ、ループ、レンブラント、スプリットの順に連続して変わります。だから実際の作業では、モデリングランプを点けたまま、ライトをゆっくり横へ動かして鼻の影を見ます。影が頬の影とつながった瞬間がレンブラントの始まりで、そこから少し戻せばループになります。

型の名前は、ライトと顔の角度で決まりました。これとは別に、被写体がカメラに対して顔を少し振っているときには、顔のどちら側にライトが当たるか、という区別が生まれます。顔を斜めに向けると、カメラから見て顔の片側は広く、つまり耳まで見える側になり、反対側は狭く見えます。広く見える側にキーライトが当たるのがブロードライティング、狭く見える側に当たるのがショートライティングです。ショートライティングでは、広く見える側が影になるので、顔の輪郭が引き締まって見え、立体感も出ます。ブロードライティングでは、顔の広い側がさらに明るく見えるので、顔が大きく、平坦に見えやすくなります。一般には、ショートライティングを基本にし、顔の細い人や、あえて柔らかく平坦に見せたい場合にブロードを選びます。

ここで注意したいのは、ライトの位置を動かさなくても、被写体に顔を反対側へ振ってもらうだけで、ブロードとショートは入れ替わることです。つまり同じループライティングでも、顔の向きによって印象は二通りあります。ライトの角度と被写体の顔の向きは、別々の操作として扱ってください。

次に、影側を明るくするフィルの話です。一灯だけで撮ると、影側の頬は光がほとんど届かず、レンブラントやスプリットでは真っ黒に落ちます。第5章で見たとおり、影を起こす二つ目の光をフィルと呼びます。一灯の撮影では、フィルにストロボを使わず、キーライトの光を反射して返す白いレフ板で作ります。レフ板は光源を増やさないので、影の形はキーライトが決めたまま、影の濃さだけを変えられます。

明るい側と影側の明るさの差は、第2章で学んだ段で数えます。この教材の基準では、白いレフ板をキーライトの反対側、被写体から1メートルに置くと、影側はキー側の約2段下になります。段差2、比で言えば4対1です。段差2は、影側の頬の肌の色が読め、それでいて立体感も残る、標準の陰影です。レフ板を50センチまで近づければ段差はおよそ1に縮んで柔らかい印象になり、レフ板を外せば段差は3以上に広がって陰影が強くなります。逆に影をもっと締めたいときは、影側に黒いレフ板を立てて、壁や天井から回ってくる光を吸わせます。これをネガティブフィルと呼びます。

レフ板の置き方には二つの注意があります。一つは高さです。被写体の顔と同じ高さか少し下に置き、面をわずかに上へ向けます。低すぎると顔の下から光が返り、あごの下だけが不自然に明るくなります。もう一つは角度です。レフ板はキーライトの光を鏡のように返すので、キーライトと被写体とレフ板の位置関係で、返る光の向きが決まります。モデリングランプを点けて、レフ板を少し振りながら影側の頬の明るさを見ると、最も効く角度が分かります。

もう一つ、ライトの高さを決める手がかりがあります。目には、光源が小さな白い点として映り込みます。この映り込みをキャッチライトと呼びます。キャッチライトが入ると目に潤いと生気が出て、入らないと同じ表情でも目が沈んで見えます。ソフトボックスなら四角い面が、アンブレラなら傘の形が映り、その位置と形でライトがどこにあったかが読めます。

キャッチライトの有無は、ライトの高さで決まります。ライトを高くするほど鼻の影は長く下に伸びて彫りの深い顔になりますが、高すぎると眉と上まぶたが目に影を落とし、キャッチライトが消えます。目安は、被写体の目の中で、キャッチライトが時計の10時か2時のあたりに映る高さです。12時に近ければライトが高すぎ、9時や3時に近ければライトが低すぎるか真横にあります。ライトの角度を型で決めた後、高さはキャッチライトの位置で決める、という順序にすると迷いにくくなります。

ここからは、実際に友人を撮る手順です。背景紙のブースにグレーの背景紙を引き、友人には背景紙から1.5メートル離れた位置に立ってもらいます。背景から離す理由は、キーライトの光を背景に届きにくくして、人物と背景を分けるためです。レンズはRF50ミリF1.8を付けます。フルサイズ換算で80ミリになります。カメラは被写体から約2メートルの位置で、上半身が収まる画角にします。カメラは第3章の基準どおり、Mモード、ISO100、200分の1秒、f/8、ホワイトバランス5500ケルビン、RAW、メカシャッターで、露出シミュレーションは「しない」に設定します。AFはワンショット、被写体検出は人物、瞳検出を有効にします。トリガーのXPro II-Cはチャンネル1、ストロボはグループAに設定し、モデリングランプを点けます。

配置を上から見た図で説明します。奥に背景紙、その1.5メートル手前に被写体、さらに2メートル手前にカメラがあります。キーライトの60×90センチのソフトボックスは、カメラから見て被写体の左45度、被写体から1.5メートル、ソフトボックスの中心が顔より30センチほど高くなる位置に置きます。面は顔へ向け、わずかに見下ろす角度にします。白いレフ板は被写体の右側、被写体から1メートル、顔の高さに立てます。設定値をまとめると、キーライトのグループAは出力4分の1で、顔の明るい側がf/8になります。白いレフ板による影側は約f/4で、キーの2段下です。この配置で、鼻の影は右の頬へ向かう小さな輪になり、ループライティングになります。友人の顔をカメラから見て少し右へ振ってもらうと、ライトはカメラから見て狭い側の顔に当たるので、ショートライティングのループになります。

ストロボの位置と出力は、次の順序で一つずつ決めます。一度に二つを変えると、写真の変化がどちらの操作によるものか分からなくなるからです。

第一に、影の形を決めます。モデリングランプの光で友人の顔を見ながら、ソフトボックスを横へ動かして鼻の影が小さな輪になる角度を探し、次に高さを上下して、キャッチライトが10時の位置に映る高さにします。ここではまだシャッターを切りません。第二に、環境光を確かめます。トリガーの電源を切り、ISO100、200分の1秒、f/8で一枚撮ります。ブースの窓を暗幕で塞いであれば画面は真っ黒になり、ストロボ以外の光が写っていないことが分かります。これは第2章で学んだ確認です。

第三に、キーライトの明るさを合わせます。トリガーの電源を入れ、レフ板を外した状態で一枚撮ります。ヒストグラムとハイライト警告を見て、顔の明るい側の肌が飛んでいれば出力を0.3段ずつ下げ、全体が暗ければ0.3段ずつ上げます。基準の配置なら出力4分の1でf/8が合いますが、肌の色や服の色で前後するので、写真で決めます。第四に、フィルを入れます。白いレフ板を1メートルの位置に立てて一枚撮ります。影側の頬に肌の色が戻り、段差2になっていることを確かめます。柔らかくしたければレフ板を近づけ、締めたければ遠ざけます。レフ板の操作ではキー側の明るさは変わらないので、出力は動かしません。

第五に、型を切り替えて撮り比べます。ソフトボックスを横へ15度振って高さを20センチ上げ、鼻の影が頬の影とつながるレンブラントで一枚、次にソフトボックスをカメラの真上へ移してバタフライで一枚撮ります。ライトを動かすと被写体までの距離が変わるので、そのたびに距離を1.5メートルに戻すか、変わった分を出力で補います。撮り比べた三枚を背面モニターで見比べると、同じ友人、同じカメラ設定で、印象の違いがライトの位置だけで作れていることが分かります。プロフィール写真として渡すのは、多くの場合ループかレンブラントのどちらかになります。

最後に、初めてのストロボ撮影で繰り返し起きる失敗と、その直し方を五つ挙げます。どれも原因はこの章と第5章の範囲にあり、機材を足さずに直せます。

一つ目は、顔の影側が濃すぎる失敗です。段差が3以上に開いています。直し方は三つあります。白いレフ板を被写体に近づけて段差を縮めるか、ソフトボックスをカメラ寄りの角度へ振って影側にも光を回すか、ソフトボックスを被写体に近づけて、見かけの大きさを増し、影の縁を柔らかくするかです。ソフトボックスを近づけると明るくなるので、1.5メートルから1.1メートルに近づけたら、出力を1段下げてf/8を保ちます。

二つ目は、目が暗く、キャッチライトが入らない失敗です。ライトが高すぎて、眉が目に影を落としています。ソフトボックスを10センチから20センチ下げるか、友人にあごをわずかに上げてもらいます。ライトの高さを下げると鼻の影は短くなるので、彫りの深さを保ちたいときは、角度を少し横へ振って補います。

三つ目は、背景が暗く落ちる失敗です。グレーの背景紙が、黒に近い濃いグレーに写ります。これは第4章の逆二乗則の帰結です。キーライトから被写体までが1.5メートル、背景までが3メートルなら、背景に届く光は被写体より2段暗くなります。グレーの紙はもともと白より反射が少ないので、写真ではさらに暗く見えます。人物を浮かび上がらせる意図なら、これは失敗ではなく狙いどおりです。背景を明るくしたければ、被写体と背景を近づけるか、第7章で学ぶ背景ライトを足します。被写体と背景を近づけると、被写体の影が背景に落ちる点には注意が要ります。

四つ目は、眼鏡にソフトボックスが映り込む失敗です。光は入射角と同じ角度で反射するので、レンズ面がカメラとソフトボックスの中間の向きを向いていると、映り込みがカメラに入ります。ソフトボックスを高くして見下ろす角度を強めるか、友人にあごを少し引いてもらい、反射の向きをカメラの上へ逃がします。それでも残る場合は、ライトを横へ振って反射をカメラの外へ出します。眼鏡のつるを耳の上でわずかに持ち上げて、レンズ面を下向きにする方法も、正面からの写真では効きます。

五つ目は、絞りを開けても出力が下がらない失敗です。背景をぼかそうとf/2.8にすると、f/8から3段明るくなりますが、SK400IIの出力は4分の1から2段しか下げられません。下限が16分の1だからです。1段分は距離で補い、ソフトボックスを1.5メートルから2.1メートルへ離します。ISOは100が下限なので、この方向には使えません。出力を128分の1まで下げられる機種なら、この問題は起きません。

一灯と白いレフ板で、上半身のプロフィール写真は撮れます。足りないのは、髪や肩の輪郭を背景から切り離すリムライトと、背景の明るさを人物と独立に決める背景ライトです。第7章でこの二つを足します。背景そのものを白く飛ばす白ホリの撮影は、背景ライトの使い方を覚えてから、第8章で扱います。
