# 第12章 総合演習（読み上げ原稿）

対象章：[第12章 総合演習](../12-capstone.md)（[総合演習問題](../exercises/12-capstone.md)）

第12章、総合演習。この章では、新しい道具は導入しません。一つの撮影を、依頼の受け取りから納品まで通しで計画し、これまでの章で学んだ判断を一つの撮影の中で組み合わせて使います。題材は、ここまでの友人のプロフィール写真とマグカップではなく、小さなカフェのWebサイトに載せる、スタッフ3人の写真とメニュー5品の写真です。慣れた題材を手放すのは、各章の判断が友人やマグカップという被写体の性質にではなく、用途と被写体の形と借りられる機材に結びついていることを、別の依頼で確かめるためです。スタジオは同じレンタルスタジオで、白ホリと背景紙のブースがあり、Godox SK400IIが3灯借りられます。借りるのは同じ半日、4時間です。

撮影の発端は、カフェのオーナーから、サイトを作り直すのでスタッフの写真とメニューの写真を撮ってほしい、と頼まれたことにします。撮影者はこの依頼を撮れる要件に分解し、灯と用具を配分し、時間割を組み、当日の確認点を決めます。

まず、計画の手順を整理しておきます。各章では、道具を一つずつ、それが解く問題と対にして学んできました。通しの撮影では、これらの判断が互いに依存し合いながら、おおむね決まった順序で現れます。最初に要件を整理する。何を、どの用途で、何カット撮り、どの形式で納めるか。これは第1章です。次に露出の基準を決める。用途と被写界深度から絞りを決め、ISOとシャッター速度を固定する。第2章です。次にカメラの設定。シャッター方式、AFかMFか、レンズと焦点距離、テザー撮影をするか。第3章です。次に灯数と用具。3灯に何を付け、どのグループに割り当てるか。第4章と第5章です。次に配置と出力。キー、フィル、背景の位置と出力を段差で組む。第6章から第10章です。そして確認。ヒストグラム、ハイライト警告、拡大表示で一灯ずつ確かめる。最後に撤収と納品。熱を冷ましてから片付け、バックアップし、現像して納める。第11章です。

この順序は工程表ではなく、依存の向きの整理です。絞りを決めずにストロボの出力は決められません。顔にピントが合えばよい写真と、皿の手前から奥までピントが要る写真では、絞りが2段違い、出力も2段違うからです。出力の段差を決めずに配置は決められません。フィルをキーの2段下にすると決めて初めて、白レフを1メートルに置くのか、アンブレラを2メートルに置くのかが決まります。実際の作業は段階を行き来しますが、後の段階の判断が前の段階の成果物に載っている、という向きは変わりません。

もう一つ、計画の性質について述べておきます。各章の後半には、決まってその道具の限界の話がありました。灯を増やすほどレンズに入る余計な光が増え、背景を明るくしすぎれば輪郭が溶け、環境光を混ぜれば色かぶりが起きる。通しの撮影では、この条件の照合が灯の数だけ繰り返されます。だから出来上がった計画は、使う灯と用具の一覧であると同時に、使わない灯とその理由の一覧にもなります。白ホリで背景を飛ばす撮影に、リムライトをわざわざ足す理由はありません。白い壁からの反射光が、髪と肩の輪郭をすでに縁取っているからです。逆に、ガラスの飲み物には正面からのキーライトが役に立たず、背後からの透過光に切り替えます。借りられる灯が3灯しかないという制約は、灯を増やして解くのではなく、被写体ごとにセットを組み替えて解きます。

時間の話もしておきます。半日4時間という枠は、撮る枚数ではなく、セットを組み替える回数で消えていきます。ライトの位置と出力を決めて、試し撮りで追い込む作業は、慣れていても20分から30分かかります。一方、セットが決まった後の1カットは、被写体を入れ替えて数枚撮るだけなので、10分あまりで済みます。したがって計画の中心は、同じセットで撮れる被写体をまとめ、組み替えの回数を最小にすることにあります。スタッフ3人は同じ配置で撮り、人ごとに変えるのはキーライトの高さだけにします。メニュー5品は、同じテーブルのセットで撮れる4品を先に撮り、セットの組み替えが要る1品を最後に回します。

ここからが本体です。まず要件です。オーナーの依頼を分解すると、こうなります。スタッフ3人は、サイトのスタッフ紹介に使う、白背景の上半身の写真で、各1カット、予備を含めて各5枚ほど撮ります。サイト側で正方形にトリミングされるので、3人で光と背景を揃える必要があります。メニューは5品。ホットコーヒーは陶器のカップで、カップの質感が分かること。アイスカフェラテはガラスのグラスで、ミルクとコーヒーの層が透けて見えること。ケーキはチーズケーキ、ガトーショコラ、フルーツタルトの3品で、表面の質感が分かり、皿の手前から奥までピントが合っていること。どれも白背景です。用途はサイトですが、オーナーは、後で印刷のメニュー表にも使うかもしれない、と言いました。だから記録はRAWにし、納品は長辺2,000ピクセルのJPEGとRAWの両方にします。白背景という条件は、スタッフとメニューで別の方法で満たします。スタッフは白ホリで背景を白く飛ばし、メニューは背景紙のブースで、白い背景紙をテーブルから壁へ立ち上げるスイープにします。要件の段階でもう一つ決めておくことがあります。ケーキと飲み物はスタジオで盛り付けるので、皿とカップとグラスを2組ずつ持ってきてもらい、アイスカフェラテは撮る直前に作ってもらいます。氷が溶けてグラスに結露が付くまでは10分あまりで、それがそのまま撮影に使える時間の上限になります。

次に、露出の基準を用途から決めます。第2章の順序どおり、絞りを先に決めます。スタッフの上半身は顔にピントが合えばよく、耳から鼻先までが被写界深度に入るf/8を基準にします。メニューは皿の手前の縁から奥のフルーツまでピントが要るので、f/16にします。ISOは100、シャッター速度は同調速度の250分の1秒に余裕を持たせた200分の1秒で、どちらの被写体でも変えません。シャッター速度はストロボ光の露出に効かず、環境光にしか効かないからです。この基準から、ストロボの出力が導かれます。教材の基準では、60かける90センチのソフトボックスを1.5メートルに置いて出力を4分の1にすると、f/8になります。物撮りではソフトボックスを1メートルまで近づけるので約1段明るくなり、出力4分の1でf/11になります。f/16にするには、そこからもう1段要ります。出力を2分の1に上げればよい、ということです。環境光の扱いも基準の段階で決めます。窓は暗幕で塞ぎ、撮影の最初にストロボを切って、ISO100、200分の1秒、f/8で1枚撮ります。真っ黒に写れば、以降の露出はストロボだけで決まると分かります。

カメラの設定は、被写体ごとに分けます。共通するのはMモード、ISO100、200分の1秒、RAW記録、ホワイトバランス5500K、メカシャッター、露出シミュレーションを「しない」にすることで、違うのは絞りとレンズとピントと保持です。スタッフはf/8、RF50mmのレンズ、換算80mmで被写体から2メートルほど。ピントはワンショットAFで、被写体検出を人物、瞳検出を有効にし、手持ちで撮ります。手持ちで構わないのは、ストロボの閃光時間が1000分の1秒前後で、被写体の動きを止めるからです。正方形にトリミングされるので、胸から上をフレームの中央3分の2に収め、上下に少し余白を残して撮ります。メニューはf/16、18から150mmのキットレンズの50mm前後で、被写体から80センチほど。ピントはマニュアルで、拡大表示で皿の手前3分の1に合わせます。三脚に据え、EOS Utilityでテザー撮影にします。構図を固定して品を入れ替えるためで、テザーにすると皿の手前と奥のピントをPCの画面で拡大して確かめられます。最初にグレーカードを1枚撮り、現像で全カットの色を同じ基準に揃えます。

3灯と用具の配分に進みます。灯は3灯しかなく、スタッフとメニューでは灯の役割が違うので、セットを二つに分けます。スタッフのセットは白ホリで、グループAをキーにして60かける90センチのソフトボックス、グループBとCを背景にして標準リフレクター、フィルは白レフ、スタンドにはサンドバッグを載せます。メニューのセットは背景紙のブースで、グループAだけを使い、ソフトボックスをキーにします。ケーキとホットコーヒーでは白レフと黒レフ、アイスカフェラテでは黒レフを2枚使い、どちらも白の背景紙とテーブルと三脚です。背景の2灯を同じグループにせず、BとCに分けるのは、壁の左右で明るさが揃わないときに片方だけ出力を変えるためです。トリガーのチャンネルは1、IDは3灯とも同じにします。メニューの撮影中、使わない2灯は電源を切ってブースの外に出しておきます。ブースの中で点いたままの灯は、意図しない反射を作るからです。

スタッフ写真の配置は、第8章の基準どおりです。上から見ると、いちばん奥に白ホリの壁があり、壁から1.5メートルの位置に標準リフレクターを付けた2灯が左右から壁に向いています。出力は16分の1で、壁面がf/11、キーの1段上になります。壁から2.5メートル以上離れたところに被写体が立ち、その斜め前45度、顔より少し上、1.5メートルの位置にソフトボックスのキーがあります。出力は4分の1で、顔がf/8です。キーの反対側、被写体から1メートルに白レフを立て、影側をキーの約2段下に起こします。カメラは被写体から2メートルほどです。被写体を壁から離すのは、キーの光を壁に届かせないためと、壁からの反射光が顔まで回り込んでコントラストを下げないためです。背景はキーの1段上にとどめます。2段を超えると、白い壁からの光が髪の縁を溶かし、黒い髪まで白く飛びます。

確認は、第7章の手順で一灯ずつ行います。まずキーだけを点け、顔にf/8が出ているかをヒストグラムで見ます。次に白レフを置き、影側の頬が真っ黒でないことを見ます。最後に背景の2灯を点け、ハイライト警告が壁だけに出て、顔と髪には出ないことを見ます。この順序を守ると、背景を点けたあとに顔が明るくなったなら、その原因が背景の回り込みだと切り分けられます。3人を同じ条件で撮るために、床にテープで立ち位置を貼り、カメラの位置も印を付けます。人ごとに変えるのはキーライトの高さだけです。顔より少し上から見下ろす角度を保つために、身長に合わせてスタンドを上下し、ソフトボックスの向きを顔に向け直します。出力と距離は変えません。1人あたり12分から15分で、表情を変えて5枚ほど撮ります。

メニュー写真に移ります。背景紙のブースでは、テーブルに白の背景紙を敷き、後ろの壁に向けて立ち上げるスイープを作ります。ケーキとホットコーヒーは同じセットです。ソフトボックスを皿の上後方、やや斜め後ろ45度の上、1メートルの位置に置き、出力2分の1で皿の上面をf/16にします。カメラ側の手前、皿から30センチに白レフを立てて、手前の影を起こします。キーを斜め後ろの上から当てるのは、ケーキの表面の凹凸に影を作り、質感を出すためです。正面から当てると、チーズケーキの表面は平らな白い面になってしまいます。ホットコーヒーの陶器のカップには、ソフトボックスの白い映り込みが側面に出ます。これを消すのではなく、黒レフで側面に暗い縁を作って丸みを出します。背景紙のスイープは、キーの光が壁の部分まで届かないので、写真の上のほうが灰色に落ちます。ここでは灯を増やさず、現像で背景を白に持ち上げると判断します。皿の周囲だけが白ければ、切り抜きの手間は少ないからです。

アイスカフェラテは、同じセットでは撮れません。ガラスの中の層は、後ろから光を透過させないと見えないからです。ソフトボックスをグラスの真後ろ1メートルに置き、出力2分の1で直接透過させます。ソフトボックスの面そのものが白い背景になります。グラスの輪郭は透過光の中に溶けるので、左右に黒レフを立て、縁に黒い反射を作って形を出します。氷と結露の時間を考え、セットを組んで、水を入れたグラスで試し撮りを済ませてから、オーナーに作ってもらいます。

タイムテーブルは、組み替えの回数から逆算します。13時に搬入と機材の点検、暗幕、環境光の確認で20分。13時20分から白ホリのセットを組んで試し撮りで30分。13時50分からスタッフ3人で45分。14時35分から白ホリを片付けて背景紙のブースへ移動し、テーブルとスイープ、三脚とテザーの準備で30分。15時5分からグレーカード、ケーキ3品、ホットコーヒーで60分。16時5分から透過光のセットに組み替え、アイスカフェラテで30分。16時35分から撤収とバックアップで25分です。スタッフは13時50分、ケーキは15時までに持ってきてもらい、アイスカフェラテは16時20分頃に作ってもらいます。早く進んだ時間はそのまま予備にし、遅れたときはスタッフの予備カットとケーキの構図の追加を削ります。削れない工程は、環境光の確認と、一灯ずつの確認と、バックアップです。

当日の確認点は、第11章の項目を被写体に合わせて絞ります。スタッフでは、ハイライト警告が壁だけに出ているか、瞳にピントが来ているか、3人のヒストグラムの山の位置が揃っているか。ケーキでは、皿の手前と奥の両方にピントが来ているか。ホットコーヒーでは、カップの映り込みが縦に一本の帯になっているか。アイスカフェラテでは、層の境目が透けていて、グラスの縁が背景に溶けていないか。トラブルが起きたら、第11章の切り分けをそのまま使います。発光しないならトリガーの電源、チャンネル、シャッター方式の順に見る。写真の下に黒い帯が出るなら、シャッター速度が同調速度を超えている。ファインダーが暗いなら、露出シミュレーションの設定が戻っている、という具合です。

最後に納品までです。撤収でモデリングランプを切り、灯が冷めるまでの時間でカードの中身をPCと外付けドライブの2か所に写します。現像では、まずグレーカードのカットでホワイトバランスを取り、メニューの全カットに適用します。スタッフは正方形にトリミングし、壁の部分が完全な白になるまで白レベルを上げます。背景がキーの1段上で撮れていれば、この操作で顔の階調は変わりません。メニューは背景紙の灰色の部分を白に持ち上げ、皿の影の境界だけを残します。長辺2,000ピクセルのJPEGを書き出し、RAWと一緒に納めます。

計画の全体を振り返ると、新しい道具は一つも使っていません。絞りを用途から決め、出力を絞りから決め、配置を段差から決め、時間をセットの組み替えから決めました。この順序は、被写体が友人からカフェのスタッフに変わっても、マグカップからケーキに変わっても変わりません。総合演習問題では、この撮影の場面を使って、第1章から第11章までの要点を30問で確かめます。
