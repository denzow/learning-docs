# 第1章 スタジオ撮影の全体像（読み上げ原稿）

対象章：[第1章 スタジオ撮影の全体像](../01-overview.md)（[演習問題](../exercises/01-overview.md)）

第1章、スタジオ撮影の全体像。この章では、スタジオ撮影が自然光の撮影と何が違うのか、レンタルスタジオにはどんな設備があるのか、どの機材が何を担うのか、そして撮影の一日はどう進むのかを、先に見渡しておきます。細かい設定や配置は第2章以降で一つずつ扱いますので、この章では個々の数値を覚える必要はありません。代わりに、教材を通して使う題材と機材、そして各章が出発点にする基準の設定を紹介します。

まず、自然光の撮影との違いから始めます。屋外や窓際で人物を撮った経験があれば、光が写真を決めることは体で分かっていると思います。曇りの日は顔の影が薄く、晴れた日の正午は目の下に濃い影が落ち、夕方の窓際は片側だけが暖かく照らされます。ただし自然光の撮影では、その光を選ぶことはできても、作ることはできません。スタジオ撮影は、この関係を逆にします。光のない部屋に自分で光源を置き、明るさも向きも柔らかさも自分で決めるのです。

スタジオ撮影が自然光の撮影と違う点は、突き詰めると二つあります。一つ目は、光を自分で作るので、同じ結果を何度でも再現できることです。自然光は時刻と天候で刻々と変わるため、同じ場所で撮っても昨日と今日で写りが違います。これに対して、暗幕で窓を塞いだスタジオでは、光源はストロボだけになります。ストロボの位置、高さ、向き、出力を記録しておけば、来月同じスタジオを借りても同じ写りが得られます。逆に言えば、写りが気に入らないときは、その原因が必ず自分の置いた光の中にあります。

二つ目は、ファインダーで見えている明るさと、写る明るさが一致しないことです。自然光の撮影では、ファインダーに映る明るさがそのまま写真の明るさになります。ところがストロボは、シャッターが開いている一瞬だけ強い光を出す装置です。シャッターを切るまでは、その光はどこにも存在しません。だからファインダーには、部屋の薄暗い定常光しか映らず、写真の明るさは撮ってみるまで分かりません。この違いが、スタジオ撮影のほとんどの戸惑いの源になります。ファインダーで見て明るさを決める習慣をいったん捨て、撮った結果のヒストグラムで判断する習慣に置き換える必要があります。これは第2章で扱います。

ここで用語を一つ補っておきます。この教材でストロボと呼ぶのは、キセノン管を放電させて閃光を出す写真用の照明です。フラッシュと同じ意味で、カメラに内蔵された小さなものも、スタンドに載せる大型のものも含みます。モノブロックは、電源部と発光部が一体になった、スタンドに載せるタイプを指します。

とはいえ、まったくの手探りではありません。ストロボにはモデリングランプという、閃光の代わりに光の向きを見せるための定常光が付いています。影の落ち方や光の当たる範囲は、モデリングランプで確かめられます。確かめられないのは明るさだけであり、それは試し撮りで合わせます。スタジオ撮影とは、光の向きと形をモデリングランプで作り、明るさを試し撮りで合わせる作業だと言えます。

次に、レンタルスタジオの設備を見ておきます。個人が借りられるレンタルスタジオには、大きく二種類の撮影スペースがあります。一つは白ホリです。壁と床を白く塗り、壁と床の境目を曲面でつないだ部屋で、この曲面をアール面と呼びます。境目の線が写らないので、背景を真っ白に飛ばして人物だけを浮かせる撮影や、床まで含めた全身の撮影に向きます。全身を撮るには被写体を壁から離す距離が要るので、白ホリは奥行きのある部屋になっています。白ホリでの撮り方は第8章で扱います。

もう一つは、背景紙を使うブースです。天井近くに取り付けたロールから幅2.72メートルの紙を引き出し、床まで垂らして背景にします。白、グレー、黒のほか、さまざまな色の紙があり、撮影のたびに巻き替えられます。白ホリより狭くて済む代わりに、幅が紙の幅に限られるので、上半身や一人の全身の撮影が中心になります。背景紙の扱いは第9章で扱います。どちらの部屋でも、撮影に使う機材はほとんど同じです。違うのは背景の作り方と、被写体を置ける広さだけです。この教材の題材では、両方の部屋を持つスタジオを借り、白ホリで人物を、背景紙のブースで商品を撮ります。人物の上半身は、背景の扱いを学ぶために、背景紙のブースでも撮ります。

続いて、機材とその役割です。スタジオ撮影の機材は、光を出すもの、光の形を変えるもの、それらを支えるもの、そしてカメラに分けられます。光を出すのは、Godox の SK400II というモノブロックストロボです。閃光を出す本体で、出力は最大の1分の1から16分の1まで変えられ、モデリングランプで光の向きを確かめられます。もう一つ、光を出す側に属するのが Godox の XPro II-C というワイヤレストリガーです。カメラのホットシューに付けて、シャッターと同時に電波でストロボを発光させます。ストロボの出力もこのトリガーから変えられます。ストロボとトリガーの間の通信は、Godox の X システムという2.4ギガヘルツの電波で行います。

光の形を変える用具には、ソフトボックスとアンブレラ、標準リフレクターとグリッド、そして白と黒のレフ板があります。ソフトボックスとアンブレラは光源を大きくして光を柔らかくします。標準リフレクターとグリッドは光を狭い範囲に集めて、硬い光や背景専用の光を作ります。白レフ板は光を反射して影を薄め、黒レフ板は光を吸って影を締めます。これらを支えるのがライトスタンドとサンドバッグです。サンドバッグはスタンドの転倒を防ぐ重りです。

カメラは Canon EOS R10 です。APS-C のミラーレスカメラで、電子シャッターではストロボが使えないので、メカシャッターか電子先幕で撮ります。レンズは、全身とテーブル上の商品には RF-S 18-150ミリのキットレンズを、上半身には RF 50ミリ F1.8 を使います。50ミリはフルサイズ換算で80ミリになります。ストロボは3灯まで借りられ、トリガーからは灯ごとに別の出力を指定できます。一灯で始めて、必要に応じて二灯目、三灯目を足していくのが、この教材の章の進み方でもあります。一灯は第6章、多灯は第7章で扱います。

では、撮影日はどう進むのでしょうか。スタジオは時間で借りるので、撮影日の作業は限られた時間に収める必要があります。半日、4時間の撮影であれば、流れはおおむね次のようになります。まず入室し、借りる機材をそろえ、ストロボをスタンドに載せて電源を入れます。次に、カメラをスタジオ向けの設定にし、トリガーを付けて、一灯が発光することを確かめます。そのうえで被写体を立たせ、モデリングランプで光の向きを決め、試し撮りで明るさを合わせます。ここまでできたら本番を撮り、合間にヒストグラムと拡大表示で露出とピントを確かめます。次の被写体や背景に移ったら、光の向きと明るさを合わせる作業からやり直します。最後に撤収し、機材を冷ましてから返します。

この流れの中で、初心者が時間を使いすぎるのは、光の向きと明るさを合わせる段階です。光の位置を少し動かすたびに明るさが変わり、明るさを直すと影の形も変わって見えるためです。これを短く済ませる鍵は、出発点となる配置と設定を先に決めておき、そこからの差分だけを調整することにあります。この教材が基準の設定を用意しているのはそのためです。細かい段取りとトラブルへの対処は、第11章で扱います。

ここで、安全について確かめておきます。スタジオの機材は家庭の照明より重く、熱く、電圧も高いからです。まず、スタンドの転倒です。ソフトボックスを付けたストロボは重心が高く、脚に触れただけで倒れます。スタンドの脚には必ずサンドバッグを載せ、脚を最大まで広げます。次にケーブルです。モノブロックは AC 電源で動くので、床にケーブルが這います。人が通る場所は避けるか、養生テープで床に留めます。そしてモデリングランプの熱です。150ワットのモデリングランプは、点けたままにするとリフレクターやソフトボックスの内側が触れないほど熱くなります。撤収の前には切って冷まし、用具を外すときは布を使います。

被写体の目にも配慮が要ります。ストロボの閃光は一瞬ですが、近距離で目に向けて何度も発光させると疲れます。テスト発光は被写体に向けずに行い、本番の枚数も必要な分にとどめます。最後に放電です。モノブロックは内部に高電圧を蓄えるので、電源を切っても分解したり濡らしたりしません。これらは撮影の技術とは別の話ですが、レンタルスタジオでは機材の破損が弁償につながります。配置を変えるたびにサンドバッグを載せ直す習慣を、最初につけておきましょう。

以降の章の見取り図も述べておきます。第2章から第5章までが道具の理解です。第2章は露出の基本で、絞り、シャッター速度、ISO の関係と、ストロボ撮影でそのどれが効くかを扱います。第3章は EOS R10 をスタジオ向けに設定する章で、M モード、シャッター方式、オートフォーカス、レンズを扱います。第4章はモノブロックストロボとトリガーの操作で、出力と距離で明るさを決める考え方を学びます。第5章は光の質と方向で、ソフトボックスやレフ板が何を変えるかを扱います。

第6章から第10章までが光の組み立てです。第6章は一灯とレフ板でポートレートを撮り、第7章は二灯目、三灯目を足して多灯にします。第8章は白ホリで背景を白く飛ばし、全身を撮ります。第9章は背景紙の色と明るさを操り、環境光の混入を防ぎます。第10章は商品を撮る章で、反射と被写界深度を扱います。そして第11章と第12章が運用です。第11章は撮影当日の段取りとトラブル対処、データの扱いを、第12章は別の題材で撮影計画を通しで立てる総合演習を扱います。

ここからは、具体例として、この教材で使う題材と基準の設定を紹介します。題材は一つの撮影です。モデル役の友人のプロフィール写真を上半身と全身で撮り、あわせて、ハンドメイド雑貨のオンラインショップに載せる陶器のマグカップの商品写真を撮ります。場所はレンタルスタジオで、半日借ります。スタジオには、幅5メートル、奥行6メートル、天井3.5メートルの白ホリと、幅2.72メートルの白、グレー、黒の背景紙があるブースがあり、窓は暗幕で塞げます。ストロボは3灯借ります。

各章は、次の基準の設定から出発し、章の目的に合わせて一部を変えます。カメラは M モードで、ISO 100、シャッター速度は200分の1秒、絞りは f/8、ホワイトバランスは5500ケルビン、記録は RAW です。キーライトは、60かける90センチのソフトボックスを付けたストロボ1灯です。被写体の斜め前45度、顔より少し上から見下ろす角度で、被写体から1.5メートルの位置に置きます。出力は4分の1です。この位置と出力で、被写体の顔が f/8 で適正になります。上から見た配置図で言えば、上に白ホリの壁、中央に被写体、その左手前に斜め45度でソフトボックス、そして下にカメラがある形です。以降の章の配置図も、背景を上、カメラを下に置いて描きます。

この基準には、後の章で使う二つの性質が含まれています。一つは、シャッター速度の200分の1秒が、ストロボの同調速度である250分の1秒より遅いことです。同調速度以下であれば、シャッター速度を変えても閃光の写りは変わりません。これは第2章で扱います。もう一つは、明るさが出力と距離で決まることです。ライトを被写体から2倍の距離に離すと2段暗くなり、出力を1段上げると1段明るくなります。これは第4章で扱います。基準の位置で f/8 になるという事実を一つ覚えておけば、そこからの変化は段の足し引きで見積もれます。

撮影日にこの基準を組んだら、本番の前に二枚だけ試し撮りをします。一枚目は、トリガーの電源を切って撮ります。ISO 100、200分の1秒、f/8 では、モデリングランプだけの部屋は真っ黒に写ります。これで、部屋の定常光が写真に影響していないことが確かめられます。もしうっすら写るなら、暗幕の隙間や天井の照明が残っています。これは第9章で扱います。

二枚目は、トリガーの電源を入れて撮ります。今度は被写体の顔が写り、ヒストグラムの山が中央付近に来ます。ここで顔が暗ければ出力を上げ、明るければ下げます。出力の一目盛りは0.1段なので、ヒストグラムを見ながら数目盛りずつ動かせば、数枚で合います。この二枚の試し撮りは、以降のどの章の配置でも最初に行います。一枚目で、写っている光はすべて自分が置いた光であることを確かめ、二枚目でその光の明るさを合わせます。自然光の撮影にはなかったこの手順が、スタジオ撮影の再現性を支えています。

この章のまとめです。スタジオ撮影は、光を自分で作るので再現でき、その代わりファインダーの明るさは写りを示さないので、向きはモデリングランプで、明るさは試し撮りで決めます。レンタルスタジオには白ホリと背景紙のブースがあり、機材は光を出すもの、形を変えるもの、支えるもの、カメラに分かれます。撮影日は基準の配置から出発して差分だけを調整し、サンドバッグと熱に気をつけて機材を扱います。次の第2章では、露出の基本と、ストロボ撮影で絞り、シャッター速度、ISO のどれが効くのかを学びます。
