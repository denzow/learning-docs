# 第3章 EOS R10 のスタジオ向け設定（読み上げ原稿）

対象章：[第3章 EOS R10 のスタジオ向け設定](../03-camera-setup.md)（[演習問題](../exercises/03-camera-setup.md)）

第3章、EOS R10のスタジオ向け設定。この章では、ストロボ撮影の露出の考え方を、EOS R10の具体的な設定に落とし込みます。撮影モードと基準の値、ファインダーの見え方、シャッターの方式、ホワイトバランスと記録形式、AF、レンズの選び方、そしてパソコンに画像を送るテザー撮影まで、一つずつ、何を、どの値に、なぜ設定するのかを確認していきます。

まず、なぜスタジオではカメラの設定を固定するのかを押さえます。第2章で、ストロボ撮影の露出を決めるのは絞り、ISO、発光量、距離の四つであり、シャッター速度は同調速度以下なら環境光にしか効かないことを学びました。自然光で撮るときは、カメラの自動露出とオートホワイトバランスに多くを任せられました。しかしカメラは、これから光るストロボがどれだけの光を出すのかを知りません。自動に任せると、カメラはモデリングランプと部屋の照明という、撮影には使わない光を基準にして、明るさも色も決めてしまいます。だからスタジオでは、カメラの設定を先に固定して、光の側を動かして絵を作ります。

一つ目は撮影モードです。モードダイヤルはM、マニュアルにします。AvやTvのような自動露出のモードでは、カメラは環境光を測って絞りやシャッター速度を動かしますが、その環境光はストロボが光った瞬間には主役ではありません。暗いスタジオで自動露出に任せると、長いシャッター速度と高いISOが選ばれて、ストロボの光に環境光まで乗った、ブレて色の濁った写真になります。Mモードなら、カメラは何も動かさず、露出は撮影者が決めた値のまま止まります。

基準の値は、ISO 100、シャッター速度200分の1秒、絞りf/8です。ISOは100に固定して、ISOオートは切ります。ISOオートは環境光を基準に感度を上げるので、Mモードでも露出が固定されなくなるからです。シャッター速度は、同調速度である250分の1秒より少し遅い200分の1秒にしておきます。こうしておくと、ワイヤレストリガーの伝達にわずかな遅れがあっても、画面の一部が黒くなる事故を避けられます。絞りf/8は、顔全体にピントが合い、ストロボの出力にも余裕がある値です。明るさはここからストロボ側で合わせます。

ISO 100を使うために、切っておく機能が二つあります。一つは高輝度側・階調優先です。これは白飛びを抑える代わりに、使えるISOの下限を200に上げてしまう機能で、有効になっているとISO 100が選べません。もう一つはオートライティングオプティマイザです。暗い部分を自動で持ち上げる機能で、背面モニターで見る画像を実際の露出より明るく見せてしまいます。RAWで記録する場合、現像するときにはどちらの機能も効きません。つまり、撮影時の判断を狂わせるだけの機能なので、両方とも「しない」にします。

二つ目は、ファインダーの見え方です。Mモードで、ISO 100、200分の1秒、f/8に設定してファインダーを覗くと、モデリングランプだけのスタジオでは、画面がほとんど真っ暗になります。これは故障ではありません。ミラーレスカメラのファインダーは、その設定で撮ったらどう写るかを、環境光から計算して表示しています。これを露出シミュレーションと呼びます。自然光では便利な機能ですが、ストロボの光を含めずに計算するので、スタジオでは構図もピントも確認できない画面になってしまいます。

そこで、撮影メニューの中にある露出シミュレーションの項目を「しない」にします。するとファインダーと背面モニターは、設定に関係なく見やすい明るさで表示されるようになります。ただし、その明るさは撮影結果とは無関係になることを覚えておいてください。露出の判断は、撮影した画像とヒストグラムで行います。なお、ストロボと通信できるトリガーを付けて電源を入れると、露出シミュレーションが自動で切れる場合もあります。ファインダーが暗いままなら設定で切ればよく、どちらでも結果は同じです。

同じ理由で、ファインダーの下に出る露出計の指針も無視します。指針はモデリングランプと部屋の照明を測って、3段以上のアンダーを示し続けます。これは環境光が写らないことの確認にはなりますが、ストロボの露出については何も語っていません。指針を0に合わせようとしてISOやシャッター速度を動かすのが、自然光に慣れた撮影者がスタジオで最初にやりがちな失敗です。

三つ目は、シャッター方式です。EOS R10には、メカシャッター、電子先幕、電子シャッターの三つがあります。電子シャッターは無音で1万6千分の1秒まで切れますが、ストロボと組み合わせることができません。電子シャッターではセンサーの読み出しが上から下へ順に進むため、画面全体が同時に露光している瞬間がなく、一瞬で終わるストロボの光を全面に受けられないからです。電子シャッターを選んだままだと、トリガーを付けていてもストロボは発光しません。

スタジオでは、メカシャッターか電子先幕を使います。どちらも、画面全体が開いている瞬間を作れる最速のシャッター速度、つまりストロボの同調速度は250分の1秒です。これより速い速度では、幕が画面の一部を覆っている間にストロボが光ってしまい、画像の端が黒い帯になります。教材で200分の1秒を基準にするのは、この帯の事故を避ける余裕です。ワイヤレストリガーは電波を受けてからストロボを光らせるまでにわずかな遅れがあり、同調速度ぎりぎりでは画面の端に細い暗い帯が出ることがあります。

ここで一つ確認しておきます。環境光が写り込まない限り、200分の1秒と60分の1秒で写りは変わりません。ストロボの閃光時間は800分の1秒から2000分の1秒程度で、被写体を止めているのはシャッターではなく、ストロボの光だからです。スタジオで窓の光や照明を意図的に混ぜるときだけ、シャッター速度を遅くして環境光の量を調整します。これは第9章で扱います。

四つ目は、ホワイトバランスと記録画質です。ホワイトバランスは、オートではなく、色温度を数値で指定するK指定にして、5500Kにします。オートホワイトバランスは、撮影前の画面に写っているモデリングランプの暖色を打ち消そうとして、ストロボの光で撮れた画像を青く転ばせることがあります。しかも1枚ごとに違う補正がかかるので、同じ設定で撮った写真の色がそろわず、あとで整える手間が増えます。ストロボの光の色温度は5600K前後なので、5500Kに固定すれば、ほぼ見た目どおりの色になり、全カットの色がそろいます。厳密に合わせたいときは、グレーカードでカスタムホワイトバランスを取ります。これも第9章で扱います。

記録画質はRAWにします。RAWはセンサーが受けた光の情報をそのまま保存する形式で、ホワイトバランスと1段程度の露出の違いは、現像のときに画質を落とさずに直せます。ストロボ撮影では試し撮りで露出を追い込むとはいえ、本番の途中でライトの距離が変わるなどのずれは起きるので、この余裕が保険になります。その場で共有したいときは、JPEGも同時に記録しておくと便利です。ピクチャースタイルは、スタンダードかニュートラルでかまいません。RAWで記録するなら、ピクチャースタイルが影響するのは背面モニターの表示とJPEGだけです。ただし、コントラストの強いスタイルは背面モニターで白飛びを実際より多く見せるので、露出を判断するにはニュートラルが向いています。

五つ目は、AFの設定です。AF動作はONE SHOT AFにします。ポートレートではモデルは決められた位置に立ち、動きは少ないので、シャッターボタンの半押しで一度ピントを合わせて止める方式で十分です。動く被写体を追い続けるSERVO AFは、ストロボのチャージを待っている間にピントが背景へ動くことがあり、スタジオでは利点が少ないです。

被写体検出は人物、瞳検出は「する」にします。EOS R10は画面内の顔と瞳を検出して、AFエリアを全域にしておけば、瞳に自動でピントを合わせます。f/8なら被写界深度は顔全体を覆いますが、f/1.8のような開放に近い絞りでは、瞳にピントが来ているかどうかが写真の出来を決めます。横顔やうつむいた姿勢で被写体検出がうまく働かないときは、1点AFに切り替えて、手前の目に合わせます。物撮りではAFではなく、手動ピントと拡大表示を使います。三脚に固定したカメラで、被写体のどこにピントを置くかを自分で決めたほうが、AFがラベルや模様の目立つ場所を選ぶより確実だからです。

六つ目は、レンズと焦点距離です。EOS R10のセンサーはAPS-Cで、同じ焦点距離のレンズでもフルサイズより狭い範囲を写します。レンズに書かれた焦点距離を1.6倍すると、フルサイズで同じ画角になる焦点距離になります。RF 50mm F1.8 STMはフルサイズ換算で80mmにあたり、これはポートレートで長く使われてきた85mmに近い画角です。被写体から2mほど離れて上半身を切り取ると、顔の輪郭が自然で、背景も整理しやすくなります。

全身は、キットレンズのRF-S 18-150mmの24mmから35mm、換算で38mmから56mmで撮ります。白ホリの奥行きは6mで、被写体を壁から2.5m以上離すと、カメラは被写体から3.5mまでしか下がれません。身長170cmのモデルを縦位置で余白を含めて収めるには、35mmでは3.5m近く必要で、24mmから28mmならもう少し余裕があります。ただし、焦点距離が短いほど、手前の手や足が大きく写る歪みが出やすいので、下がれる範囲で長いほうを選びます。

キットレンズの開放F値は暗めですが、ストロボ撮影では問題になりません。教材の基準はf/8であり、明るさはストロボの出力で作るので、レンズの明るさが露出を制約することはないからです。手ブレ補正は、手持ちならそのまま、三脚に載せるなら切ります。

七つ目は、テザー撮影です。テザー撮影とは、カメラをパソコンにつないで、撮った画像をその場で大きな画面に送る撮り方です。EOS R10はUSB-Cケーブルで接続し、キヤノンのEOS Utilityを使うと、シャッターを切るたびに画像がパソコンの指定したフォルダに保存され、画面に表示されます。背面モニターは3インチしかなく、ピントのわずかな甘さや、髪の毛の端に出たフレアは見落としやすいものです。ライティングを組み立てている間は、1枚撮るごとにパソコンの画面で確認できると、判断が速く確実になります。Wi-Fiでも接続できますが、RAWの転送には時間がかかるので、撮影のテンポを保つにはUSB接続のほうが向いています。ケーブルはスタンドやモデルの足に引っかけやすいので、床に這わせてテープで留めるか、長さに余裕のあるものを使います。

それでは、モデル役の友人のプロフィール写真を撮る日を例に、スタジオに入ってから最初の試し撮りまでの手順を通して確認します。ストロボの設置と出力の決め方は第4章と第6章に任せて、ここではカメラの側だけを追います。

まずバッテリーを入れ、SDカードを初期化して、日時が合っていることを確認します。次にモードダイヤルをMにして、ISO 100、200分の1秒、f/8に合わせ、ISOオートになっていないことを確かめます。撮影メニューの中で、高輝度側・階調優先とオートライティングオプティマイザを「しない」にします。シャッター方式をメカシャッター、または電子先幕にします。電子シャッターのままではストロボが光りません。続いて露出シミュレーションを「しない」にして、ファインダーが見やすい明るさになったことを確かめます。

次に、ホワイトバランスをK指定に切り替えて5500Kを指定し、記録画質をRAW、必要ならRAWとJPEGの同時記録にして、ピクチャースタイルをニュートラルにします。AF動作をONE SHOT AF、AFエリアを全域、被写体検出を人物、瞳検出を「する」にします。再生メニューの中でハイライト警告を「する」にして、再生時にヒストグラムが出る表示に切り替えておきます。ここまでできたら、トリガーをホットシューに付けて電源を入れ、テザー撮影をするならUSB-Cでパソコンにつないで、EOS Utilityで保存先のフォルダを指定します。

最後に、ストロボを切ったまま、モデルの立ち位置に向けて1枚撮ります。真っ黒に写れば、この設定では環境光は写りません。この試し撮りは環境光の確認であると同時に、電子シャッターやISOオートのような設定の取りこぼしを見つける手順でもあります。ここで真っ黒にならないときは、シャッター速度とISOが基準からずれているか、暗幕が開いています。

この日のレンズの使い分けもまとめておきます。上半身はRF 50mm、換算80mmで、被写体から約2m、絞りf/8です。全身はRF-S 18-150mmの24mmから28mm、換算38mmから45mmで、約3m離れて、同じくf/8です。マグカップの商品写真は、18-150mmの50mm前後で約60cmまで寄り、被写界深度を稼ぐためにf/11にします。これは第10章で扱います。

本文には、ここまでの設定を理由とともに並べた一覧の表を載せています。撮影のたびにこの表を見返せば、設定の取りこぼしを防げます。

この章のまとめです。スタジオでは、カメラに露出と色を決めさせず、Mモード、ISO 100、200分の1秒、f/8、ホワイトバランス5500K、RAWという設定に固定して、明るさはストロボ側で作ります。ファインダーが暗いのは露出シミュレーションのせいなので「しない」にし、露出計の指針は無視して、撮影後のヒストグラムで判断します。電子シャッターではストロボが光らないので、メカシャッターか電子先幕を使い、同調速度に余裕を持たせます。焦点距離は1.6倍で換算し、上半身は50mm、全身はキットレンズの広角側で撮ります。次の第4章では、この設定のカメラに合わせて、モノブロックストロボとワイヤレストリガーをどう扱うかを学びます。
