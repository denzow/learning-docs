# 第8章 白ホリでの撮影（読み上げ原稿）

対象章：[第8章 白ホリでの撮影](../08-white-cyc.md)（[演習問題](../exercises/08-white-cyc.md)）

第8章、白ホリでの撮影。この章では、白ホリで背景を意図した明るさにする方法を学びます。背景を真っ白に飛ばすには背景ライトをどれだけ明るくすればよいのか、なぜ明るすぎてはいけないのか、被写体を壁からどれだけ離すのか、床の反射をどう扱うのか、全身を撮るときの焦点距離とカメラの高さ、切り抜き用の撮り方、そして背景ライトを使わずに白ホリを灰色に落とす方法までを扱います。

まず、この章の問いを確認します。第6章と第7章では友人の上半身を撮りました。そこでは背景の明るさを積極的には決めておらず、キーライトの光がどれだけ背景に届くかで背景の調子が決まっていました。プロフィール写真の残りの一枚は全身で、しかも背景を真っ白に抜きたい。ここで気をつけたいのは、背景を白くするのは、白い面を背景に置くだけでは足りない、ということです。白い壁も、光が当たらなければ灰色に写ります。背景の明るさは、被写体の明るさと同じように、自分で決めて作るものです。

白ホリの構造から説明します。白ホリは、壁と床を曲面でつないだ、継ぎ目のない白い面です。壁と床の境界を曲面にしてあるので、写真に壁と床の境界線が写りません。この曲面をR面と呼びます。普通の部屋を背景にすると、壁と床の角に影の線が入って奥行きが見えてしまいますが、白ホリではその線がなく、被写体が白い空間に浮いたように写ります。ただし、境界線が消えるのは、その面が白く飛ぶまで光を当てたときだけです。R面に光が当たっていなければ、曲面に沿った陰影が、なだらかな灰色のグラデーションとして写ります。これは欠点ではなく、後で説明するように、背景ライトを使わずに灰色の背景を作る手段になります。

白ホリを使うときの物理的な注意が二つあります。R面は踏むとひび割れや汚れが残るので、被写体もスタッフもR面の手前で止まります。床は靴の跡がつくので、スタジオの指示に従って靴を脱ぐか、撮影前にモップで拭いておきます。

次に、背景を白く飛ばす仕組みです。写真の中で真っ白とは、その部分の画素が最大値に達していることを指します。第2章で、ハイライトが最大値に達すると階調が失われる、いわゆる白飛びを学びましたが、背景を抜くときは、この白飛びを意図的に起こします。被写体を f/8 で適正に写す設定のまま、背景の壁面だけが f/8 より明るければ、壁面は白飛びして純白になります。

必要な明るさの差は、キーライトより1段から1.5段です。壁面が f/11 から f/13 相当の明るさなら、f/8 で撮った画像で壁面は白飛びします。ここで、明るければ明るいほど確実だと考えて2段以上明るくすると、別の問題が起きます。壁面に当たった光は、壁で反射して被写体の背後から回り込みます。背景が明るすぎると、この回り込みが被写体の輪郭を明るく縁取り、髪の毛の細部が背景に溶けてしまいます。壁面から強い光がレンズに入ることでフレアも起き、画像全体の黒が浮いて、コントラストが下がります。ですから背景ライトの明るさは、白飛びする最小限で止めます。確認には R10 のハイライト警告を使います。背景だけが点滅し、被写体の肌や服が点滅しない状態が目標です。

背景ライトは、壁に向けて左右から2灯当てます。1灯を正面から当てると、中央だけが明るいホットスポットになり、画面の端で白飛びしきれない灰色が残ります。左右の2灯を交差させる、つまり左のライトは壁の右側を、右のライトは壁の左側を狙うようにすると、壁面の明るさが均一になります。壁面が均一に飛んでいるかどうかは、被写体を外して背景だけを撮り、ヒストグラムが右端に張り付いているかで確かめます。

被写体と壁の距離についてです。被写体は壁から2.5メートル以上離します。理由は二つあり、どちらも第4章の逆二乗則に基づきます。一つ目は、キーライトの光を壁に届かせないためです。被写体から1.5メートルのキーライトは、壁から2.5メートル離れた被写体の背後にある壁まで、4メートルの距離になります。距離が1.5メートルから4メートルへ2.7倍になると、壁に届く光は約2.8段暗くなります。壁の明るさをキーライトではなく背景ライトが決める状態にしたいので、キーライトの漏れは小さいほうがよいのです。

二つ目は、背景ライトの光を被写体に当てないためです。背景ライトは壁から1.5メートルの位置で壁に向いているので、被写体が壁から2.5メートル離れていれば、背景ライトは被写体の1メートル後ろにあり、光は被写体の背中側を通り過ぎます。被写体が壁に近いと、背景ライトが被写体の横に並び、直射光が肩や髪に当たって、意図しないリムライトになってしまいます。

このため、白ホリの奥行きは全身撮影の制約になります。教材のスタジオは奥行き6メートルで、壁から被写体まで2.5メートル、被写体からカメラまで3メートル強を取ると、ほぼ使い切ります。詰めるなら2メートルを下限にして、背景ライトの向きを被写体から遠ざける向きに浅く振ります。

床の反射と足元の影の話です。床も白ホリの一部で、背景ライトの光の一部は床に落ちます。壁から遠い床は背景ライトからも遠いので、被写体の足元の床は壁ほど白く飛びません。全身写真では、足元の床が白から薄い灰色へ変わっていく様子と、キーライトが作る足元の影が写ります。この影は消さなくてかまいません。白い空間に立っている人物には床があり、足元に影があるほうが自然に見えます。床まで白く飛ばそうとして床にもライトを当てると、下からの光が被写体のあごや鼻の下を照らし、フレアも増えます。背景の差し替えを前提にするなら、足元の影は、あとで切り抜きの段階で残すか消すかを選べます。

床の白さには、もう一つの効果があります。床に落ちた光は上へ反射して、下からの弱いフィルになります。白ホリで撮ると背景紙のブースより影が柔らかく写るのは、この床の反射のためです。抑えたいときは、被写体の足元の手前に黒レフを寝かせて置きます。

全身撮影の焦点距離とカメラの高さに移ります。上半身では RF 50ミリ、フルサイズ換算80ミリを使いましたが、全身を奥行き6メートルの白ホリで撮るには焦点距離が長すぎます。換算80ミリで1.7メートルの人物を縦位置に収めるには、被写体から約5メートル離れる必要があります。全身には、キットレンズの18から150ミリの、24ミリから35ミリの範囲を使います。換算では38ミリから56ミリです。35ミリなら被写体から約3.3メートルで、縦位置に全身と上下の余白が入ります。

広角側の24ミリなら2.3メートルまで近づけますが、近づくほど遠近感の誇張が強くなり、頭が大きく脚が短く写ります。奥行きに余裕があれば35ミリを選びます。

カメラの高さは、被写体の腰から胸の高さに置き、レンズを水平に向けます。立った姿勢のまま目の高さから見下ろすと、脚が短く写ります。逆に膝の高さから見上げると脚が長く見え、これはファッション写真で意図的に使われる構図です。プロフィール写真では、見た目を歪めない胸の高さを基準にします。絞りは基準の f/8 のままでかまいません。35ミリ、f/8、3.3メートルなら被写界深度が前後1メートル以上あり、全身のどこにピントを合わせても全体が鮮明に写ります。AF は第3章の設定、被写体検出の人物と瞳検出のままで、全身でも瞳を検出します。

切り抜きを前提にした撮り方についてです。あとで背景を差し替える写真では、切り抜きの手間を決めるのは、背景の均一さと輪郭の状態です。背景は純白で均一にし、輪郭には白い縁取りを作りません。縁取りは背景の回り込みで生じるので、背景ライトは1段上に抑え、被写体の左右に黒レフを立てて、壁から戻ってくる光を遮ります。髪の毛の細部は最も溶けやすい部分なので、残っているかを拡大表示で確かめます。

背景ライトを使わずに灰色に落とす方法です。白ホリは、背景ライトを消せば白ではなくなります。壁に届く光はキーライトの漏れだけになり、その明るさは距離で決まります。被写体が壁から2.5メートルのとき、壁はキーライトから4メートルで、被写体より約2.8段暗くなります。f/8 の露出で2.8段暗い白い壁は、中間より少し暗い灰色に写ります。さらに被写体を壁から離すと、壁はもっと暗くなります。壁から5メートルなら、キーライトから6.5メートルで約4.2段暗く、濃い灰色になります。ソフトボックスの向きを被写体の手前側へ振るフェザリングを使うと壁への漏れがさらに減り、黒に近づきます。白ホリ一つで、白から濃い灰色までの背景を、背景ライトの有無と距離で作れるわけです。第9章のグレーの背景紙は、この操作を背景紙で行います。

ハイキーについても触れておきます。白い背景に明るい服の被写体を、影の薄い柔らかい調子で撮る表現をハイキーと呼びます。白ホリの白背景はハイキーの前提になりますが、背景を飛ばしただけではハイキーにはなりません。ハイキーの中身は、フィルを強めて顔の影を薄くすること、つまりライティング比を1段差まで詰めることと、顔の露出を基準より3分の1段から3分の2段明るめにすることです。ハイキーは露出オーバーとは違います。肌のハイライトが白飛びしたら、それは明るい写真ではなく、階調のない写真です。ハイライト警告で背景だけが点滅し、肌は点滅しない範囲で明るくします。

ここからは具体例です。友人の全身を白ホリで撮ります。用意するのは、ソフトボックスを付けたキーライト1灯、白レフ、標準リフレクターを付けた背景ライト2灯です。トリガーのグループは、キーをA、背景2灯をまとめてCに割り当てます。背景2灯を同じグループにしておくと、壁面の明るさを一つの操作で上げ下げできます。

配置を言葉で説明します。奥に白ホリの壁があります。壁から1.5メートル手前の左右に背景ライトを置き、それぞれ壁に向けます。左のライトは壁の右側を、右のライトは壁の左側を狙って交差させます。壁から2.5メートル手前に被写体が立ちます。被写体の斜め前45度、2.1メートルの位置にソフトボックスのキーライト、その反対側1メートルに白レフを置きます。切り抜き用のカットでは、被写体の左右、画面の外ぎりぎりに黒レフを立てます。カメラは被写体から3.3メートル手前に、三脚で置きます。

まず立ち位置を決めます。壁から2.5メートルの床にマスキングテープで印をつけ、友人にはこの印の上に立ってもらいます。カメラは印から3.3メートル離した位置に三脚で置き、レンズの高さを友人の胸の高さに合わせて水平に向けます。18から150ミリを35ミリにし、縦位置で全身と上下の余白が入ることを確かめます。

キーライトの位置は、上半身のときの1.5メートルから2.1メートルに離します。全身では、顔に合わせたキーライトから足元までの距離が、顔までの距離より長くなり、足元が暗くなるからです。1.5メートルの位置でソフトボックスの中心を顔の高さより少し上に置くと、足元までは約2.2メートルで、顔より1段以上暗くなります。2.1メートルに離すと足元までは約2.6メートルで、差は0.6段まで縮みます。離した分だけ暗くなるので、出力を4分の1から2分の1へ1段上げて、顔を f/8 に戻します。ソフトボックスは縦長にし、中心を友人の胸の高さまで下げて、顔から膝まで均等に光が届くようにします。

第7章の手順どおり、灯を一つずつ点けて確認します。最初はキーライトだけです。トリガーでグループCをオフにし、Aを2分の1にして撮ります。顔がヒストグラムの中央より少し右にあり、白い壁が中間より暗い灰色に写っていれば、キーライトの漏れが壁を支配していないと分かります。この段階の壁の灰色が、あとで使う灰色の背景そのものです。

次に背景ライトだけを点けます。Aをオフ、Cを16分の1にして、友人には画面の外へ出てもらい、壁だけを撮ります。標準リフレクターの400ワットセカンドは、16分の1でも壁から1.5メートルで f/11 相当になります。ヒストグラムが右端に張り付き、ハイライト警告で壁面全体が点滅していれば、壁は均一に飛んでいます。画面の端に点滅しない灰色が残るなら、2灯の交差させる角度を変えて、壁の端まで光を回します。

最後に両方を点け、友人に戻ってもらって撮ります。確認するのは三つです。顔の露出が変わっていないこと、ハイライト警告が背景だけで点滅していること、髪の輪郭を拡大表示して細部が残っていることです。輪郭が溶けているなら背景が明るすぎるので、背景ライトを壁から1.8メートルへ下げて半段落とします。SK400II の出力は16分の1が下限なので、これ以上暗くするには距離で調整します。

設定値をまとめます。キーライトはグループA、ソフトボックスを縦にして斜め前45度、2.1メートル、出力2分の1で、顔が f/8、足元が f/6.3 です。フィルは白レフで、影側は f/4、2段差です。背景はグループC、標準リフレクター2灯を壁から1.5メートル、出力16分の1で、壁面は f/11、キーの1段上です。カメラはマニュアル、ISO 100、200分の1秒、f/8、ホワイトバランス5500ケルビン、RAW、メカシャッターです。ストロボを全部切って同じ設定で1枚撮り、真っ黒になることを最初に確かめておきます。

続けて、切り抜き用のカットを撮ります。オンラインショップの商品ページに友人の着用写真も載せる予定なので、切り抜きやすいカットが要ります。黒レフを被写体の左右、画面の外ぎりぎりに立てます。壁から戻る光を黒レフが吸収し、肩と腕の輪郭に出る白い縁取りが消えます。背景の出力は変えません。1段上で白飛びしているなら、それ以上明るくする理由はないからです。同じ設定のまま、友人に画面の外へ出てもらい、背景だけを1枚撮っておきます。これが、切り抜きの段階で床の影を消すときの材料になります。

次に、背景ライトを切って灰色にします。同じ立ち位置のまま、グループCをオフにして撮ると、背景は中間より少し暗い灰色になります。キーライトから壁までは、キーライトから被写体までの2.1メートルと、被写体から壁までの2.5メートルを足した4.6メートルで、被写体より約2.3段暗くなります。もっと暗くしたければ友人に前へ出てもらい、壁からの距離を稼ぎます。白ホリの奥行きが許す範囲で、壁から4メートルまで離せば約3段差になり、濃い灰色になります。設定を一つも変えずに、白背景とグレー背景の両方が撮れます。

最後にハイキーのカットです。白レフをキーの反対側1メートルから0.6メートルまで近づけると、影側は約1段差まで明るくなります。キーの出力を2分の1から0.3段上げ、顔を f/8 より少し明るく写します。背景は変えません。ハイライト警告が背景だけで点滅し、白いシャツの明るい部分が点滅し始めたら、そこがキーの上限です。

次の第9章では、この背景の操作を背景紙と色に広げ、環境光が混ざったときの扱いを学びます。
