# 第7章 多灯ライティングの組み立て（読み上げ原稿）

対象章：[第7章 多灯ライティングの組み立て](../07-multi-light.md)（[演習問題](../exercises/07-multi-light.md)）

第7章、多灯ライティングの組み立て。この章では、ストロボを二灯、三灯と増やしていくときの考え方と手順を学びます。灯の役割を四つに分けること、灯同士の明るさの関係を段差で表すこと、一灯ずつ点けて確認しながら足していくこと、そしてその手順をカメラの位置から進めるためのトリガーの操作です。後ろから当てる灯に付きもののフレアの対処と、クラムシェルという配置にも触れます。

まず、なぜ灯を増やすのかを確認します。第6章では、ソフトボックス一灯と白いレフ板だけで、友人の上半身を撮りました。一灯でも顔の陰影は作れますし、レフ板で影の濃さも変えられます。それでも、一灯では解けない問題が二つ残りました。一つは、黒い髪と黒っぽい服が暗い背景に溶けて、肩から上の輪郭が消えてしまうことです。もう一つは、背景の明るさをキーライトの位置と出力の都合で決めるしかなく、顔の露出と背景の明るさを別々に選べないことです。

多灯ライティングは、灯を増やして絵を派手にする技法ではありません。一灯で解けない問題を一つ選び、その問題だけを担当する灯を一つ足す、という考え方です。輪郭が溶けるなら、輪郭に光を当てる灯を足します。背景を明るくしたいなら、背景だけを照らす灯を足します。灯ごとに役割を一つに絞ると、どの灯をどう動かせば何が変わるかが分かり、調整で迷わなくなります。

では、灯の四つの役割を順に見ていきます。多灯の灯は、当てる場所ではなく、担う役割で呼びます。一つ目はキーライトです。キーライトは被写体の形を決める灯で、顔のどこに影が落ちるか、鼻の影がどちらを向くかは、キーライトの位置で決まります。露出の基準もキーライトが作ります。第6章で使った一灯は、このキーライトです。

二つ目はフィルライトです。フィルライトは、キーライトが作った影を起こす灯です。影を完全に消すのではなく、影の中に階調が残る程度に、弱く当てます。第6章の白いレフ板もフィルの役割を担っていましたが、レフ板の強さは被写体との距離でしか変えられません。上半身なら1メートルに置いた1枚で足りても、全身では1枚で顔から足まで起こしきれませんし、近づけると画面に写り込みます。フィルをストロボにすると、位置を変えずに出力で強さを決められます。フィルは方向を作ってはいけないので、キーの反対側のカメラ寄りに、できるだけ大きな光源で当てます。

三つ目はリムライトです。リムライトは、被写体の斜め後ろから当てて、髪や肩の縁に細い光を乗せる灯です。ヘアライト、セパレーションライトとも呼ばれますが、同じ位置の同じ灯を指すことが多いので、この教材ではリムライトで通します。役割は被写体を背景から切り離すことで、暗い背景に黒髪が溶ける問題は、この灯が解きます。光を顔に回り込ませたくないので、標準リフレクターにグリッドを付けた、狭い光を使います。

四つ目は背景ライトです。背景ライトは、背景だけを照らして、背景の明るさをキーライトから独立に決める灯です。被写体には当てません。白ホリを白く飛ばすときも、グレーの背景紙を好きな明るさに置くときも、この灯の出力で決めます。背景ライトの実際は、第8章と第9章で扱います。

一つの灯に二つの役割を求めると、調整が衝突します。キーライトを背景も照らす位置に置けば、顔の露出を変えるたびに背景の明るさも動いてしまいます。リムライトで顔の側面まで明るくしようとすれば、輪郭に必要な出力と、頬に許せる出力が合いません。灯を足すかどうかは、いま解きたい問題を担当している灯があるか、で決めます。

次に、ライティング比の話です。キーライトとフィルライトの明るさの関係を、ライティング比と呼びます。教科書では、キーとフィルの両方が当たる明部と、フィルだけが当たる暗部の明るさの比を、2対1、4対1、8対1のように書きます。この教材では、これをキーとフィルの段差で表します。フィルがキーより1段暗ければ段差1、2段暗ければ段差2です。

段差で覚える理由は、ストロボの出力ダイヤルと一対一に対応するからです。フィルの出力を1段下げれば、段差は1増えて、影はその分濃くなります。比で覚えると、4対1から8対1にするのに何段動かすかを、毎回換算することになります。

段差と絵の印象の対応を、目安として押さえておきます。段差1、比で言えば2対1は、影がごく薄く、顔が平らに見えます。証明写真や、明るく柔らかい印象に向きます。段差2、4対1は、影に階調が残って立体感があり、プロフィール写真の標準です。段差3、8対1は、影が濃く、顔の半分が沈む、陰影を強調した印象になります。フィルなしでは影がほぼ黒く落ち、これは第9章のローキーで使います。

リムライトの明るさは、キーと同じか1段上を目安にします。黒髪は光を吸うので明るめに、明るい髪や白い服は縁が飛びやすいので控えめにします。そして、露出の基準は常にキーライトです。カメラの絞りは、キーライトで顔が適正になる値に固定し、フィルとリムはキーに対する段差で決めます。フィルを明るくしたいからといって絞りを開けると、キーの露出まで動いてしまいます。

ここからが、この章の中心となる手順です。三灯を同時に点けて撮ると、影の濃さが足りないのがフィルの弱さのせいなのか、キーの位置のせいなのか、判断できません。多灯は、一灯ずつ点けて確認しながら足していきます。手順は五つの段階に分かれます。

段階1では、キーライトだけを点け、第6章の手順で位置、出力、絞りを決めます。ここで露出の基準が固まります。段階2では、キーを消してフィルライトだけを点け、フィルが顔をどれだけ照らしているかを見ます。目標の段差に合わせて出力を決め、影の方向が付いていないことを確認します。段階3では、キーとフィルを点け、影側の頬に階調が出ているかを見ます。段差が違えば、フィルの出力だけを動かします。段階4では、キーとフィルを消してリムライトだけを点け、光が髪と肩の縁だけに乗っているか、レンズに直接入っていないかを見ます。段階5で全部を点けて撮り、ヒストグラムとハイライト警告で仕上がりを確認します。

各段階で見るものが違います。段階1は影の形と露出、段階2と3は影の濃さ、段階4は輪郭とフレアです。後の段階で気になることが出ても、前の段階の灯は動かしません。キーを動かせば、段階2以降がやり直しになるからです。

この手順は、灯ごとに点けたり消したり、出力を変えたりを何度も繰り返します。そのたびにストロボ本体まで歩いていては、撮影が進みません。トリガーのXPro II-Cは、グループごとにモードと出力をカメラ位置から変えられます。準備として、三灯の受信チャンネルとIDをトリガーと揃え、キーをグループA、フィルをグループB、リムをグループCに割り当てます。どの灯がどのグループかは、ライトスタンドにテープで書いておきます。撮影中は、トリガーのグループボタンで灯を選び、モードボタンでMとOFFを切り替え、ダイヤルで出力を変えます。グループをOFFにすれば、その灯は発光しないので、キーだけ、フィルだけ、という試し撮りがカメラ位置から済みます。

モデリングランプは、灯ごとの効き方の見当をつけるのに使います。出力に比例して明るさが変わる設定にしておけば、フィルを1段下げたときに影がどう変わるかを、撮る前に目で追えます。ただし、定常光で見える明暗の差は、ストロボ光の差と厳密には一致しません。段差の最終判断は、試し撮りで行います。

次に、リムライトのフレアの話です。リムライトは被写体の後ろにあるので、発光面がレンズに向いています。発光面から出た光がレンズに直接入るとフレアが起き、画面全体のコントラストが落ちて黒が灰色に浮き、ときに光の形が写り込みます。一灯の撮影では起きない、多灯に固有の失敗です。判定は簡単で、カメラ位置から灯の発光面が見えるなら、光はレンズに入っています。

対処は三つあります。一つ目は灯の位置を変えることで、被写体の真後ろではなく斜め後ろ45度に置き、発光面が被写体の身体で隠れる位置と高さを探します。二つ目はグリッドで光の広がりを絞ることで、輪郭に当てる光は狭くてよいので、グリッドを付けても効きは落ちません。三つ目はフラッグです。黒いレフ板や黒い板を灯とレンズの間に立てて、レンズに向かう光だけを遮ります。被写体に向かう光は遮りません。

もう一つの失敗は、リムが強すぎて輪郭が白く飛び、髪の質感が消えることです。髪の縁が細い線として残る出力まで下げます。SK400IIの出力は16分の1までしか下がらないので、それでも強ければ、灯を遠ざけるか、リフレクターにディフューザーを掛けて減光します。

クラムシェルという配置にも触れておきます。クラムシェルは、キーライトを顔の正面上から見下ろす位置、つまり第6章のバタフライの位置に置き、その真下にフィルを置いて、上下から顔を挟む配置です。上下に開いた貝殻の形から名が付きました。下からのフィルは、白いレフ板か、白アンブレラの弱い灯で作ります。顔の影は上下から埋まってほぼ消え、目には上下二つのキャッチライトが入ります。段差は1か2で、明るく整った印象になるので、美容系や証明写真寄りのプロフィールに向きます。

それでは、具体例に入ります。友人の上半身を、背景紙のブースで三灯を使って撮ります。背景はグレーの背景紙で、被写体は背景紙から2.5メートル前に立ちます。第6章の一灯の絵を出発点にして、フィルとリムを足していきます。

配置を上から見た形で説明します。奥にグレーの背景紙があり、その手前2.5メートルに被写体が立ちます。キーライトはグループAで、60センチかける90センチのソフトボックスを、被写体の斜め前45度、顔より少し上の高さ、被写体から1.5メートルに置き、出力は4分の1、これで顔がf/8になります。フィルはグループBで、白アンブレラをキーの反対側、カメラのすぐ横、顔の高さ、被写体から2メートルに置き、出力は8分の1、これで顔がf/4、つまり段差2になります。リムはグループCで、標準リフレクターにグリッドを付けて、被写体の斜め後ろ45度、高さ2メートルから見下ろす角度、被写体から2メートルに置き、出力は16分の1、これで髪がf/8からf/11になります。カメラはISO100、200分の1秒、f/8、ホワイトバランス5500ケルビン、レンズはRF50ミリで、基準の設定から変えません。

段階1では、トリガーでグループBとCをOFFにして、キーだけで撮ります。第6章と同じく、鼻の影が頬に向かってループを描き、両目にキャッチライトが入り、顔の明るい側のヒストグラムが右寄りで飛んでいないことを確認します。背景紙は被写体の2.5メートル後ろにあり、キーライトからは4メートル近く離れているので、f/8では暗いグレーに落ちます。この暗い背景に黒髪が溶けているのが、これから解く問題です。

段階2では、AをOFF、BをMにして、フィルだけで撮ります。顔は全体にf/4相当で2段暗く写り、右も左もほぼ同じ明るさで、鼻の影が目立たなければ合格です。鼻の横に影が付くなら、フィルの位置がカメラから離れすぎているので、カメラの真横まで寄せます。

段階3で、AとBを点けます。影側の頬が黒く沈まず、明るい側より暗いけれども皮膚の階調は残っている、という見え方になります。これが段差2の絵です。もっと柔らかくしたければBを4分の1に上げて段差1に、もっと陰影を出したければBを16分の1に下げて段差3にします。このとき、キーの出力と絞りは動かしません。

段階4では、AとBをOFF、CをMにして、リムだけで撮ります。髪の縁と肩の線だけが光り、頬や耳の側面まで明るくなっていなければ合格です。撮る前に、カメラ位置からリムの発光面が見えていないかを確かめます。見えているなら、灯を被写体の身体の陰に入る位置まで後ろに回し、それでも見えるなら、灯とカメラの間に黒いレフ板を立てます。髪の縁が白く飛んでいる場合は、16分の1から下げられないので、灯を2.8メートルまで遠ざけます。距離が1.4倍になると、約1段暗くなります。

段階5で、全部を点けます。髪の輪郭が背景から浮き、影側の頬に階調が残り、キャッチライトが両目に入っていれば完成です。ヒストグラムでは、髪の縁のハイライトが右端に少しかかる程度で、顔の明部は右寄りで飛んでいない状態を確認します。

最後に、よくある失敗と原因の切り分けを整理します。影側の頬が真っ黒なら、疑うのはフィルで、Bだけで撮って顔が写るかを確かめ、Bの出力を上げるか近づけます。顔が平らで立体感がないなら、これもフィルで、段差を数えて、Bを1段下げます。画面全体が眠くて黒が浮くなら、疑うのはリムで、カメラ位置から発光面が見えるかを確かめ、灯を後ろに回すか、グリッドかフラッグを使います。髪の縁が白く飛ぶなら、Cだけで撮って髪の質感が残るかを確かめ、灯を遠ざけるかディフューザーを掛けます。耳や頬の側面まで明るいなら、Cだけで撮って光の範囲を見て、グリッドを付けるか、角度を後ろに振ります。顔の露出が段階1と違うなら、Aだけで撮り直して、動かしてしまった灯を戻します。

どの症状も、まず疑う灯だけを点けて撮れば、原因の灯が特定できます。三灯を点けたまま出力をあちこち動かすのは、原因を分からなくする操作です。一灯ずつ足す手順と、灯だけを点ける確かめ方が、この章で持ち帰ってほしい二つの習慣です。次の第8章では、この考え方を白ホリに持ち込み、背景ライトで背景を白く飛ばす撮り方を学びます。
