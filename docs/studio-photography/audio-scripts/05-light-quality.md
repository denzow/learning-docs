# 第5章 光の質と方向、ライティング用具（読み上げ原稿）

対象章：[第5章 光の質と方向、ライティング用具](../05-light-quality.md)（[演習問題](../exercises/05-light-quality.md)）

第5章、光の質と方向、ライティング用具。この章では、明るさ以外の光の性質を学びます。影の縁の鋭さを決める光の質、影の落ちる場所を決める光の方向、そしてその二つを操作するためのソフトボックスやアンブレラといった用具です。第4章までで、出力と距離を調整して顔の明るさを f/8 に合わせることはできるようになりました。ところが、同じ f/8 になった二枚の写真が、まるで違って見えることがあります。片方は鼻の影がくっきりと頬に落ち、もう片方は影の縁がなだらかに溶けている。ヒストグラムはどちらも同じ位置に山を作りますから、この違いは露出では説明できません。その違いを作っているものを、この章で扱います。

まず、光の質という言葉の意味から始めます。写真の光は、影の縁で分類します。影の縁が鋭く、明るい部分と暗い部分がはっきり分かれる光を、硬い光と呼びます。影の縁が幅を持って、なだらかに移り変わる光を、柔らかい光と呼びます。晴れた日の正午の太陽は硬い光で、曇りの日の空は柔らかい光です。

では、硬いか柔らかいかは何で決まるのでしょうか。光源の明るさでも色でもなく、被写体から見た光源の見かけの大きさで決まります。理屈はこうです。光源が一つの点だとすると、被写体の表面のどの点も、光源が見えるか、何かに遮られて見えないかの二択になります。だから明るい部分と影は一本の線で分かれます。ところが光源が面積を持つと、面の一部からは見えるけれど残りの部分からは遮られる、という中間の領域が生まれます。この領域は、光源のどれだけの部分が見えているかに応じて暗くなるので、影の縁が幅を持つのです。その幅は、被写体から見て光源がどれだけの角度を占めるかに比例します。

ここで「見かけの大きさ」と言ったのは、光源の実際の大きさではないからです。太陽は直径が地球の百倍以上ありますが、遠いので、地上から見た角度は0.5度しかありません。だから太陽は点光源として振る舞い、影は硬くなります。一方、曇り空は太陽の光を雲全体に広げるので、空の半分が光源になり、影はほとんど消えます。同じ理屈で、60センチ掛ける90センチのソフトボックスも、1.5メートルに置けば被写体から見て33度ほどの角度を占める大きな光源ですが、5メートルに離せば10度ほどの小さな光源になります。つまり、光の質は用具だけでは決まらず、用具と距離の組み合わせで決まります。

次に、距離を変えると何が変わるかを整理します。ライトを被写体に近づける操作は、三つのことを同時に変えます。一つ目は、いま話した見かけの大きさで、近いほど柔らかくなります。二つ目は明るさで、第4章の逆二乗則により、距離を半分にすると2段明るくなります。三つ目は、被写体の中での明るさの落ち方です。

この三つ目は見落とされやすいところです。ライトが顔から1メートルにあるとき、顔から50センチ後ろにある肩や胸は、ライトから1.5メートルの位置にあります。逆二乗則で計算すると、顔より1.2段暗くなります。同じライトを顔から3メートルに離すと、肩や胸はライトから3.5メートルにあり、顔との差は0.4段に縮みます。近いライトは被写体の中で明るさが急に落ち、遠いライトは全身をほぼ均一に照らします。上半身で顔だけを浮かび上がらせたいなら近く、全身を均一に照らしたいなら遠く、というのがこの性質の使い方です。

ここで大事な順序があります。明るさは出力で戻せますが、質と落ち方は距離でしか変えられません。ライトを近づけて明るくなりすぎたら出力を下げればいいし、離して暗くなったら出力を上げればいい。ですから、位置を決めるときは、まず質と落ち方の観点で距離を決め、次に出力で明るさを合わせます。出力を先に決めて、距離で明るさを合わせる順序では、光の質が出力の都合で決まってしまいます。

続いて、ライティング用具の話に移ります。モノブロックのボーエンズマウントには、光を広げたり絞ったりする用具を付けます。スタジオで借りられる主な用具を、光の質、光の広がり、効率の三つの観点で整理していきます。効率というのは、同じ出力と距離で被写体がどれだけ明るくなるかのことで、標準リフレクターを基準にした段数で表します。

標準リフレクターは、ストロボに付属する金属の皿で、発光管の光を前方に集めます。光源の大きさは発光管と皿の直径、20センチほどしかありませんから、光は硬く、そのかわり効率は高く、光は前方60度ほどに広がります。背景ライトやリムライトに使います。グリッドは、この皿の前に付けるハニカム状の格子で、光の広がりを20度から40度に狭めます。光の質は変えず、届く範囲だけを絞る用具で、効率は1段ほど落ちます。

ソフトボックスは、箱の中でストロボの光を反射させ、前面の拡散布から出します。被写体から見た光源は前面の布の大きさになるので、光は柔らかくなります。側面は黒い布で覆われているので、光は前方にしか出ず、背景やスタジオの壁には漏れにくい。効率は標準リフレクターより2段から3段落ちます。キーライトの定番です。

透過アンブレラは、傘の布を通して光を出します。光源の大きさは傘の直径になるので柔らかいのですが、光は傘の後ろにも横にも広がり、白い壁や天井に当たって戻ってきます。この回り込みは、フィルが欲しいときには役に立ち、背景を暗く落としたいときには邪魔になります。反射アンブレラは、傘の内側に光を当てて跳ね返す使い方で、透過より広がりは狭いものの、ソフトボックスほどには制御できません。効率はどちらも2段から3段落ちます。

白レフ板はストロボではなく、キーライトの光を反射して影側に戻す板です。反射した光は板の大きさの柔らかい光源になり、影を薄めます。黒レフ板はその逆で、影側に届く光を遮ります。白ホリのように壁も床も白いスタジオでは、キーライトの光が壁で反射して影側に回り込み、影が意図せず薄くなります。黒レフ板を影側に立てると、この回り込みを止めて影を濃くできます。光を足すのではなく引く道具なので、ネガティブフィルとも呼ばれます。

次は、光の方向です。光の方向は、影がどこに落ちるかを決めます。顔で読むなら、いちばん分かりやすい指標は鼻の影です。鼻は顔の中でいちばん突き出ているので、その影の向きと長さが、光の水平方向の角度と高さをそのまま表します。カメラの位置を基準に、方向を五つに整理します。

正面、つまりカメラの真上や真横にライトがあると、影はすべて被写体の後ろに落ち、カメラからは見えません。顔は平坦に写り、立体感が出ません。斜め前45度に置くと、鼻の影がライトと反対側の頬へ落ち、頬骨と鼻筋に立体感が出ます。ポートレートの出発点で、第6章の型はここから変化させます。真横、90度のサイドからの光では、顔の半分が影になり、肌の質感や凹凸が強調されます。斜め後ろからの逆光では、顔は影になり、髪と肩の輪郭に光の縁ができます。第7章のリムライトはこの方向で使います。そして真上からのトップライトでは、目の窪みと鼻の下、顎の下に影が落ちます。ライトを見下ろす角度にしすぎたときにも、同じことが起きます。

水平方向だけでなく、高さも方向のうちです。顔より少し上から見下ろす光は、太陽や室内灯と同じ向きなので自然に見えます。顔より下からの光は、目の下や鼻の上に影を作り、見慣れないので不自然に見えます。第1章の基準設定にある「顔より少し上」という高さは、この自然さの範囲の中で立体感を出す高さです。

光の方向を確かめるもう一つの指標が、キャッチライトです。瞳に映ったライトの像のことで、これがあると目に潤いが出て、ないと目は暗く沈みます。キャッチライトはライトの位置と形をそのまま映します。ソフトボックスなら四角、アンブレラなら丸い像が、ライトのある側の上のほうに映ります。瞳の上半分にキャッチライトがあれば、ライトの高さは自然な範囲にあります。瞳の中央や下半分にあれば、ライトが低すぎます。

概念の最後に、フェザリングを説明します。ソフトボックスの光は、前面の中心がいちばん明るく、縁に向かって落ちていきます。中心を被写体の顔に向ける置き方が基本ですが、それだと顔はいちばん明るく、胸や肩は縁の光で暗くなります。フェザリングとは、ライトの中心を被写体から少し外し、光の縁の部分で被写体を照らす置き方です。羽根の縁のように光を薄く当てることから、こう呼ばれます。

中心をカメラ側、つまり被写体の手前へ振ると、顔には縁の光が当たり、胸や肩にも同じ縁の光が届くので、顔と体の明るさの差が縮まります。また、ライトの中心の強い光が背景へ向かわなくなるので、背景に光が漏れにくくなります。縁の光は中心より弱いので、出力は0.5段から1段上げて明るさを戻します。フェザリングは光の質を変える操作ではなく、光の落ち方と漏れ方を変える操作です。

ここからは具体例です。友人の顔を、同じ一灯で、用具、距離、方向だけを変えて撮り比べます。違いを見るための実験なので、白ホリの前に立ってもらいますが、背景は照らさず、被写体は壁から3メートル離します。カメラの設定は ISO 100、200分の1秒、f/8、ホワイトバランス5500ケルビンで固定し、RF 50ミリを付けたカメラは被写体から2メートルに置きます。どの組み合わせでも、出力か距離を調整して、顔の明るさを f/8 に合わせてから比べます。

まず用具を変えます。ライトの位置は、すべて被写体の斜め前45度、顔より少し上から見下ろす角度で揃えます。標準リフレクターは2.1メートルに置き、出力16分の1で顔が f/8 になります。鼻の影の縁が鋭く、頬に輪郭のある影が落ち、肌の凹凸が目立ちます。透過アンブレラは1.5メートル、出力4分の1で f/8 です。影の縁はなだらかになり、白ホリ全体がうっすら明るくなって、影側の頬にも光が回ります。ソフトボックスも1.5メートル、出力4分の1で f/8 です。影の縁は透過アンブレラと同じくらい柔らかいのですが、白ホリは暗いままで、影側の頬はアンブレラより暗くなります。

標準リフレクターだけ距離が2.1メートルなのは、SK400IIの出力の下限が16分の1で、1.5メートルに置くと顔が f/11 を超えてしまうからです。下限に当たったら距離を離すか絞りを絞る、という判断は第4章のとおりですが、標準リフレクターはもともと硬いので、2.1メートルに離しても質の比較には影響しません。透過アンブレラとソフトボックスの違いは、顔ではなく、背景と影側の頬に出ます。アンブレラの光は四方に広がり、白ホリの壁と床に当たって戻ってくるので、影側の頬が意図せず明るくなり、背景も持ち上がります。背景を暗く落としたいなら、ソフトボックスを選ぶか、アンブレラのままなら影側に黒レフ板を立てて回り込みを止めます。

次に、ソフトボックスの距離だけを変えます。0.8メートルに近づけると、出力16分の1で顔が f/8 になります。影の縁はいちばん柔らかく、顔だけが明るくて、肩から下は急に暗くなります。顔から50センチ後ろの肩は1.3段ほど暗くなります。基準の1.5メートルでは出力4分の1で、影は柔らかく、上半身がほぼ均一に照らされ、肩は0.7段ほど暗い程度です。3メートルに離すと、出力をフル発光の1分の1にしてようやく f/8 になります。影の縁はやや硬くなり、全身が均一に照らされ、肩の差は0.4段に縮みます。ただしフル発光なので、チャージに1秒かかります。

0.8メートルで出力が16分の1になっているのは、1.5メートルから0.8メートルに近づけると逆二乗則で1.8段明るくなるので、出力を2段下げてほぼ相殺しているからです。3メートルではその逆で、2段暗くなる分を出力1分の1で補っています。つまり、出力の下限と上限が、ソフトボックスを置ける距離の範囲を決めています。この範囲より近くに置きたければ絞りを絞り、遠くに置きたければ ISO を上げるか絞りを開きます。

続いて、方向を変えて撮り比べます。用具をソフトボックス、距離を1.5メートル、出力を4分の1に固定して、被写体を中心にライトを回します。高さは顔より少し上で揃えます。正面、つまりカメラの真上に置くと、鼻の影は鼻の真下に短く落ち、キャッチライトは両目の上中央に四角く映り、顔は平坦に写ります。斜め前45度では、鼻の影がライトと反対側の頬へ斜めに落ち、キャッチライトは両目のライト側の上に映り、頬骨と鼻筋に立体感が出ます。真横の90度では、ライト側の頬は f/8 ですが顔の反対側半分が影になり、キャッチライトはライト側の目にしか映らず、影側の目が沈みます。斜め後ろ45度の逆光では、顔全体が影になって f/2.8 ほどしかなく、キャッチライトは映らず、髪と肩の輪郭だけが光ります。

サイドと逆光は、それ単独でプロフィール写真に使う光ではありません。サイドは第6章のスプリットライティングとして、逆光は第7章のリムライトとして、他の光と組み合わせて使います。初心者が最初に覚えるべきは、斜め前45度から始めて、鼻の影とキャッチライトを見ながら少しずつ動かす、という手順です。

斜め前45度のまま、影側に板を立てて回り込みを比べると、レフ板の効き方が分かります。何も置かないと、影側の頬は f/2.8 前後、つまり3段ほど下で、白ホリからの回り込みがあってもここまで落ちます。白レフ板を被写体から1メートルに置くと f/4 前後、2段下まで明るくなり、影が薄まって、影側の目にも第二のキャッチライトが映ります。黒レフ板を同じ位置に置くと f/2 前後まで落ち、回り込みが止まって影が濃くなり、顔の立体感が強まります。同じ一灯でも、影側の板一枚で顔の印象はここまで変わります。第6章では、この白レフ板をフィルとして基準の配置に組み込みます。

最後に、フェザリングを試します。斜め前45度、1.5メートルのソフトボックスをそのまま、向きだけを変えます。中心を顔に向けた状態では、出力4分の1で顔が f/8、胸は f/6.3 前後、背景の白ホリは f/2.8 前後です。ここからライトを30度ほどカメラ側へ振り、光の縁で顔を照らします。振った分だけ顔に届く光が弱まるので、出力を0.7段上げて顔を f/8 に戻します。すると胸は f/7.1 前後になり、顔との差は0.7段から0.3段に縮みます。ソフトボックスの中心の強い光が背景へ向かなくなったので、白ホリは f/2 前後と、1段暗くなります。一つのライトの向きだけで、被写体の中の落ち方と、背景への漏れの両方を調整できるわけです。

この章のまとめです。光の質は、被写体から見た光源の見かけの大きさで決まり、距離は質と落ち方で決めて、明るさは出力で合わせます。方向は鼻の影とキャッチライトで確かめ、斜め前45度、顔より少し上を出発点にします。次の第6章では、この光で、ループやレンブラントといったポートレートの型を作ります。
