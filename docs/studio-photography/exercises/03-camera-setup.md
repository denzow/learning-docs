# 第3章 演習問題

対象章：[第3章 EOS R10 のスタジオ向け設定](../03-camera-setup.md)（[読み上げ原稿](../audio-scripts/03-camera-setup.md)）

## 問題

### 問1

スタジオに入り、EOS R10 を M モード、ISO 100、1/200 秒、f/8 に設定してファインダーを覗くと、画面がほとんど真っ暗でモデルの立ち位置も見えない。
このとき取るべき対処はどれか。

- A. ISO を 3200 まで上げ、シャッター速度を 1/30 秒にして、ファインダーの露出計の指針が 0 になるようにする
- B. 撮影メニュー内の露出Simulation を「しない」にし、露出の判断は撮影後のヒストグラムで行う
- C. 撮影モードを Av に変え、絞り f/8 のままカメラにシャッター速度を決めさせる
- D. モデリングランプを最大にして、ファインダーが明るく見えるまで待つ

### 問2

トリガーをホットシューに付け、チャンネルとグループもストロボと合わせたのに、シャッターを切ってもストロボがまったく発光しない。
トリガーのテスト発光ボタンを押すと発光する。
最初に確認すべきカメラの設定はどれか。

- A. ホワイトバランスが K 指定になっているか
- B. AF 動作が ONE SHOT AF になっているか
- C. シャッター方式が電子シャッターになっていないか
- D. 記録画質が RAW になっているか

### 問3

上半身のカットを撮ったあと、モデルにその場で写真を見せるためモニターで再生したところ、思ったより明るく写っているように見えた。
しかしパソコンに取り込んだ RAW を現像すると、顔は少し暗く、想定していた露出より半段ほどアンダーだった。
背面モニターの見え方と現像結果がずれた原因として最も考えられるものはどれか。

- A. 露出Simulation を「しない」にしていたため、再生画像も実際より明るく表示されていた
- B. オートライティングオプティマイザが有効で、モニターに表示される画像の暗部が自動で持ち上げられていた
- C. ホワイトバランスを 5500K に固定していたため、モニターでは色が明るく見えた
- D. ONE SHOT AF で瞳にピントを合わせたため、顔の露出が優先された

### 問4

RF 50mm F1.8 STM を付けた EOS R10 で、白ホリの奥に立ったモデルの全身を縦位置で撮ろうとしたが、カメラを 3.5m まで下げても頭と足が画面に入りきらない。
被写体と壁の距離は変えないものとして、適切な対処はどれか。

- A. RF-S 18-150mm に付け替え、24〜28mm（フルサイズ換算 38〜45mm）で撮る
- B. 絞りを f/1.8 に開き、被写界深度を浅くして画角を広げる
- C. 電子シャッターに切り替え、センサーの読み出し範囲を広げる
- D. 露出Simulation を「する」に戻し、画面の表示範囲を広げる

### 問5

ストロボ 1 灯で撮った上半身のカットを 20 枚並べると、カットごとに肌の色が青っぽくなったり赤っぽくなったりして、そろっていない。
ストロボの位置と出力は変えていない。
原因と対処の組み合わせとして適切なものはどれか。

- A. 閃光時間のばらつきが原因なので、シャッター速度を 1/60 秒に遅くして光を安定させる
- B. ISO 100 では色の再現が不安定なので、ISO 400 に上げる
- C. オートホワイトバランスがモデリングランプの色に反応してカットごとに違う補正をかけているので、K 指定で 5500K に固定する
- D. ピクチャースタイルがスタンダードだと色が転ぶので、モノクロで撮って現像時に着色する

## 解答と解説

### 問1

**解答**：B

ミラーレスカメラのファインダーは、設定した露出で環境光がどう写るかを表示する露出シミュレーションを行っている。
スタジオの環境光はストロボの光に比べてはるかに弱いので、ISO 100、1/200 秒、f/8 では画面が真っ暗になるが、これは正常な動作である。
露出Simulation を「しない」にすれば画面は見やすい明るさになり、露出の判断は撮影後の画像とヒストグラムで行えばよい。
A は露出計の指針を環境光に合わせる操作で、ストロボの光に環境光まで乗ったブレと色かぶりの原因になる。
C は自動露出に戻す操作で、カメラが環境光を基準に遅いシャッター速度を選ぶので同じ問題が起きる。
D のモデリングランプは構図の確認を助けるが、ファインダーの暗さを解消する設定ではない。

### 問2

**解答**：C

電子シャッターはセンサーを上から順に読み出すため、画面全体が同時に露光する瞬間がなく、EOS R10 ではストロボと組み合わせられない。
電子シャッターが選ばれていると、トリガーを正しく設定していてもカメラがストロボへ発光の合図を送らない。
テスト発光ボタンで光ることは、トリガーとストロボの通信に問題がないことを示しているので、カメラ側の設定を疑うのが順当である。
A、B、D はどれも発光の可否には関係しない。

### 問3

**解答**：B

オートライティングオプティマイザは暗部を自動で持ち上げる機能で、背面モニターに表示される画像（と JPEG）に効くが、RAW のデータには効かない。
そのため、モニターでは適正に見えた画像が、現像すると想定よりアンダーだった、というずれが起きる。
A の露出Simulation は撮影前の表示に関わる設定で、再生画像の明るさには影響しない。
C のホワイトバランスは色に関わる設定で、明るさのずれの説明にならない。
D の AF の設定は露出に影響しない。

### 問4

**解答**：A

EOS R10 は APS-C なので、50mm はフルサイズ換算 80mm の画角になり、身長 170cm のモデルを縦位置で余白を含めて収めるには 5m 以上の距離が要る。
白ホリの奥行きでは下がりきれないので、換算 38〜45mm になる 24〜28mm を使う。
B の絞りは被写界深度を変えるだけで、画角は変わらない。
C の電子シャッターは画角に関係がなく、ストロボが発光しなくなるので不適切である。
D の露出Simulation は表示の明るさの設定で、表示範囲とは関係ない。

### 問5

**解答**：C

オートホワイトバランスは撮影前の画面に写っている光の色を基準に補正を決める。
スタジオではモデリングランプの暖色や、構図に入る服や背景の色によってその判断がカットごとに揺れるため、同じ光で撮っても色がそろわない。
ストロボの色温度は 5600K 前後で安定しているので、K 指定で 5500K に固定すれば全カットの色がそろう。
A の閃光時間は色のばらつきの原因ではなく、シャッター速度を遅くすると環境光が混ざってかえって色が濁る。
B の ISO は色のばらつきとは関係がない。
D はピクチャースタイルの誤解で、RAW で記録する限りスタイルは現像結果を縛らない。
