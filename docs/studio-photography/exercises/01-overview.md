# 第1章 演習問題

対象章：[第1章 スタジオ撮影の全体像](../01-overview.md)（[読み上げ原稿](../audio-scripts/01-overview.md)）

## 問題

### 問1

白ホリでモデル役の友人を撮る準備をし、キーライトのモデリングランプを点けてファインダーをのぞいたところ、顔がかなり暗く見えた。
このとき最初に取るべき行動として適切なものはどれか。

- A. ファインダーで見た明るさが写りになるので、ISO を上げて顔が明るく見えるまで調整する
- B. ファインダーの明るさはストロボの閃光を含まないので、影の向きだけを確かめ、明るさは試し撮りのヒストグラムで判断する
- C. モデリングランプの光量を最大にし、ファインダーで顔が適正に見える絞りを探す
- D. 暗く見えるのは環境光が足りないためなので、暗幕を開けて窓の光を入れる

### 問2

スタジオ撮影が自然光の撮影と違う点として、本章が挙げた二つの違いの組み合わせはどれか。

- A. 高価な機材が要ることと、モデルが必要なこと
- B. 光を自分で作るので同じ結果を再現できることと、ファインダーで見える明るさと写る明るさが一致しないこと
- C. シャッター速度を速くできることと、ISO を下げられること
- D. 背景を白く飛ばせることと、全身を撮れること

### 問3

同じスタジオで来月も撮影する予定があり、今回と同じ写りを再現したい。
記録しておくべき情報として最も適切な組み合わせはどれか。

- A. 撮影した時刻と天候
- B. ストロボの位置、高さ、向き、出力と、カメラの設定
- C. モデルの服装と表情
- D. スタジオの料金と利用時間

### 問4

ソフトボックスを付けたストロボをライトスタンドに載せ、白ホリの中で位置を何度か動かした。
機材の安全に関する記述として適切なものはどれか。

- A. サンドバッグは最初に一度載せれば、位置を動かしても載せ直す必要はない
- B. モデリングランプは撤収の直前まで点けたままにしておくと、用具を外すときに見やすい
- C. 位置を動かすたびにサンドバッグを載せ直し、撤収の前にはモデリングランプを切って冷ます
- D. テスト発光は、光の当たり方を確かめるために被写体の目に向けて行う

### 問5

基準の配置を組み、本番の前に「トリガーの電源を切って一枚」「トリガーの電源を入れて一枚」の試し撮りをした。
一枚目を撮る目的として適切なものはどれか。

- A. ストロボのチャージが終わるまでの時間を測るため
- B. 部屋の定常光が写真に影響していないことを確かめるため
- C. カメラのオートフォーカスが動くことを確かめるため
- D. モデリングランプだけで撮れるかどうかを試すため

## 解答と解説

### 問1

**解答**：B

ストロボの閃光はシャッターを切った一瞬にしか存在しないので、ファインダーに映るのはモデリングランプと部屋の定常光だけである。
その明るさは写真の明るさとは無関係であり、ファインダーで判断できるのは影の向きや光の当たる範囲にとどまる。
明るさは試し撮りのヒストグラムで判断する。
A と C はファインダーの明るさを写りと同一視しており、ISO や絞りを変えると閃光の露出もずれてしまう。
D は環境光を入れることになり、ストロボだけで光を作るというスタジオ撮影の利点を手放す。

### 問2

**解答**：B

本章は、スタジオ撮影が自然光と違う点を二つに絞った。
光源をすべて自分で置くので、位置と出力を記録すれば同じ写りを再現できること、そして閃光は撮る瞬間にしか存在しないので、ファインダーの明るさが写りを示さないことである。
A は撮影の条件であって光の性質の違いではない。
C はストロボ撮影でも当てはまるが、本章が違いの軸に置いた点ではない。
D は白ホリという部屋の性質であり、ストロボ撮影一般の違いではない。

### 問3

**解答**：B

暗幕で窓を塞いだスタジオでは光源はストロボだけなので、写りを決めるのはストロボの位置、高さ、向き、出力と、カメラの設定である。
これらを記録しておけば、別の日に同じ写りを再現できる。
A は自然光の撮影で写りを左右する条件であり、スタジオでは関係がない。
C と D は写りの再現に必要な情報ではない。

### 問4

**解答**：C

ソフトボックスを付けたストロボは重心が高く、脚に触れただけで倒れる。
スタンドを動かせばサンドバッグも動かす必要があるので、位置を変えるたびに載せ直す。
モデリングランプは 150W で用具を触れないほど熱くするので、撤収の前に切って冷ます。
A は載せ直しを怠っており、B は熱い用具を素手で外すことになる。
D はテスト発光を被写体の目に向けており、目の負担になる。

### 問5

**解答**：B

ISO 100、1/200 秒、f/8 でトリガーを切って撮ると、モデリングランプだけの部屋は真っ黒に写る。
これで、写真に写る光がすべて自分の置いたストロボの光であることを確かめられる。
うっすら写るなら、暗幕の隙間や天井の照明が残っている。
A のチャージ時間はレディ音で分かり、C のピントは試し撮り一枚目の目的ではない。
D については、この設定ではモデリングランプの光量では写らないことを確かめるのが目的であり、それで撮ろうとしているのではない。
