# 第8章 演習問題

対象章：[第8章 白ホリでの撮影](../08-white-cyc.md)（[読み上げ原稿](../audio-scripts/08-white-cyc.md)）

## 問題

### 問1

白ホリで友人の全身を撮る。
キーライトで顔が f/8 になる設定のまま、背景の壁を純白に飛ばしたい。
背景ライトで壁面をどの明るさにするのが適切か。

- A. 壁面が f/8 になるように合わせる。被写体と同じ明るさなら白い壁はそのまま白く写る
- B. 壁面が f/11 から f/13 相当になるように合わせる。キーより 1 段から 1.5 段明るければ白飛びする
- C. 壁面が f/22 相当になるように、背景ライトを出力 1/1 で最も明るくする。明るいほど確実に飛ぶ
- D. 壁面の明るさは関係なく、ホワイトバランスを高い色温度にすれば壁は白くなる

### 問2

背景ライトを出力 1/1 にして撮ったところ、背景は真っ白になったが、友人の肩と髪の輪郭が白く縁取られ、髪の細部が背景に溶けて見える。
画像全体も黒が浮いてコントラストが低い。
原因と対処の組み合わせとして適切なものはどれか。

- A. キーライトが弱すぎる。キーの出力を上げて被写体の明るさを背景に近づける
- B. ピントが背景に合っている。AF を 1 点にして瞳に合わせ直す
- C. 背景が明るすぎて壁からの反射光が被写体の背後から回り込み、フレアも起きている。背景ライトをキーの 1 段上まで落とす
- D. ホワイトバランスが合っていない。WB を 5500K から 6500K に変えて輪郭の色を消す

### 問3

奥行き 6m の白ホリで全身を撮るとき、被写体を壁から 2.5m 以上離すよう勧められる理由として適切なものはどれか。

- A. キーライトの光が壁に届きにくくなり、背景ライトの光が被写体に当たらなくなる。どちらも逆二乗則と光の向きによる
- B. 壁に近いと被写体の影が壁に落ちてしまう。2.5m 離せばストロボの影は壁に届かない
- C. カメラから被写体までの距離を 2.5m 以上にしないと、35mm で全身が入らない
- D. 背景ライトの光は 2.5m までしか届かないので、その外側に被写体を置く必要がある

### 問4

白ホリで全身を撮るために、RF 50mm から RF-S 18-150mm に付け替えて 35mm にした。
カメラの位置と高さについて適切な組み合わせはどれか。

- A. 被写体から約 3.3m、レンズの高さは被写体の胸の高さで水平に向ける
- B. 被写体から約 3.3m、立ったままの目の高さから少し見下ろす。顔に近い高さのほうが表情が写る
- C. 18mm まで広げて被写体から 1.5m に近づき、レンズは胸の高さにする。近いほうがストロボの光量が節約できる
- D. 被写体から約 5m、レンズは膝の高さから見上げる。全身が入り、脚が長く写る

### 問5

背景を白く飛ばした全身のカットを撮り終えた後、同じ立ち位置のまま、背景を灰色にしたカットも撮りたい。
キーライトは被写体から 2.1m、被写体は壁から 2.5m にある。
機材を動かさずに背景を灰色にする方法として適切なものはどれか。

- A. 背景ライトの出力を 1/16 から 1/8 に上げる。明るくすると壁の白が飽和して灰色に見える
- B. 絞りを f/8 から f/11 に絞る。被写体も背景も 1 段暗くなり、背景が灰色になる
- C. ホワイトバランスを 3500K にする。壁が青灰色に写る
- D. 背景ライトのグループを OFF にする。壁にはキーライトの漏れだけが届き、約 2.3 段暗い灰色に写る

## 解答と解説

### 問1

**解答**：B

背景を純白にするとは、壁面の画素を最大値まで飛ばすことである。
被写体を f/8 で適正に写す設定のまま、壁面が f/11 から f/13 相当（キーより 1 段から 1.5 段明るい）なら壁面は白飛びして純白になる。
A のように壁面を被写体と同じ f/8 にすると、白い壁は白飛びせず、明るい灰色として階調が残る。
C の「明るいほど確実」は、2 段を超えたところで壁からの反射光の回り込みとフレアを招き、輪郭が溶けて黒が浮く。
D のホワイトバランスは色を変えるだけで、明るさを変えない。

### 問2

**解答**：C

輪郭の白い縁取り、髪の細部の溶け、全体の黒浮きは、背景が明るすぎるときに起きる典型的な症状である。
壁面に当たった強い光が壁で反射して被写体の背後から回り込み、同時に壁面からの強い光がレンズ内で散ってフレアになる。
対処は背景ライトを落とすことで、キーの 1 段上（f/11 相当）まで下げれば、白飛びは保ったまま回り込みとフレアが減る。
出力の下限が 1/16 の SK400II では、それ以上は距離で落とす。
A のようにキーを上げても回り込みは減らず、肌が白飛びに近づく。
B のピント、D のホワイトバランスは、この症状の原因ではない。

### 問3

**解答**：A

理由は二つあり、どちらも光の距離と向きによる。
被写体から 1.5m のキーライトは、壁から 2.5m 離れた被写体の背後の壁まで 4m の距離になり、逆二乗則で約 2.8 段暗くなるので、壁の明るさを背景ライトに委ねられる。
背景ライトは壁から 1.5m で壁に向いているので、被写体が壁から 2.5m 離れていれば背景ライトは被写体の後ろにあり、直射光が肩や髪に当たらない。
B のストロボの影は、白ホリではむしろ壁が飛んでいるので問題にならない。
C はカメラと被写体の距離の話であり、壁との距離とは別である。
D のようにストロボの光が一定の距離で止まることはない。

### 問4

**解答**：A

35mm（フルサイズ換算 56mm）で 1.7m の人物を縦位置に余白つきで収めるには、被写体から約 3.3m が要る。
カメラの高さは被写体の腰から胸に置き、レンズを水平に向けると、頭と足の大きさの比が見た目に近くなる。
B のように目の高さから見下ろすと脚が短く写る。
C の 18mm で 1.5m まで近づくと、パースペクティブが強くなって頭が大きく脚が短く写り、ストロボの光量は距離に関係しない。
D の 5m は奥行き 6m の白ホリでは取れず、見上げる構図は脚を長く見せる意図的な表現である。

### 問5

**解答**：D

背景ライトを消せば、壁に届く光はキーライトの漏れだけになる。
キーライトから壁までは 2.1m と 2.5m を足した 4.6m で、被写体より約 2.3 段暗い。
f/8 の露出で 2.3 段暗い白い壁は、中間より少し暗い灰色に写る。
A のように背景ライトを上げれば壁はさらに白く飛ぶだけである。
B の絞りは被写体と背景を同時に暗くするので、背景はまだ白飛びし、被写体が暗くなる。
C のホワイトバランスは壁を青くするが、明るさは変わらない。
