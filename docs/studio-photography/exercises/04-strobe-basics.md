# 第4章 演習問題

対象章：[第4章 モノブロックストロボとワイヤレストリガー](../04-strobe-basics.md)（[読み上げ原稿](../audio-scripts/04-strobe-basics.md)）

## 問題

### 問1

60×90cm のソフトボックスを被写体から 1.5m に置き、出力 1/4 で顔が f/8 の適正になった。
全身を入れるためにソフトボックスを被写体から 3m に離したとき、絞りを f/8 のままにして同じ明るさを得るには出力をどうすればよいか。

- A. 1/2 に上げる
- B. 1/1 に上げる
- C. 1/8 に下げる
- D. 1/16 に下げる

### 問2

モデルの表情を追って続けて何枚も切ったところ、ほとんどのコマは適正なのに、時々一枚だけ全体が暗いコマが混ざっていた。
設定は ISO 100、1/200 秒、f/8、メカシャッターで変えていない。
原因として最も考えられるものはどれか。

- A. シャッター速度が同調速度を超えていて、幕が閃光を遮っている
- B. ストロボのチャージが終わる前にシャッターを切った
- C. トリガーの電池が減って電波が届かなくなっている
- D. モデリングランプの熱でストロボの出力が落ちている

### 問3

XPro II-C のテスト発光ボタンを押すとストロボは光り、レディ音も鳴る。
ところが EOS R10 のシャッターを切ると、ストロボが光らず真っ黒な写真になる。
最初に確かめるべき設定はどれか。

- A. カメラのシャッター方式が電子シャッターになっていないか
- B. トリガーとストロボのチャンネルが一致しているか
- C. ストロボの出力が 1/16 より下に設定されていないか
- D. ストロボが光スレーブの S2 モードになっていないか

### 問4

スタジオでモデルを撮るにあたり、XPro II-C を TTL ではなく M モードで使う理由として適切なものはどれか。

- A. TTL は SK400II のようなモノブロックには対応しておらず、クリップオンストロボ専用だから
- B. M モードのほうがチャージ時間が短く、連続して撮れるから
- C. TTL は閃光時間が長くなり、被写体の動きが止まらないから
- D. スタジオでは条件が変わらないので、一度決めた出力で構図を変えても露出が揺れないから

### 問5

モデリングランプを最大の明るさで点けたまま、ISO 100、1/200 秒、f/8 で撮影している。
モデリングランプの光が写真の明るさに影響していないことを、その場で確かめる方法はどれか。

- A. モデリングランプを消して一枚撮り、点けたときと比べてヒストグラムの山が動かないことを見る
- B. カメラのファインダーに表示される露出計の指針が中央に来ていることを見る
- C. トリガーの電源を切って一枚撮り、真っ黒に写ることを見る
- D. シャッター速度を 1/250 秒に上げて撮り、明るさが変わらないことを見る

## 解答と解説

### 問1

**解答**：B

逆二乗則により、距離が 2 倍になると光は 4 分の 1、つまり 2 段暗くなる。
1.5m から 3m は 2 倍なので、出力を 2 段上げて 1/4 から 1/1 にすれば同じ f/8 に戻る。
A の 1/2 は 1 段しか上げておらず、距離 1.4 倍（2.1m）に相当する。
C と D は出力を下げており、逆方向である。
なお、1/1 ではチャージ時間が 1 秒ほどに延びるので、連続して切るには待ちが要る。

### 問2

**解答**：B

一部のコマだけが暗く、しかも全体が均一に暗いのは、チャージが終わる前にシャッターを切って、蓄えきれていないエネルギーで発光したときの症状である。
A の同調速度超えなら、全コマに黒い帯が出るか、全コマが暗くなる。
C の電波が届かない場合はストロボがまったく光らないので、真っ黒に近い写真になり、暗さの程度が違う。
D のような現象は起きない。
モデリングランプの熱で問題になるのは、本体や用具が触れないほど熱くなることである。
レディ音を聞いてから切るか、出力を下げてチャージを短くするのが対処になる。

### 問3

**解答**：A

テスト発光で光る以上、トリガーとストロボの通信（チャンネルと ID）は通っており、チャージも済んでいる。
残る原因はカメラがトリガーに発光の合図を送っていないことで、EOS R10 は電子シャッターではストロボが発光しない。
シャッター方式をメカシャッターか電子先幕に戻す。
B はテスト発光で光ることから除外できる。
C の出力を 1/16 より下に設定しても、ストロボは 1/16 で光るので真っ黒にはならない。
D の光スレーブは、無線で通信できている状態では関係がない。

### 問4

**解答**：D

M モードを選ぶ理由は、スタジオではライトの位置と出力を決めれば条件が変わらないことにある。
TTL は撮るたびにプリ発光の反射を測って出力を決めるので、画面に白い壁や黒い服が多く入る構図に変えると、同じライティングなのに明るさが揺れる。
A は誤りで、XPro II-C と Godox の X システムに対応したモノブロックでは TTL も使える。
B と C は誤りで、チャージ時間と閃光時間は出力で決まり、TTL か M かでは変わらない。

### 問5

**解答**：C

トリガーを切って撮った一枚には、ストロボ以外の光しか写らない。
それが真っ黒なら、モデリングランプも室内の照明も、ISO 100、1/200 秒、f/8 の露出には混ざっていない。
A も間違いではないが、ストロボ光の中に混ざったわずかな差をヒストグラムで見分けるのは難しく、環境光だけを取り出して見る C のほうが確実である。
B は誤りで、M モードでサードパーティのトリガーを使うとき、ファインダーの露出計はストロボ光を含まない環境光だけを測っており、ストロボ撮影の露出の判断には使えない。
D は誤りで、1/250 秒に上げても環境光の写り方が 3 分の 1 段変わるだけで、混ざっているかどうかの判断にはならない。
