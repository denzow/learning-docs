# 第5章 演習問題

対象章：[第5章 光の質と方向、ライティング用具](../05-light-quality.md)（[読み上げ原稿](../audio-scripts/05-light-quality.md)）

## 問題

### 問1

60×90cm のソフトボックスを被写体から 1.5m に置いて友人の顔を撮ったところ、影の縁が思ったより硬く見えた。
影をもっと柔らかくしたい。
光の質を決める機構に照らして、正しい対処はどれか。

- A. 出力を 1/4 から 1/8 に下げて、光を弱くする
- B. ソフトボックスを被写体から 0.8m まで近づけ、出力を下げて明るさを戻す
- C. ソフトボックスを 3m に離し、出力を上げて明るさを戻す
- D. ソフトボックスを外して標準リフレクターに替え、被写体から 3m に置く

### 問2

透過アンブレラをキーライトにして白ホリの前で友人を撮ったところ、背景が意図せず明るく、影側の頬も思ったより明るく写った。
ライトの位置と出力は変えたくない。
原因と対処の組み合わせとして適切なものはどれか。

- A. アンブレラの光が四方に広がって白い壁と床で反射している。ソフトボックスに替えるか、影側に黒レフ板を立てる
- B. アンブレラは硬い光なので背景まで届いている。反射アンブレラに替えて光を柔らかくする
- C. シャッター速度が遅く環境光が写り込んでいる。1/200 秒から 1/250 秒に上げる
- D. アンブレラの効率が高すぎる。グリッドを付けて光の広がりを絞る

### 問3

上半身のプロフィール写真を撮り比べたところ、ライトが顔から 0.8m のときは顔だけが明るく肩から下が急に暗くなり、3m のときは全身がほぼ均一に照らされた。
どちらも出力を調整して顔の明るさは f/8 に揃えてある。
この違いが生じる理由として正しいものはどれか。

- A. 近いライトほど出力が低いので、体まで光が届かない
- B. 顔と肩のライトからの距離の比が、ライトが近いほど大きくなり、逆二乗則による明るさの差が広がる
- C. 近いライトは光が硬くなるので、体に落ちる影が濃くなる
- D. 遠いライトはソフトボックスの縁の光で照らすことになり、フェザリングと同じ効果が出る

### 問4

友人の顔を撮った写真を拡大して見ると、キャッチライトが両方の瞳の中央より下に四角く映り、目の下にも影が出ていた。
ライトの位置について読み取れることと対処はどれか。

- A. ライトがカメラの真上の正面にある。斜め前 45 度に振る
- B. ライトが顔より低い位置にある。顔より少し上から見下ろす高さまで上げる
- C. ライトが被写体の真上にある。高さを下げて顔の高さに合わせる
- D. ライトが遠すぎてキャッチライトが小さい。被写体に近づける

### 問5

斜め前 45 度、1.5m のソフトボックスで友人を撮ると、顔は f/8 だが胸は 0.7 段暗く、背景の白ホリにも光が漏れて f/2.8 ほどの明るさになった。
顔と胸の差を縮め、背景への漏れも減らしたい。
ライトの距離と用具は変えないという条件で、適切な操作はどれか。

- A. ソフトボックスの中心を 30 度ほどカメラ側へ振って光の縁で顔を照らし、出力を 0.7 段上げる
- B. ソフトボックスの中心を背景側へ振り、出力を 0.7 段下げる
- C. 絞りを f/8 から f/5.6 に開き、出力を 1 段下げる
- D. 白レフ板を胸の前に置き、出力はそのままにする

## 解答と解説

### 問1

**解答**：B

光の質は被写体から見た光源の見かけの大きさで決まる。
同じソフトボックスでも、近づければ被写体から見た角度が大きくなり、影の縁は柔らかくなる。
近づけると逆二乗則で明るくなるので、出力を下げて顔の明るさを戻す。
A は明るさしか変えず、影の縁の鋭さは変わらない。
C は逆に見かけの大きさを小さくするので硬くなる。
D の標準リフレクターは 20cm ほどの硬い光源で、3m に離せばさらに小さく見えるため、最も硬い光になる。

### 問2

**解答**：A

透過アンブレラは光を四方八方に広げる用具で、白ホリの壁と床に当たった光が戻ってきて背景を持ち上げ、影側の頬にも回り込む。
前方にしか光を出さないソフトボックスに替えるか、影側に黒レフ板を立てて回り込みを遮るのが対処である。
B は前提が誤りで、アンブレラの光は柔らかい。
柔らかさと広がりは別の性質であり、反射アンブレラに替えても広がりは残る。
C は環境光の話で、ストロボを切った試し撮りが真っ黒になるスタジオでは当てはまらない。
D のグリッドは標準リフレクターに付ける用具で、アンブレラには付けられない。

### 問3

**解答**：B

ライトが顔から 0.8m なら、0.5m 後ろの肩はライトから 1.3m にあり、距離の比が大きいので逆二乗則による差が 1.3 段ほどになる。
ライトが 3m なら肩は 3.5m にあり、比が小さいので差は 0.4 段ほどに縮む。
明るさの落ち方は距離でしか変えられず、出力では戻せない。
A は誤りで、出力は顔の明るさを揃えるために調整しているだけである。
C は逆で、近いライトは柔らかくなる。
D はフェザリングの説明として誤りで、ライトの向きを変えていない限り縁の光で照らすことにはならない。

### 問4

**解答**：B

キャッチライトはライトの位置をそのまま映すので、瞳の中央より下にあればライトは顔より低い。
低い位置からの光は目の下や鼻の上に影を作り、見慣れないので不自然に見える。
顔より少し上から見下ろす高さに上げると、キャッチライトは瞳の上半分に移り、影は自然な向きになる。
A は水平方向の話で、正面のライトでもキャッチライトの上下は高さで決まる。
C の真上のライトなら目の窪みに影が落ち、キャッチライトは映らないか瞳の上端に出る。
D の距離はキャッチライトの大きさを変えるが、位置は変えない。

### 問5

**解答**：A

ソフトボックスの中心を被写体から外して縁の光で照らすフェザリングは、顔と体の明るさの差を縮め、中心の強い光が背景へ向かわなくなるので漏れも減る。
縁の光は弱いので、出力を上げて顔の明るさを戻す。
B は中心を背景に向けるので、漏れが増える。
C は絞りと出力を相殺しているだけで、顔と胸の差も背景への漏れも変わらない。
D の白レフ板は胸を明るくはするが、背景への漏れには効かない。
